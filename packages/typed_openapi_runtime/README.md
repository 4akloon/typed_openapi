# typed_openapi_runtime

Runtime support for clients generated by
[`typed_openapi`](../typed_openapi/README.md).

> **Status:** early design, not published yet.

Planned contents:

- typed API exceptions and `Result`;
- `Patch<T>` for tri-state fields (absent / `null` / value);
- JSON decoding helpers that report the JSON path of a failure;
- encoders for OpenAPI parameter styles (`form`, `deepObject`, `pipeDelimited`, …);
- a WHATWG-compliant SSE decoder.

Kept small on purpose: dependencies are limited to `dio` and `meta`.
