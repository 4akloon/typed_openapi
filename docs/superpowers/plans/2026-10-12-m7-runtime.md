# План M7: runtime (`typed_openapi_runtime`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** пакет `typed_openapi_runtime` дає згенерованому коду все, що йому потрібно під час виконання: `Result<T, E>` з типізованими невдачами замість винятків, `Patch<T>` для полів із трьома станами, строге декодування JSON (`JsonReader`) з JSON pointer першої невідповідності, `JsonValue`, кодувальники стилів параметрів OAS, надсилання запиту через Dio користувача (`DioRequestSender.send`) і потік подій SSE за WHATWG як `Result` зі `Stream<SseItem<T>>` (`openEvents`).

**Architecture:** `lib/src/` пакета `typed_openapi_runtime` поділено за відповідальністю: `json/` і `model/` (декодування і `Patch`), `result/` (sealed `Result`), `params/` (RFC 6570 / RFC 3986), `request/` (`OperationInfo`, `OperationRequest`, що сам кодує шлях і query, `RawResponse`, на якому перемикається згенерований декодер), `dio/` (`DioRequestSender`, `CallOptions` — єдине місце, що викликає Dio), `sse/` (WHATWG-парсер байтів у `SseMessage` і типізований `SseItemDecoder`). Задачі йдуть знизу вгору: кожна додає шар і його тести, остання перевіряє, що API складається в код форми M8–M10.

**Tech Stack:** Dart `>=3.10.0 <4.0.0`, чистий Dart; залежності `dio: ^5.11.1` і `meta: ^1.19.0` (уже в pubspec), нових немає; тести на `package:test`, Dio — через тестовий `HttpClientAdapter` без мережі.

## Global Constraints

- SDK `>=3.10.0 <4.0.0`; пакет — чистий Dart, працює на web (крім SSE зі стандартним браузерним адаптером Dio). Primary constructors (Dart 3.13) не використовуються.
- Залежності — лише `dio` і `meta`; `pubspec.yaml` не змінюється.
- Dart 3.10 активно: dot shorthands скрізь, де відомий тип контексту (`style: .matrix`, `responseKind: .text`, `.value('Rex')`), null-aware елементи (`'tags': ?tags`, `h.name: ?h.encode()`), switch-вирази і patterns, sealed / final класи, extension type `JsonValue`.
- ООП: жодних функцій верхнього рівня, крім `main` у тестах; декодери — статичні методи `JsonReader`, кодувальники — класи параметрів і enum `PercentEncoder`. Кожен публічний член має doc-коментар.
- Згенерований метод не кидає винятків на даних сервера: відповідь, що не відповідає схемі, — `DecodeError` з pointer; ловляться лише `DioException` і `JsonDecodeException`; `Error` (`TypeError`, `StateError`) не ловиться.
- Строгість: інший JSON-тип — помилка; єдине розширення — ціле там, де очікується `number`; `null` — помилка лише в required non-nullable (optional читає його як «немає»); `date-time` без зсуву — помилка з `hint`; лише перша невідповідність.
- Детермінізм: query і заголовки — у порядку параметрів; ключі мап — у порядку JSON.
- Dio користувача не змінюється (`baseUrl`, заголовки, інтерсептори, `validateStatus`, transformer); повторів немає; запит — лише через `dio.request`.
- Межі: глибина JSON — 1000 рівнів, перевірка без рекурсії; нескінченні й завеликі числа — помилка; SSE ніколи не випускає помилку потоку.
- Негативні тести на валідних входах у кожній задачі (валідні читання, приклади OAS і WHATWG, успішні запити).

## Ухвалені рішення

Рішення специфікації M7 — обов'язкові. Тут — те, що специфікація лишає планові.

1. **Файли — по одному типу або тісній групі**, як у таблиці «Файли». Бібліотека експортує публічні типи `show`-списками; `ParameterValue` і `PercentEncoder` — внутрішні.
2. **`JsonReader` — клас з екземплярними читаннями властивостей і статичними декодерами** (лінт `avoid_classes_with_only_static_members` забороняє клас лише зі статичними членами). Декодер — `T Function(Object? value)`, тож tear-off `JsonReader.asInt`, `Tag.fromJson` через `JsonReader.objectOf` і конвертер R6.8 взаємозамінні.
3. **Шлях помилки будується знизу вгору:** декодер кидає `JsonDecodeException` без шляху, кожен рівень (`required`, `listOf`, `mapOf`) додає свій сегмент через `under`, схему ставить найглибший `JsonReader`. Ціна — `try` на поле; на успішному шляху вона нульова.
4. **`RawResponse` — на що перемикається згенерований декодер:** `statusCode`, `json`, `jsonObject`, `text`, `bytes` і `success` / `error` / `undocumented`, що створюють `Result` з уже відомими статусом і заголовками. Декодер — функція `Result<T, E> Function(RawResponse)`, тож `send` не знає про статуси операції.
5. **`OperationRequest` несе параметри, а не готовий URL:** `resolvePath` підставляє `PathParameter` у `OperationInfo.pathTemplate` і додає query; генерований код не склеює рядки.
6. **Задача 5 вводить `send`, задача 7 замінює `dio_request_sender.dart` цілком**, додаючи `openEvents`, `forPlatform` і `webStreamingMessage` (до задачі 6 SSE-типів ще немає).

Поведінка, яку закріплюють тести:
- `Patch`: `toJson` дає `{}`, `{"name":"Rex","tag":null}`; dot shorthands `.value('Rex')` / `.nullValue()` у контексті `Patch<String>?`; рівність і вичерпний `switch` за `null` / `PatchNull` / `PatchValue`.
- Читання матриці required × nullable на валідних даних не дають помилок; зайві поля ігноруються.
- Відсутнє required — `expected a required property, got no value` з pointer, полем і схемою; `null` — помилка лише в required non-nullable, `optional` читає `null` як «немає»; інший тип — `expected an integer, got a string`.
- Pointer вкладених значень: `/tags/1/name` зі схемою `Tag`; ключі мапи екрануються (`/labels/a~1b~0c`); порядок ключів мапи зберігається; `FormatException` конвертера — помилка в pointer елемента.
- Строгість: `asInt(1.0)` і 30-значне ціле (`jsonDecode` дає `double`) — помилка; `asDouble(1)` — `1.0`; нескінченність — помилка; `date-time` — лише RFC 3339 зі зсувом, без неіснуючих дат і секунди 60; кожна така помилка несе `hint` (`JsonReader.dateTimeHint`: конвертер `types.formats` або override `format`), без зсуву — `actual: a date-time without an offset`.
- `checkDepth`: 1000 рівнів — так, 1001 і 200 000 — `JsonDecodeException` з pointer довжиною 1000, без переповнення стека.
- `JsonValue`: `jsonEncode` як є, доступи не кидають, `value['a'][1].asString`, відсутнє — `JsonValue(null)`.

```dart
import 'dart:convert';

import 'package:test/test.dart';
import 'package:typed_openapi_runtime/typed_openapi_runtime.dart';

/// A model the way generated code reads one.
final class Tag {
  const Tag(this.name);

  factory Tag.fromJson(Map<String, Object?> json) {
    final r = JsonReader(json, schema: 'Tag');
    return Tag(r.required('name', JsonReader.asString));
  }

  final String name;
}

void main() {
  JsonDecodeException failure(void Function() body) {
    try {
      body();
    } on JsonDecodeException catch (e) {
      return e;
    }
    fail('expected a JsonDecodeException');
  }

  group('JsonReader properties', () {
    const json = <String, Object?>{
      'id': 7,
      'name': 'Rex',
      'tag': null,
      'extra': 'ignored',
    };
    const r = JsonReader(json, schema: 'Pet');

    test('reads valid properties and ignores undeclared ones', () {
      expect(r.required('id', JsonReader.asInt), 7);
      expect(r.requiredNullable('tag', JsonReader.asString), isNull);
      expect(r.requiredNullable('name', JsonReader.asString), 'Rex');
      expect(r.optional('name', JsonReader.asString), 'Rex');
      expect(r.optional('missing', JsonReader.asString), isNull);
    });

    test('a missing required property names schema, field and pointer', () {
      final e = failure(() => r.required('age', JsonReader.asInt));
      expect(e.schema, 'Pet');
      expect(e.field, 'age');
      expect(e.pointer, '/age');
      expect(e.message, 'expected a required property, got no value');
      expect(
        e.toString(),
        'JsonDecodeException: expected a required property, got no value '
        'at /age in Pet',
      );
      expect(
        failure(() => r.requiredNullable('age', JsonReader.asInt)).pointer,
        '/age',
      );
    });

    test('null is an error in a required non-nullable property only', () {
      final e = failure(() => r.required('tag', JsonReader.asString));
      expect(e.message, 'expected a non-null value, got null');
      expect(e.pointer, '/tag');

/// JSON that does not match the schema a generated `fromJson` expects.
///
/// Thrown by `fromJson` (the json_serializable contract has no other way to
/// fail) and turned into a `DecodeError` result by the request sender,
/// so it never reaches the caller of a generated operation. The message names
/// the expected and the actual JSON type, never the value itself: values can
/// be large or private.
final class JsonDecodeException implements Exception {
  /// Creates an exception at [path] inside the value of [schema].
  JsonDecodeException({
    required this.expected,
    required this.actual,
    List<Object> path = const [],
    this.schema,
    this.hint,
  }) : path = List.unmodifiable(path);

  /// What the schema expects, such as `an integer`.
  final String expected;

  /// What the JSON has, such as `a string` or `no value`.
  final String actual;

  /// Object keys ([String]) and array indexes ([int]) from the decoded value
  /// to the place of the problem.
  final List<Object> path;

  /// The schema whose `fromJson` found the problem, if known.
  final String? schema;

  /// How to fix the problem when the server sends this on purpose, such as
  /// a converter for a date-time format; `null` when there is no advice.
  final String? hint;

  /// [path] as an RFC 6901 JSON pointer; `''` is the decoded value itself.
  String get pointer => [
    for (final segment in path)
      '/${'$segment'.replaceAll('~', '~0').replaceAll('/', '~1')}',
  ].join();

  /// The key of the field with the problem, or `null` when the problem is
  /// not in an object property.
  String? get field => switch (path.lastOrNull) {
    final String key => key,
    _ => null,
  };

  /// `expected …, got …`.
  String get message => 'expected $expected, got $actual';

  /// The same problem one level deeper: [segment] is prepended to [path],
  /// and [schema] is set when the problem has none yet.
  JsonDecodeException under(Object segment, {String? schema}) =>
      JsonDecodeException(
        expected: expected,
        actual: actual,
        path: [segment, ...path],
        schema: this.schema ?? schema,
        hint: hint,
      );

  /// The same problem with [schema] set when it has none yet.
  JsonDecodeException inSchema(String schema) => JsonDecodeException(
    expected: expected,
    actual: actual,
    path: path,
    schema: this.schema ?? schema,
    hint: hint,
  );

  /// Describes the JSON type of [value] for [actual]: `null`, `a boolean`,
  /// `a number`, `a string`, `an array`, `an object` or `a non-JSON value`.
  static String describe(Object? value) => switch (value) {
    null => 'null',
    bool() => 'a boolean',
    num() => 'a number',
    String() => 'a string',
    List() => 'an array',
    Map() => 'an object',
    _ => 'a non-JSON value',
  };

  @override
  String toString() {
    final at = path.isEmpty ? '' : ' at $pointer';
    final owner = schema == null ? '' : ' in $schema';
    final advice = hint == null ? '' : '. $hint';
    return 'JsonDecodeException: $message$at$owner$advice';
  }
}

import '../model/patch.dart';
import 'json_decode_exception.dart';
import 'json_value.dart';

/// Reads the properties of one JSON object for a generated `fromJson`.
///
/// Decoding is strict: a value of another JSON type is an error, and the
/// only widening is an integer where a `number` is expected. The first
/// mismatch stops decoding.
///
/// Every read takes a decoder, `T Function(Object? value)`: one of the
/// static decoders of this class ([asInt], [listOf], …), a generated
/// `fromJson`, or a user converter. A [JsonDecodeException] from the
/// decoder gets the property key prepended to its path, so a problem deep
/// inside the value names its full JSON pointer; a [FormatException] (as
/// `DateTime.parse` or a user converter throws) becomes a
/// [JsonDecodeException] at the property. Undeclared properties are
/// ignored.
///
/// ```dart
/// factory Pet.fromJson(Map<String, Object?> json) {
///   final r = JsonReader(json, schema: 'Pet');
///   return Pet(
///     id: r.required('id', JsonReader.asInt),
///     tags: r.optional(
///       'tags',
///       JsonReader.listOf(JsonReader.objectOf(Tag.fromJson)),
///     ),
///   );
/// }
/// ```
final class JsonReader {
  /// Reads [json], the value of [schema].
  const JsonReader(this.json, {required this.schema});

  /// Reads [value], which must be a JSON object.
  factory JsonReader.of(Object? value, {required String schema}) {
    try {
      return JsonReader(asObject(value), schema: schema);
    } on JsonDecodeException catch (e) {
      throw e.inSchema(schema);
    }
  }

  /// The deepest nesting of arrays and objects [checkDepth] accepts.
  static const int maxDepth = 1000;

  /// The object being read.
  final Map<String, Object?> json;

  /// The schema name reported in decoding errors.
  final String schema;

  /// A required, non-nullable property: absent and `null` are errors.
  T required<T extends Object>(String key, T Function(Object? value) decode) {
    _checkPresent(key);
    return _decode(key, _nonNull(key), decode);
  }

  /// A required, nullable property: absent is an error, `null` is `null`.
  T? requiredNullable<T extends Object>(
    String key,
    T Function(Object? value) decode,
  ) {
    _checkPresent(key);
    final value = json[key];
    return value == null ? null : _decode(key, value, decode);
  }

  /// An optional property, nullable or not: absent and `null` are both
  /// `null`, as the Dart field is `T?` either way (use [patch] to tell them
  /// apart).
  T? optional<T extends Object>(String key, T Function(Object? value) decode) {
    final value = json[key];
    return value == null ? null : _decode(key, value, decode);
  }

  /// A three-state property: absent gives `null`, `null` gives
  /// [Patch.nullValue], a value gives [Patch.value].
  Patch<T>? patch<T extends Object>(
    String key,
    T Function(Object? value) decode,
  ) {
    if (!json.containsKey(key)) return null;
    final value = json[key];
    return value == null
        ? const PatchNull()
        : PatchValue(_decode(key, value, decode));
  }

  /// A required property of any JSON value (a schema without
  /// constraints); `null` is a value. Absent is an error.
  JsonValue requiredValue(String key) {
    _checkPresent(key);
    return JsonValue(json[key]);
  }

  /// An optional property of any JSON value; absent reads as
  /// `JsonValue(null)`. A [JsonValue] over `null` is `null` at run time, so
  /// `JsonValue?` could not tell absent from `null` anyway.
  JsonValue optionalValue(String key) => JsonValue(json[key]);

  void _checkPresent(String key) {
    if (json.containsKey(key)) return;
    throw JsonDecodeException(
      expected: 'a required property',
      actual: 'no value',
      path: [key],
      schema: schema,
    );
  }

  Object _nonNull(String key) =>
      json[key] ??
      (throw JsonDecodeException(
        expected: 'a non-null value',
        actual: 'null',
        path: [key],
        schema: schema,
      ));

  T _decode<T>(String key, Object? value, T Function(Object? value) decode) =>
      _at(key, value, decode, schema: schema);

  /// Runs [decode] on [value] and moves its problem under [segment].
  static T _at<T>(
    Object segment,
    Object? value,
    T Function(Object? value) decode, {
    String? schema,
  }) {
    try {
      return decode(value);
    } on JsonDecodeException catch (e) {
      throw e.under(segment, schema: schema);
    } on FormatException catch (e) {
      throw JsonDecodeException(
        expected: 'a value its decoder accepts',
        actual: 'a value it rejected: ${e.message}',
        path: [segment],
        schema: schema,
      );
    }
  }

  /// A JSON object.
  static Map<String, Object?> asObject(Object? value) => switch (value) {
    final Map<String, Object?> map => map,
    _ => throw _mismatch('an object', value),
  };

  /// A JSON array.
  static List<Object?> asList(Object? value) => switch (value) {
    final List<Object?> list => list,
    _ => throw _mismatch('an array', value),
  };

  /// A JSON string.
  static String asString(Object? value) => switch (value) {
    final String text => text,
    _ => throw _mismatch('a string', value),
  };

  /// A JSON boolean.
  static bool asBool(Object? value) => switch (value) {
    final bool flag => flag,
    _ => throw _mismatch('a boolean', value),
  };

  /// A JSON integer. A double is rejected, even `1.0`: `jsonDecode` gives
  /// an [int] for every integer literal small enough, so a double means the
  /// server wrote a fraction, an exponent or a number too big for `int`.
  static int asInt(Object? value) => switch (value) {
    final int number => number,
    _ => throw _mismatch('an integer', value),
  };

  /// A finite JSON number as a [double]; an integer is widened.
  static double asDouble(Object? value) => asNumber(value).toDouble();

  /// A finite JSON number. JSON has no infinity, but `jsonDecode('1e400')`
  /// gives one; it is rejected, because `jsonEncode` could not write it back.
  static num asNumber(Object? value) => switch (value) {
    final num number when number.isFinite => number,
    num() => throw JsonDecodeException(
      expected: 'a finite number',
      actual: 'a number out of the double range',
    ),
    _ => throw _mismatch('a number', value),

  /// An RFC 3339 date-time string (`format: date-time`), such as
  /// `2024-02-03T04:05:06Z` or `2024-02-03T04:05:06.5+02:00`. A date-time
  /// without an offset is rejected (it does not name an instant), and so
  /// are dates that do not exist (`2024-02-30`) and leap seconds, which
  /// [DateTime] would silently roll over. The error carries
  /// [dateTimeHint]: the explicit fix when a server sends another format.
  static DateTime asDateTime(Object? value) {
    final text = asString(value);
    final match = _rfc3339.firstMatch(text);
    if (match != null) {
      final year = int.parse(match[1]!);
      final month = int.parse(match[2]!);
      final day = int.parse(match[3]!);
      if (day <= DateTime.utc(year, month + 1, 0).day) {
        return DateTime.parse(text.toUpperCase());
      }
    }
    throw JsonDecodeException(
      expected: 'an RFC 3339 date-time string',
      actual: _localDateTime.hasMatch(text)
          ? 'a date-time without an offset'
          : 'a string in another format',
      hint: dateTimeHint,
    );
  }

  /// The fix for a server that sends `date-time` in another format.

  /// whose values [decode] reads; keys keep the JSON order.

    T Function(Object? value) decode,
  ) => (value) {
    final entries = asObject(value);
    return <String, T>{
      for (final MapEntry(:key, value: item) in entries.entries)
        key: _at(key, item, decode),

  /// Checks that [json] nests arrays and objects at most [maxDepth] deep,
  /// without recursion; a deeper value would overflow the stack of a
  /// recursive `fromJson` or `jsonEncode`. The error path points at the
  /// first container that is too deep.
  static void checkDepth(Object? json) {
    if (json is! Map && json is! List) return;
    final levels = [_Level(json)];
    while (levels.isNotEmpty) {
      final level = levels.last;
      if (!level.moveNext()) {
        levels.removeLast();
        continue;
      }
      final child = level.value;
      if (child is! Map && child is! List) continue;
      if (levels.length >= maxDepth) {
        throw JsonDecodeException(
          expected: 'arrays and objects nested at most $maxDepth deep',
          actual: 'deeper nesting',
          path: [for (final l in levels) l.segment],
        );
      }
      levels.add(_Level(child));
    }
  }

    r'^(\d{4})-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])[Tt]'
    r'([01]\d|2[0-3]):[0-5]\d:[0-5]\d(\.\d+)?'
    r'([Zz]|[+-]([01]\d|2[0-3]):[0-5]\d)$',
  );

  static final RegExp _localDateTime = RegExp(
    r'^\d{4}-\d{2}-\d{2}[Tt ]\d{2}:\d{2}(:\d{2}(\.\d+)?)?$',
  );

  static JsonDecodeException _mismatch(String expected, Object? value) =>
      JsonDecodeException(
        expected: expected,
        actual: JsonDecodeException.describe(value),
      );
}

/// One container on the explicit stack of [JsonReader.checkDepth].
final class _Level {
  _Level(Object? container)
    : _entries = switch (container) {
        final Map<Object?, Object?> map => map.entries.iterator,
        final List<Object?> list => list.asMap().entries.iterator,
        _ => const <MapEntry<Object?, Object?>>[].iterator,
      };

  final Iterator<MapEntry<Object?, Object?>> _entries;

  bool moveNext() => _entries.moveNext();

  Object get segment => _entries.current.key ?? 'null';

  Object? get value => _entries.current.value;
}

import 'package:dio/dio.dart';

import '../json/json_decode_exception.dart';

/// The outcome of a generated operation: [Success] with the decoded body of
/// type [T], or a [Failure] whose documented error body has type [E].
///
/// Generated operations never throw for expected problems (HTTP errors,
/// transport failures, cancellation, bodies that do not match the schema);
/// errors of the program (`TypeError`, `StateError`) are not caught. There
/// are no helper methods: read a result with pattern matching.
///
/// ```dart
/// switch (await api.pets.getPetById(petId: 1)) {
///   case Success(:final data): show(data);
///   case HttpError(:final body): showError(body);
///   case Failure(): retryLater();
/// }
/// ```
///
/// An operation without documented errors has `E = Never`; a success
/// without a body has `T = void`.
sealed class Result<T, E> {
  const Result();
}

/// A response with a documented success status.
final class Success<T, E> extends Result<T, E> {
  /// Creates a success with the decoded [data].
  const Success(this.data, {required this.statusCode, this.headers = const {}});

  /// The decoded body.
  final T data;

  /// The HTTP status code.
  final int statusCode;

  /// The response headers, names in lower case.
  final Map<String, List<String>> headers;
}

/// Any outcome but [Success].
sealed class Failure<T, E> extends Result<T, E> {
  const Failure();
}

/// A response with a documented error status (4xx, 5xx or `default`) whose
/// body decoded as [E]. A body that does not decode is a [DecodeError].
final class HttpError<T, E> extends Failure<T, E> {
  /// Creates an error with the decoded [body].
  const HttpError(
    this.body, {
    required this.statusCode,
    this.headers = const {},
  });

  /// The decoded error body.
  final E body;

  /// The HTTP status code.
  final int statusCode;

  /// The response headers, names in lower case.
  final Map<String, List<String>> headers;

  @override
  String toString() => 'HttpError($statusCode)';
}

/// A response whose status the operation does not document; the body is
/// kept as received.
final class UndocumentedStatus<T, E> extends Failure<T, E> {
  /// Creates an undocumented-status failure.
  const UndocumentedStatus({
    required this.statusCode,
    this.rawBody,
    this.headers = const {},
  });

  /// The HTTP status code.
  final int statusCode;

  /// The body as the HTTP client returned it (decoded JSON, text or bytes).
  final Object? rawBody;

  /// The response headers, names in lower case.
  final Map<String, List<String>> headers;

  @override
  String toString() => 'UndocumentedStatus($statusCode)';
}

/// A response body that does not match the schema of its status (success
/// or documented error), or is not valid JSON. Carries the first mismatch.
final class DecodeError<T, E> extends Failure<T, E> {
  /// Creates a decode failure.
  const DecodeError(
    this.error, {
    this.statusCode,
    this.rawBody,
    this.headers = const {},
  });

  /// What did not match and where (JSON pointer, expected, actual).
  final JsonDecodeException error;

  /// The HTTP status code; `null` when Dio could not parse the JSON body
  /// and dropped the response.
  final int? statusCode;

  /// The body as the HTTP client returned it; for JSON Dio could not parse,
  /// the text its parser reported.
  final Object? rawBody;

  /// The response headers, names in lower case.
  final Map<String, List<String>> headers;

  @override
  String toString() => 'DecodeError(${statusCode ?? 'no status'}: $error)';
}

/// The request got no response: a timeout, a connection or certificate
/// problem, or another failure Dio reports.
final class TransportError<T, E> extends Failure<T, E> {
  /// Creates a transport failure.
  const TransportError(this.exception, this.stackTrace);

  /// What Dio reported; `exception.type` tells the kind.
  final DioException exception;

  /// Where [exception] was thrown.
  final StackTrace stackTrace;

  @override
  String toString() => 'TransportError(${exception.type.name})';
}

/// The caller cancelled the request; not a failure of the server or the
/// network.
final class Cancelled<T, E> extends Failure<T, E> {
  /// Creates a cancellation outcome.
  const Cancelled(this.exception, this.stackTrace);

  /// What Dio reported (`DioExceptionType.cancel`).
  final DioException exception;

  /// Where [exception] was thrown.
  final StackTrace stackTrace;

  @override
  String toString() => 'Cancelled';
}

/// case.
enum PercentEncoder {
  /// Keeps only unreserved characters (`A-Z a-z 0-9 - . _ ~`), as RFC 6570
  /// simple expansion does.
  unreserved,

  /// `allowReserved: true`: also keeps the reserved characters that are safe
  /// in a query value (`: / ? @ ! $ ' ( ) * , ;`) and valid `%XX` triplets.
  /// `[ ] #` and `& = +` stay encoded, as OAS 3.2 requires for the query.
  reserved,

  /// Header values: keeps printable ASCII (space to `~`); control
  /// characters and non-ASCII are encoded, so a value cannot break the
  /// header line.
  header;

  /// Encodes [text].
  String encode(String text) {
    final bytes = utf8.encode(text);
    final out = StringBuffer();
    for (var i = 0; i < bytes.length; i++) {
      final byte = bytes[i];
      if (_keeps(byte) || _isTriplet(bytes, i)) {
        out.writeCharCode(byte);
      } else {
        out
          ..write('%')
          ..write(byte.toRadixString(16).toUpperCase().padLeft(2, '0'));
      }
    }
    return out.toString();
  }

  bool _keeps(int byte) => switch (this) {
    unreserved => _isUnreserved(byte),
    reserved => _isUnreserved(byte) || _safeReserved.contains(byte),
    header => byte >= 0x20 && byte <= 0x7E,
  };

  bool _isTriplet(List<int> bytes, int i) =>
      this == reserved &&
      bytes[i] == 0x25 &&
      i + 2 < bytes.length &&
      _isHex(bytes[i + 1]) &&
      _isHex(bytes[i + 2]);

  static bool _isUnreserved(int byte) =>
      (byte >= 0x41 && byte <= 0x5A) ||
      (byte >= 0x61 && byte <= 0x7A) ||
      (byte >= 0x30 && byte <= 0x39) ||
      byte == 0x2D ||
      byte == 0x2E ||
      byte == 0x5F ||
      byte == 0x7E;

  static bool _isHex(int byte) =>
      (byte >= 0x30 && byte <= 0x39) ||
      (byte >= 0x41 && byte <= 0x46) ||
      (byte >= 0x61 && byte <= 0x66);

  static final Set<int> _safeReserved = r":/?@!$'()*,;".codeUnits.toSet();
}

import 'percent_encoder.dart';

/// A parameter value classified the way RFC 6570 expands it: undefined, a
/// scalar, a list or an object (name-value pairs).
///
/// The input is the JSON form of the value (`toJson` already applied):
/// `null`, [String], [num], [bool], a list of these or a string-keyed map of
/// these. `null` items and entries are skipped; an empty list or map is
/// undefined, like `null`. Anything else is a mistake of the calling code
/// and throws [ArgumentError].
sealed class ParameterValue {
  const ParameterValue();

  /// Classifies [value].
  factory ParameterValue.of(Object? value) => switch (value) {
    null => const UndefinedValue(),
    final List<Object?> list => _items(list),
    final Map<String, Object?> map => _pairs(map),
    _ => ScalarValue(text(value)),
  };

  /// Expands the value of the parameter [name] per RFC 6570:
  /// [first] starts a defined value, [separator] joins exploded items,
  /// [delimiter] joins items that are not exploded, [named] adds `name=`,
  /// [ifEmpty] follows the name of an empty scalar. Undefined gives `''`.
  String expand(
    String name, {
    required PercentEncoder encoder,
    required bool explode,
    required bool named,
    String first = '',
    String separator = ',',
    String delimiter = ',',
    String ifEmpty = '',
  });

  /// The text of a scalar JSON value.
  static String text(Object? value) => switch (value) {
    final String text => text,
    final bool flag => '$flag',
    final num number when number.isFinite => '$number',
    _ => throw ArgumentError.value(
      value,
      'value',
      'Not a finite JSON scalar; convert parameter values with toJson',
    ),
  };

  static ParameterValue _items(List<Object?> list) {
    final items = [
      for (final item in list)
        if (item != null) text(item),
    ];
    return items.isEmpty ? const UndefinedValue() : ListValue(items);
  }

  static ParameterValue _pairs(Map<String, Object?> map) {
    final pairs = [
      for (final MapEntry(:key, :value) in map.entries)
        if (value != null) (key, text(value)),
    ];
    return pairs.isEmpty ? const UndefinedValue() : ObjectValue(pairs);
  }
}

/// `null`, an empty list or an empty object: the parameter is not sent.
final class UndefinedValue extends ParameterValue {
  /// Creates an undefined value.
  const UndefinedValue();

  @override
  String expand(
    String name, {
    required PercentEncoder encoder,
    required bool explode,
    required bool named,
    String first = '',
    String separator = ',',
    String delimiter = ',',
    String ifEmpty = '',
  }) => '';
}

/// A string, number or boolean.
final class ScalarValue extends ParameterValue {
  /// Creates a scalar with its [text].
  const ScalarValue(this.text);

  /// The text of the value.
  final String text;

  @override
  String expand(
    String name, {
    required PercentEncoder encoder,
    required bool explode,
    required bool named,
    String first = '',
    String separator = ',',
    String delimiter = ',',
    String ifEmpty = '',
  }) {
    final value = encoder.encode(text);
    if (!named) return '$first$value';
    final key = PercentEncoder.unreserved.encode(name);
    return text.isEmpty ? '$first$key$ifEmpty' : '$first$key=$value';
  }
}

/// A list of scalars.
final class ListValue extends ParameterValue {
  /// Creates a list of item texts.
  const ListValue(this.items);

  /// The texts of the items.
  final List<String> items;

  @override
  String expand(
    String name, {
    required PercentEncoder encoder,
    required bool explode,
    required bool named,
    String first = '',
    String separator = ',',
    String delimiter = ',',
    String ifEmpty = '',
  }) {
    final key = PercentEncoder.unreserved.encode(name);
    final values = items.map(encoder.encode);
    if (explode) {
      final parts = named ? values.map((v) => '$key=$v') : values;
      return '$first${parts.join(separator)}';
    }
    final joined = values.join(delimiter);
    return named ? '$first$key=$joined' : '$first$joined';
  }
}

/// An object: name-value pairs in map order.
final class ObjectValue extends ParameterValue {
  /// Creates an object of property name and text pairs.
  const ObjectValue(this.pairs);

  /// The property names and the texts of their values.
  final List<(String, String)> pairs;

  @override
  String expand(
    String name, {
    required PercentEncoder encoder,
    required bool explode,
    required bool named,
    String first = '',
    String separator = ',',
    String delimiter = ',',
    String ifEmpty = '',
  }) {
    if (explode) {
      final parts = [
        for (final (key, value) in pairs)
          '${encoder.encode(key)}=${encoder.encode(value)}',
      ];
      return '$first${parts.join(separator)}';
    }
    final joined = [
      for (final (key, value) in pairs) ...[
        encoder.encode(key),
        encoder.encode(value),
      ],
    ].join(delimiter);
    if (!named) return '$first$joined';
    return '$first${PercentEncoder.unreserved.encode(name)}=$joined';
  }
}

/// The `style` of a path parameter.
enum PathStyle {
  /// `blue`, `blue,black`, `R,100,G,200` (explode: `R=100,G=200`).
  simple,

  /// `.blue`, `.blue,black` (explode: `.blue.black`).
  label,

  /// `;color=blue`, `;color=blue,black` (explode: `;color=blue;color=black`).
  matrix,
}

/// The `style` of a query parameter.
enum QueryStyle {
  /// `color=blue`, `color=blue&color=black` (no explode: `color=blue,black`).
  form,

  /// Arrays joined by spaces: `color=blue%20black`.
  spaceDelimited,

  /// Arrays joined by pipes: `color=blue%7Cblack`.
  pipeDelimited,

  /// Objects as `color%5BR%5D=100&color%5BG%5D=200` (`color[R]=100`).
  deepObject,
}

/// A path parameter: its value replaces `{name}` in the path template.
///
/// Values are the JSON form of the parameter (`toJson` applied): a scalar, a
/// list or a string-keyed map. `null` and empty lists and maps are
/// undefined and expand to `''`. Every character but the unreserved ones is
/// percent-encoded, so a value cannot add path segments.
final class PathParameter {
  /// Creates a path parameter; OAS defaults are `simple` without explode.
  const PathParameter(
    this.name,
    this.value, {
    this.style = .simple,
    this.explode = false,
  });

  /// The name in the path template.
  final String name;

  /// The JSON form of the value.
  final Object? value;

  /// The serialization style.
  final PathStyle style;

  /// Whether lists and objects are exploded.
  final bool explode;

  /// The text that replaces `{name}`.
  String encode() {
    final value = ParameterValue.of(this.value);
    return switch (style) {
      .simple => value.expand(
        name,
        encoder: .unreserved,
        explode: explode,
        named: false,
      ),
      .label => value.expand(
        name,
        encoder: .unreserved,
        explode: explode,
        named: false,
        first: '.',
        separator: '.',
      ),
      .matrix => value.expand(
        name,
        encoder: .unreserved,
        explode: explode,
        named: true,
        first: ';',
        separator: ';',
      ),
    };
  }
}

/// A query parameter.
///
/// Values are the JSON form of the parameter, as for [PathParameter];
/// undefined values are not sent. Names and values are percent-encoded;
/// [allowReserved] keeps the reserved characters that are safe in a query.
final class QueryParameter {
  /// Creates a query parameter. OAS defaults: `form`; explode for `form`
  /// only.
  const QueryParameter(
    this.name,
    this.value, {
    this.style = .form,
    bool? explode,
    this.allowReserved = false,
  }) : explode = explode ?? style == .form;

  /// The parameter name.
  final String name;

  /// The JSON form of the value.
  final Object? value;

  /// The serialization style.
  final QueryStyle style;

  /// Whether lists and objects are exploded.
  final bool explode;

  /// Whether reserved characters are sent without percent-encoding.
  final bool allowReserved;

  /// The `name=value` pairs joined by `&`, or `''` when the value is
  /// undefined.
  String encode() {
    final value = ParameterValue.of(this.value);
    final PercentEncoder encoder = allowReserved ? .reserved : .unreserved;
    if (style == .deepObject) return _deepObject(value, encoder);
    return value.expand(
      name,
      encoder: encoder,
      explode: explode,
      named: true,
      separator: '&',
      delimiter: switch (style) {
        .spaceDelimited => '%20',
        .pipeDelimited => '%7C',
        _ => ',',
      },
      ifEmpty: '=',
    );
  }

  String _deepObject(ParameterValue value, PercentEncoder encoder) {
    final key = PercentEncoder.unreserved.encode(name);
    return switch (value) {
      UndefinedValue() => '',
      ObjectValue(:final pairs) => [
        for (final (property, text) in pairs)
          '$key%5B${PercentEncoder.unreserved.encode(property)}%5D='
              '${encoder.encode(text)}',
      ].join('&'),
      _ => throw ArgumentError.value(
        this.value,
        name,
        'deepObject serializes objects only',
      ),
    };
  }
}

///
/// The request sender puts it into `RequestOptions.extra` under
/// [extraKey], so interceptors can tell operations apart
/// (`OperationInfo.of(options)?.operationId`).

  /// Describes one operation.
  const OperationInfo({
    required this.operationId,
    required this.method,
    required this.pathTemplate,
    this.tags = const [],
  });

  /// The key of this object in the `extra` map of a request.
  static const String extraKey = 'typed_openapi.operation';

  /// The `operationId` of the spec, or the name the generator gave the
  /// operation.
  final String operationId;

  /// The HTTP method in upper case.
  final String method;

  /// The path as the spec writes it, such as `/pets/{petId}`.
  final String pathTemplate;

  /// The tags of the operation in spec order.
  final List<String> tags;

  /// The operation of a request, or `null` for a request a generated
  /// client did not send.
  static OperationInfo? of(RequestOptions options) =>
      switch (options.extra[extraKey]) {
        final OperationInfo info => info,
        _ => null,
      };

  @override
  String toString() => '$method $pathTemplate ($operationId)';
}

/// One call of an operation, independent of the HTTP client: the operation,
/// its parameters in spec order and the body.
final class OperationRequest {
  /// Creates a request of [operation].
  const OperationRequest(
    this.operation, {
    this.path = const [],
    this.query = const [],
    this.headers = const [],
    this.cookies = const [],
    this.body,
    this.contentType,
    this.responseKind = .json,
    this.streamStatuses = const {},
  });

  /// The operation being called.
  final OperationInfo operation;

  /// The values of the `{name}` placeholders of the path template.
  final List<PathParameter> path;

  /// The query parameters, sent in this order.
  final List<QueryParameter> query;

  /// The header parameters, sent in this order.
  final List<HeaderParameter> headers;

  /// The cookie parameters, sent in one `Cookie` header in this order.
  final List<CookieParameter> cookies;

  /// The body as the HTTP client sends it: a JSON value (`toJson()`), form
  /// text, bytes; `null` for no body.
  final Object? body;

  /// The `Content-Type` of [body].
  final String? contentType;

  /// How the response body is read.
  final ResponseKind responseKind;

  /// For an event-stream operation, the documented success statuses whose
  /// body is the stream; `DioRequestSender.openEvents` opens the stream for
  /// these only and decodes any other status like a normal response.
  final Set<int> streamStatuses;

  /// The path template with the path parameters substituted and the query
  /// string appended, relative to the base URL of the HTTP client.
  ///
  /// A placeholder without a parameter is a mistake of the calling code and
  /// throws [ArgumentError].
  String resolvePath() {
    final values = {for (final p in path) p.name: p};
    final resolved = operation.pathTemplate.replaceAllMapped(
      _placeholder,
      (match) {
        final name = match[1]!;
        final parameter = values[name];
        if (parameter == null) {
          throw ArgumentError.value(
            operation.pathTemplate,
            'pathTemplate',
            'No value for {$name}',
          );
        }
        return parameter.encode();
      },
    );
    final queryString = [
      for (final q in query) q.encode(),
    ].where((part) => part.isNotEmpty).join('&');
    return queryString.isEmpty ? resolved : '$resolved?$queryString';
  }

  /// The header parameters with a defined value and the `Cookie` header, in
  /// order.
  Map<String, String> resolveHeaders() {
    final cookie = [
      for (final c in cookies) ?c.encode(),
    ].join('; ');
    return {
      for (final h in headers) h.name: ?h.encode(),
      if (cookie.isNotEmpty) 'Cookie': cookie,
    };
  }

  static final RegExp _placeholder = RegExp(r'\{([^{}]+)\}');
}

import 'dart:convert';
import 'dart:typed_data';

import '../json/json_decode_exception.dart';
import '../json/json_reader.dart';

/// A response before decoding, independent of how it was received: what a
/// generated decoder switches on.
///
/// ```dart
/// (response) => switch (response.statusCode) {
///   200 => response.success(Pet.fromJson(response.jsonObject)),
///   404 => response.error(NotFound.fromJson(response.jsonObject)),
///   _ => response.undocumented(),
/// }
/// ```
final class RawResponse {
  /// Creates a response.
  const RawResponse({
    required this.statusCode,
    this.body,
    this.headers = const {},
  });

  /// The HTTP status code.
  final int statusCode;

  /// The body as the HTTP client returned it: JSON parsed by Dio, a
  /// [String], bytes ([Uint8List]) or `null`.
  final Object? body;

  /// The response headers, names in lower case.
  final Map<String, List<String>> headers;

  /// The body as parsed JSON. Nothing is parsed or converted here: a server
  /// that answers a JSON operation with `text/plain` gives a [String], which
  /// a decoder that expects an object rejects. Nesting deeper than
  /// [JsonReader.maxDepth] throws [JsonDecodeException].
  Object? get json {
    JsonReader.checkDepth(body);
    return body;
  }

  /// The body as a JSON object; anything else throws [JsonDecodeException].
  Map<String, Object?> get jsonObject => JsonReader.asObject(json);

  /// The body of a text operation; no body is `''`.
  String get text => switch (body) {
    null => '',
    final String text => text,
    final other => throw JsonDecodeException(
      expected: 'a text body',
      actual: JsonDecodeException.describe(other),
    ),
  };

  /// The body of a binary operation; no body is empty.
  Uint8List get bytes => switch (body) {
    null => Uint8List(0),
    final Uint8List bytes => bytes,
    final other => throw JsonDecodeException(
      expected: 'a binary body',
      actual: JsonDecodeException.describe(other),
    ),
  };

  /// A success with the decoded [data].
  Result<T, E> success<T, E>(T data) =>
      Success(data, statusCode: statusCode, headers: headers);

  /// A documented error with the decoded [body].
  Result<T, E> error<T, E>(E body) =>
      HttpError(body, statusCode: statusCode, headers: headers);

  /// A status the operation does not document; the body is kept as is.
  Result<T, E> undocumented<T, E>() => UndocumentedStatus(
    statusCode: statusCode,
    rawBody: body,
    headers: headers,
  );

  /// Parses a body the HTTP client did not parse (an error body of a
  /// streaming operation): JSON when [headers] name a JSON content type,
  /// UTF-8 text otherwise, `null` when empty. Text that is not JSON throws
  /// [JsonDecodeException].
  static Object? parse(Uint8List bytes, Map<String, List<String>> headers) {
    if (bytes.isEmpty) return null;
    final text = utf8.decode(bytes, allowMalformed: true);
    if (!isJson(headers)) return text;
    try {
      return jsonDecode(text);
    } on FormatException {
      throw JsonDecodeException(
        expected: 'a JSON body',
        actual: 'text that is not JSON',
      );
    }
  }

  /// Whether [headers] name a JSON content type (`application/json`,
  /// `text/json`, `*/*+json`), as Dio decides.
  static bool isJson(Map<String, List<String>> headers) {
    final type = headers['content-type']?.firstOrNull
        ?.split(';')
        .first
        .trim()
        .toLowerCase();
    return type != null &&
        (type == 'application/json' ||
            type == 'text/json' ||
            type.endsWith('+json'));
  }
}

/// implement them). Base URL, timeouts and retries belong to the user's
/// Dio and its interceptors.
final class CallOptions {
  /// Creates per-call options.
  const CallOptions({
    this.cancelToken,
    this.headers = const {},
    this.extra = const {},
    this.onSendProgress,
    this.onReceiveProgress,
  });

  /// Cancels the request; the operation then returns `Cancelled`.
  final CancelToken? cancelToken;

  /// Headers added to the request; they win over the headers the operation
  /// sends for its header parameters.
  final Map<String, Object?> headers;

  /// Data for interceptors, merged into `RequestOptions.extra`.
  final Map<String, Object?> extra;

  /// Reports sent bytes.
  final ProgressCallback? onSendProgress;

  /// Reports received bytes.
  final ProgressCallback? onReceiveProgress;

/// Sends an [OperationRequest] through the user's [Dio] and turns every
/// outcome into a [Result].
///
/// - The Dio instance is never changed: no `baseUrl`, interceptor,
///   transformer or `validateStatus` is set, and nothing is retried.
///   Requests go through `dio.request`, which merges the instance
///   `BaseOptions` (base URL, headers, timeouts).
/// - The path and the query string are encoded here and passed to Dio as
///   one finished path: interceptors see an empty `queryParameters`.
/// - HTTP errors take Dio's usual path: `validateStatus` decides, error
///   statuses reach the `onError` of interceptors, and only then is the
///   response decoded here. An interceptor may resolve an error into a
///   response of any status, so the decoder always switches on the status.
/// - Cancellation is [Cancelled], other Dio failures are [TransportError],
///   a body the decoder rejects with [JsonDecodeException] is
///   [DecodeError]. Nothing else is caught: errors of the program
///   (`TypeError`, `StateError`) reach the caller.
final class DioRequestSender {
  /// Sends requests through [dio].
  const DioRequestSender(this.dio);

  /// The user's Dio instance.
  final Dio dio;

  /// Sends [request] and decodes the response of any status with [decode].
  Future<Result<T, E>> send<T, E>(
    OperationRequest request,
    Result<T, E> Function(RawResponse response) decode, {
    CallOptions? call,
  }) async {
    final Response<Object?> response;
    try {
      response = await _request(request, call);
    } on DioException catch (e, stackTrace) {
      final failed = e.response;
      if (e.type == .badResponse && failed != null) {
        return _decode(_raw(failed, failed.data), decode);
      }
      return _failure(e, stackTrace);
    }
    return _decode(_raw(response, response.data), decode);
  }

  Future<Response<Object?>> _request(
    OperationRequest request,
    CallOptions? call,
  ) {
    final path = request.resolvePath();
    final options = Options(
      method: request.operation.method,
      headers: {...request.resolveHeaders(), ...?call?.headers},
      extra: {...?call?.extra, OperationInfo.extraKey: request.operation},
      contentType: request.contentType,
      responseType: switch (request.responseKind) {
        .json => .json,
        .text => .plain,
        .bytes => .bytes,
      },
    );
    // The type argument picks how Dio reads the body: Dio forces JSON for
    // any type but String and List<int> with bytes.
    Future<Response<R>> send<R>() => dio.request<R>(
      path,
      data: request.body,
      options: options,
      cancelToken: call?.cancelToken,
      onSendProgress: call?.onSendProgress,
      onReceiveProgress: call?.onReceiveProgress,
    );
    return switch (request.responseKind) {
      .json => send<Object?>(),
      .text => send<String>(),
      .bytes => send<List<int>>(),
    };
  }

  /// A response without a status (only a faulty interceptor builds one)
  /// gets status 0, which no operation documents.
  static RawResponse _raw(Response<Object?> response, Object? body) =>
      RawResponse(
        statusCode: response.statusCode ?? 0,
        body: body,
        headers: response.headers.map,
      );

  static Result<T, E> _decode<T, E>(
    RawResponse raw,
    Result<T, E> Function(RawResponse response) decode,
  ) {
    try {
      return decode(raw);
    } on JsonDecodeException catch (e) {
      return DecodeError(
        e,
        statusCode: raw.statusCode,
        rawBody: raw.body,
        headers: raw.headers,
      );
    }
  }

  /// A failure without a response. Dio drops the response when its JSON
  /// parser fails (`unknown` with a [FormatException]): a decode error
  /// without a status, whose raw body is the text the parser reported (for
  /// a body Dio read in chunks, only the chunk that failed).
  static Failure<T, E> _failure<T, E>(
    DioException e,
    StackTrace stackTrace,
  ) => switch (e) {
    DioException(type: .cancel) => Cancelled(e, stackTrace),
    DioException(
      type: .unknown,
      response: null,
      error: FormatException(:final source),
    ) =>
      DecodeError(
        JsonDecodeException(
          expected: 'a JSON body',
          actual: 'text that is not JSON',
        ),
        rawBody: switch (source) {
          final List<int> bytes => utf8.decode(bytes, allowMalformed: true),
          final other => other,
        },
      ),
    _ => TransportError(e, stackTrace),
  };
}

import 'dart:convert';

import '../json/json_decode_exception.dart';
import '../json/json_reader.dart';

/// One event of a `text/event-stream` body before its data is decoded, as
/// the WHATWG event stream format dispatches it.
final class SseMessage {
  /// Creates a message.
  const SseMessage({
    required this.data,
    this.event = 'message',
    this.id = '',
    this.retry,
  });

  /// The `event` field, or `message` when the event has none.
  final String event;

  /// The `data` lines joined by `\n`.
  final String data;

  /// The last `id` seen in the stream so far (it persists across events);
  /// `''` when there was none or an empty `id` reset it. A reconnect sends
  /// it as `Last-Event-ID`.
  final String id;

  /// The last valid `retry` seen in the stream so far: the reconnection
  /// time the server asks for, or `null`.
  final Duration? retry;

  /// [data] parsed as JSON; text that is not JSON, or nesting deeper than
  /// [JsonReader.maxDepth], throws [JsonDecodeException].
  Object? get json {
    final Object? value;
    try {
      value = jsonDecode(data);
    } on FormatException {
      throw JsonDecodeException(
        expected: 'JSON event data',
        actual: 'text that is not JSON',
      );
    }
    JsonReader.checkDepth(value);
    return value;
  }

  /// [data] as a JSON object; anything else throws [JsonDecodeException].
  Map<String, Object?> get jsonObject => JsonReader.asObject(json);

  @override
  bool operator ==(Object other) =>
      other is SseMessage &&
      other.event == event &&
      other.data == data &&
      other.id == id &&
      other.retry == retry;

  @override
  int get hashCode => Object.hash(event, data, id, retry);

  @override
  String toString() =>
      'SseMessage(event: $event, data: $data, id: $id, retry: $retry)';
}

```dart
import 'dart:async';
import 'dart:convert';

import 'sse_message.dart';

/// Decodes a `text/event-stream` body into [SseMessage]s, following the
/// WHATWG HTML "Interpreting an event stream" rules. Generated code uses
/// it through `SseItemDecoder`.
///
/// - Bytes are UTF-8 (invalid sequences become U+FFFD, a leading BOM is
///   dropped); a character split between chunks is kept whole.
/// - Lines end with CRLF, LF or CR, also when CR and LF arrive in different
///   chunks.
/// - `event`, `data` (several lines joined by `\n`), `id` (ignored when it
///   contains U+0000) and `retry` (ASCII digits only, otherwise ignored);
///   lines starting with `:` are comments; other fields are ignored.
/// - An empty line dispatches the event unless no `data` was seen; an event
///   not finished by an empty line when the stream ends is discarded.
///
/// Malformed input never throws; errors of the source stream pass through.
final class SseDecoder extends StreamTransformerBase<List<int>, SseMessage> {
  /// Creates a decoder; each bound stream gets its own state.
  const SseDecoder();

  @override
  Stream<SseMessage> bind(Stream<List<int>> stream) => Stream.eventTransformed(
    // bind, not stream.transform: a Stream<Uint8List> (what Dio gives) does
    // not accept a transformer of List<int> at run time.
    const Utf8Decoder(allowMalformed: true).bind(stream),
    _SseSink.new,
  );
}

/// The parser state of one stream.
final class _SseSink implements EventSink<String> {
  _SseSink(this._out);

  final EventSink<SseMessage> _out;
  final StringBuffer _line = StringBuffer();
  final StringBuffer _data = StringBuffer();
  bool _started = false;
  bool _afterCr = false;
  bool _hasData = false;
  String _eventType = '';
  String _lastEventId = '';
  Duration? _retry;

  @override
  void add(String chunk) {
    var start = 0;
    if (!_started && chunk.isNotEmpty) {
      _started = true;
      if (chunk.codeUnitAt(0) == 0xFEFF) start = 1;
    }
    for (var i = start; i < chunk.length; i++) {
      final unit = chunk.codeUnitAt(i);
      if (unit == 0x0A && _afterCr) {
        _afterCr = false;
        start = i + 1;
      } else if (unit == 0x0A || unit == 0x0D) {
        _line.write(chunk.substring(start, i));
        _endLine();
        start = i + 1;
        _afterCr = unit == 0x0D;
      } else {
        _afterCr = false;
      }
    }
    _line.write(chunk.substring(start));
  }

  @override
  void addError(Object error, [StackTrace? stackTrace]) =>
      _out.addError(error, stackTrace);

  @override
  void close() => _out.close();

  void _endLine() {
    final line = _line.toString();
    _line.clear();
    if (line.isEmpty) return _dispatch();
    if (line.startsWith(':')) return;
    final colon = line.indexOf(':');
    final field = colon < 0 ? line : line.substring(0, colon);
    var value = colon < 0 ? '' : line.substring(colon + 1);
    if (value.startsWith(' ')) value = value.substring(1);
    switch (field) {
      case 'event':
        _eventType = value;
      case 'data':
        _data
          ..write(value)
          ..write('\n');
        _hasData = true;
      case 'id' when !value.contains('\u0000'):
        _lastEventId = value;
      case 'retry' when _digits.hasMatch(value):
        if (int.tryParse(value) case final millis?) {
          _retry = Duration(milliseconds: millis);
        }
    }
  }

  void _dispatch() {
    if (!_hasData) {
      _eventType = '';
      return;
    }
    final data = _data.toString();
    _out.add(
      SseMessage(
        event: _eventType.isEmpty ? 'message' : _eventType,
        data: data.substring(0, data.length - 1),
        id: _lastEventId,
        retry: _retry,
      ),
    );
    _data.clear();
    _hasData = false;
    _eventType = '';
  }

  static final RegExp _digits = RegExp(r'^[0-9]+$');
}

````dart
import '../json/json_decode_exception.dart';
import 'sse_message.dart';

/// One item of an open event stream: an [SseEvent], an [SseDecodeError]
/// for one event that did not decode (the stream goes on), or
/// [SseDisconnected], always the last item. The stream never emits errors.
///
/// ```dart
/// await for (final item in events) {
///   switch (item) {
///     case SseEvent(:final data): show(data);
///     case SseDecodeError(:final error): log(error);
///     case SseDisconnected(): break;
///   }
/// }
/// ```
sealed class SseItem<T> {
  const SseItem();
}

/// An event whose data decoded as [T].
final class SseEvent<T> extends SseItem<T> {
  /// Creates an event.
  const SseEvent(this.data, {this.event = 'message', this.id = '', this.retry});

  /// The decoded data.
  final T data;

  /// The `event` field, or `message`.
  final String event;

  /// The last event id seen in the stream so far, or `''`.
  final String id;

  /// The last reconnection time the server asked for, or `null`.
  final Duration? retry;

  @override
  String toString() => 'SseEvent($event, id: $id)';
}

/// An event whose data does not match its schema; later events still come.
final class SseDecodeError<T> extends SseItem<T> {
  /// Creates a decode error for [message].
  const SseDecodeError(this.error, this.message);

  /// What did not match and where.
  final JsonDecodeException error;

  /// The event as received.
  final SseMessage message;

  @override
  String toString() => 'SseDecodeError(${message.event}: $error)';
}

/// The end of the stream: the server closed it ([cause] is `null`) or the
/// connection failed ([cause] is the error, usually a `DioException`, also
/// for a cancelled request). Always the last item.
final class SseDisconnected<T> extends SseItem<T> {
  /// Creates the last item.
  const SseDisconnected({this.cause, this.stackTrace});

  /// Why the stream ended, or `null` when the server closed it.
  final Object? cause;

  /// Where [cause] was raised.
  final StackTrace? stackTrace;

  @override
  String toString() => 'SseDisconnected(${cause ?? 'closed by server'})';
}

```dart
import 'dart:async';

import '../json/json_decode_exception.dart';
import 'sse_decoder.dart';
import 'sse_item.dart';
import 'sse_message.dart';

/// Decodes a `text/event-stream` body into [SseItem]s: each message goes
/// through [decode] (a generated function, usually over
/// [SseMessage.jsonObject]); a [JsonDecodeException] becomes an
/// [SseDecodeError] and the stream goes on. The end of the body, or its
/// first error, becomes [SseDisconnected] and closes the stream, so the
/// stream never emits errors. Cancelling the subscription cancels the body.
final class SseItemDecoder<T>
    extends StreamTransformerBase<List<int>, SseItem<T>> {
  /// Creates a decoder whose events [decode] reads.
  const SseItemDecoder(this.decode);

  /// Reads the data of one event.
  final T Function(SseMessage message) decode;

  @override
  Stream<SseItem<T>> bind(Stream<List<int>> stream) {
    StreamSubscription<SseMessage>? source;
    late final StreamController<SseItem<T>> items;
    void end(SseDisconnected<T> last) {
      items
        ..add(last)
        ..close();
    }

    items = StreamController<SseItem<T>>(
      onListen: () {
        source = const SseDecoder()
            .bind(stream)
            .listen(
              (message) => items.add(_item(message)),
              onError: (Object error, StackTrace stackTrace) {
                end(SseDisconnected(cause: error, stackTrace: stackTrace));
              },
              onDone: () => end(const SseDisconnected()),
              cancelOnError: true,
            );
      },
      onPause: () => source?.pause(),
      onResume: () => source?.resume(),
      onCancel: () => source?.cancel(),
    );
    return items.stream;
  }

  SseItem<T> _item(SseMessage message) {
    try {
      return SseEvent(
        decode(message),
        event: message.event,
        id: message.id,
        retry: message.retry,
      );
    } on JsonDecodeException catch (e) {
      return SseDecodeError(e, message);
    }
  }
}

```dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:dio/dio.dart';
import 'package:meta/meta.dart';

import '../json/json_decode_exception.dart';
import '../request/operation_info.dart';
import '../request/operation_request.dart';
import '../request/raw_response.dart';
import '../result/result.dart';
import '../sse/sse_item.dart';
import '../sse/sse_item_decoder.dart';
import '../sse/sse_message.dart';
import 'call_options.dart';

/// Sends an [OperationRequest] through the user's [Dio] and turns every
/// outcome into a [Result].
///
/// - The Dio instance is never changed: no `baseUrl`, interceptor,
///   transformer or `validateStatus` is set, and nothing is retried.
///   Requests go through `dio.request`, which merges the instance
///   `BaseOptions` (base URL, headers, timeouts).
/// - The path and the query string are encoded here and passed to Dio as
///   one finished path: interceptors see an empty `queryParameters`.
/// - HTTP errors take Dio's usual path: `validateStatus` decides, error
///   statuses reach the `onError` of interceptors, and only then is the
///   response decoded here. An interceptor may resolve an error into a
///   response of any status, so the decoder always switches on the status.
/// - Cancellation is [Cancelled], other Dio failures are [TransportError],
///   a body the decoder rejects with [JsonDecodeException] is
///   [DecodeError]. Nothing else is caught: errors of the program
///   (`TypeError`, `StateError`) reach the caller.
final class DioRequestSender {
  /// Sends requests through [dio].
  const DioRequestSender(this.dio) : _isWeb = _webPlatform;

  /// Sends requests through [dio] as if the platform were the web or not.
  @visibleForTesting
  const DioRequestSender.forPlatform(this.dio, {required bool isWeb})
    : _isWeb = isWeb;

  /// The user's Dio instance.
  final Dio dio;

  final bool _isWeb;

  /// Sends [request] and decodes the response of any status with [decode].
  Future<Result<T, E>> send<T, E>(
    OperationRequest request,
    Result<T, E> Function(RawResponse response) decode, {
    CallOptions? call,
  }) async {
    final Response<Object?> response;
    try {
      response = await _request(request, call);
    } on DioException catch (e, stackTrace) {
      final failed = e.response;
      if (e.type == .badResponse && failed != null) {
        return _decode(_raw(failed, failed.data), decode);
      }
      return _failure(e, stackTrace);
    }
    return _decode(_raw(response, response.data), decode);
  }

  /// Opens a `text/event-stream` operation. A status in
  /// [OperationRequest.streamStatuses] gives a [Success] whose stream reads
  /// every event with [decodeEvent]; any other status reads the whole body
  /// and decodes it with [decodeError] (which returns a documented error or
  /// an undocumented status). On the web, with Dio's default
  /// adapter, the result is a [TransportError] that explains how to get a
  /// streaming adapter: the default adapter delivers the body only when the
  /// connection closes.
  Future<Result<Stream<SseItem<T>>, E>> openEvents<T, E>(
    OperationRequest request,
    T Function(SseMessage message) decodeEvent,
    Result<Stream<SseItem<T>>, E> Function(RawResponse response) decodeError, {
    CallOptions? call,
  }) async {
    if (_isWeb && _hasDefaultAdapter) {
      final exception = DioException(
        requestOptions: RequestOptions(
          path: request.resolvePath(),
          method: request.operation.method,
          extra: {OperationInfo.extraKey: request.operation},
        ),
        error: UnsupportedError(webStreamingMessage),
        message: webStreamingMessage,
      );
      return TransportError(exception, StackTrace.current);
    }
    final Response<Object?> response;
    try {
      response = await _request(request, call, events: true);
    } on DioException catch (e, stackTrace) {
      final failed = e.response;
      if (e.type == .badResponse && failed != null) {
        return _openFailed(failed, decodeError);
      }
      return _failure(e, stackTrace);
    }
    final status = response.statusCode ?? 0;
    final body = response.data;
    if (request.streamStatuses.contains(status) && body is ResponseBody) {
      return Success(
        SseItemDecoder<T>(decodeEvent).bind(body.stream),
        statusCode: status,
        headers: response.headers.map,
      );
    }
    return _openFailed(response, decodeError);
  }

  /// Explains why server-sent events cannot stream on the web with the
  /// default Dio adapter.
  static const String webStreamingMessage =
      'Server-sent events need a streaming HTTP adapter on the web: Dio\'s '
      'default browser adapter delivers the body only when the connection '
      'closes. Set a fetch-based adapter on your Dio, such as '
      'ConversionLayerAdapter from package:dio_compatibility_layer with '
      'package:http\'s BrowserClient or package:fetch_client.';

  bool get _hasDefaultAdapter =>
      dio.httpClientAdapter.runtimeType == HttpClientAdapter().runtimeType;

  Future<Response<Object?>> _request(
    OperationRequest request,
    CallOptions? call, {
    bool events = false,
  }) {
    final path = request.resolvePath();
    final options = Options(
      method: request.operation.method,
      headers: {
        if (events) 'Accept': 'text/event-stream',
        ...request.resolveHeaders(),
        ...?call?.headers,
      },
      extra: {...?call?.extra, OperationInfo.extraKey: request.operation},
      contentType: request.contentType,
      responseType: events
          ? .stream
          : switch (request.responseKind) {
              .json => .json,
              .text => .plain,
              .bytes => .bytes,
            },
    );
    // The type argument picks how Dio reads the body: Dio forces JSON for
    // any type but String, List<int> with bytes or ResponseBody with stream.
    Future<Response<R>> send<R>() => dio.request<R>(
      path,
      data: request.body,
      options: options,
      cancelToken: call?.cancelToken,
      onSendProgress: call?.onSendProgress,
      onReceiveProgress: call?.onReceiveProgress,
    );
    if (events) return send<ResponseBody>();
    return switch (request.responseKind) {
      .json => send<Object?>(),
      .text => send<String>(),
      .bytes => send<List<int>>(),
    };
  }

  /// A response without a status (only a faulty interceptor builds one)
  /// gets status 0, which no operation documents.
  static RawResponse _raw(Response<Object?> response, Object? body) =>
      RawResponse(
        statusCode: response.statusCode ?? 0,
        body: body,
        headers: response.headers.map,
      );

  static Result<T, E> _decode<T, E>(
    RawResponse raw,
    Result<T, E> Function(RawResponse response) decode,
  ) {
    try {
      return decode(raw);
    } on JsonDecodeException catch (e) {
      return DecodeError(
        e,
        statusCode: raw.statusCode,
        rawBody: raw.body,
        headers: raw.headers,
      );
    }
  }

  /// Reads the whole body of an event-stream response that did not open,
  /// parses it (JSON by content type) and decodes it with [decodeError].
  static Future<Result<Stream<SseItem<T>>, E>> _openFailed<T, E>(
    Response<Object?> response,
    Result<Stream<SseItem<T>>, E> Function(RawResponse response) decodeError,
  ) async {
    final headers = response.headers.map;
    final Uint8List bytes;
    try {
      bytes = switch (response.data) {
        final ResponseBody body => await _readAll(body.stream),
        _ => Uint8List(0),
      };
    } on DioException catch (e, stackTrace) {
      return _failure(e, stackTrace);
    }
    final Object? body;
    try {
      body = RawResponse.parse(bytes, headers);
    } on JsonDecodeException catch (e) {
      return DecodeError(
        e,
        statusCode: response.statusCode,
        rawBody: utf8.decode(bytes, allowMalformed: true),
        headers: headers,
      );
    }
    return _decode(_raw(response, body), decodeError);
  }

  static Future<Uint8List> _readAll(Stream<List<int>> stream) async {
    final bytes = BytesBuilder(copy: false);
    await stream.forEach(bytes.add);
    return bytes.takeBytes();
  }

  /// A failure without a response. Dio drops the response when its JSON
  /// parser fails (`unknown` with a [FormatException]): a decode error
  /// without a status, whose raw body is the text the parser reported (for
  /// a body Dio read in chunks, only the chunk that failed).
  static Failure<T, E> _failure<T, E>(
    DioException e,
    StackTrace stackTrace,
  ) => switch (e) {
    DioException(type: .cancel) => Cancelled(e, stackTrace),
    DioException(
      type: .unknown,
      response: null,
      error: FormatException(:final source),
    ) =>
      DecodeError(
        JsonDecodeException(
          expected: 'a JSON body',
          actual: 'text that is not JSON',
        ),
        rawBody: switch (source) {
          final List<int> bytes => utf8.decode(bytes, allowMalformed: true),
          final other => other,
        },
      ),
    _ => TransportError(e, stackTrace),
  };

  static const bool _webPlatform = bool.fromEnvironment(
    'dart.library.js_interop',
  );
}

# typed_openapi_runtime

Runtime support for clients generated by
[`typed_openapi`](../typed_openapi/README.md): the only package generated
code depends on. Dependencies: `dio` and `meta`.

> **Status:** in development, not published yet.

## Contents

- `Result<T, E>`: every generated method returns one; nothing is thrown for
  expected problems. Read it with pattern matching:

  ```dart
  switch (await api.pets.getPetById(petId: 1)) {
    case Success(:final data): show(data);
    case HttpError(:final body): showError(body);          // documented 4xx/5xx
    case DecodeError(:final error): log(error.pointer);    // body does not match
    case UndocumentedStatus() || TransportError() || Cancelled(): retryLater();
  }
  ```

- `Patch<T>` for three-state request fields: a `Patch<T>?` field that is
  `null` is not sent, `.nullValue()` sends `null`, `.value(x)` sends `x`.
- `JsonReader` for generated `fromJson`: strict decoding (the only widening
  is an integer where a number is expected) that throws
  `JsonDecodeException` with the JSON pointer, the expected and the actual
  JSON type of the first mismatch. `JsonValue` holds any JSON value.
- Parameter encoders for the OpenAPI styles (`simple`, `label`, `matrix`,
  `form`, `spaceDelimited`, `pipeDelimited`, `deepObject`, headers,
  cookies) with RFC 3986 percent-encoding.
- `DioRequestSender`: sends a request through your `Dio` and types the
  outcome. `CallOptions` carries the per-call cancel token, headers,
  `extra` and progress callbacks.
- An event stream (`text/event-stream`) decoder following WHATWG; an open
  stream yields `SseEvent`, `SseDecodeError` (one bad event) and, last,
  `SseDisconnected`. It never emits errors.

## Your Dio is used as is

- Nothing on your `Dio` is changed: base URL, headers, timeouts,
  interceptors, transformer and `validateStatus` stay yours. Nothing is
  retried: that is the job of your interceptors.
- Error statuses go through your interceptors' `onError` before they are
  typed.
- Every request carries its `OperationInfo` (operation id, method, path
  template, tags): `OperationInfo.of(options)` in an interceptor.
- The path and the query string are encoded by the runtime and passed to
  Dio as one path, so `options.queryParameters` is empty in interceptors;
  read `options.uri` instead.

## Notes

- `Result` has the same name as `Result` in `package:async`. In a library
  that imports both, hide one (`import 'package:async/async.dart' hide
  Result;`) or import one with a prefix.
- JSON is parsed by Dio. When the body is not valid JSON, Dio drops the
  response, so the `DecodeError` has no `statusCode`, and its `rawBody` is
  the text Dio's parser reported: the whole body when Dio read it at once,
  only the failing chunk when Dio streamed it (a `Content-Length` header was
  present).
- A `date-time` must be RFC 3339 with an offset. For a server that sends
  another format, map the format to your own type with a converter
  (`types.formats`) or override the property's `format`.

## Web

Everything works on the web except event streams with Dio's default
browser adapter, which delivers a body only when the connection closes. An
event-stream operation then returns a `TransportError` that says so. Set a
fetch-based adapter on your Dio, such as `ConversionLayerAdapter` from
`dio_compatibility_layer` with `package:http`'s `BrowserClient` or
`fetch_client`.

- `Result` збігається з `Result` з `package:async`. У бібліотеці, що
  імпортує обидва, сховай один (`import 'package:async/async.dart' hide
  Result;`) або імпортуй один із префіксом.
- JSON розбирає Dio. Коли тіло — невалідний JSON, Dio відкидає відповідь,
  тож `DecodeError` не має `statusCode`, а його `rawBody` — текст, який
  повідомив парсер Dio: усе тіло, коли Dio прочитав його одразу, і лише
  чанк із помилкою, коли Dio його стрімив (був заголовок `Content-Length`).
- `date-time` має бути RFC 3339 зі зсувом. Для сервера, що пише інший
  формат, зістав формат зі своїм типом через конвертер (`types.formats`) або
  перевизнач `format` властивості в override-і.

## Web

На web працює все, крім потоків подій зі стандартним браузерним адаптером
Dio, який віддає тіло лише після закриття з'єднання. Операція з потоком
подій тоді повертає `TransportError` з поясненням. Постав у свій Dio
адаптер на fetch, наприклад `ConversionLayerAdapter` з
`dio_compatibility_layer` з `BrowserClient` з `package:http` або
