# Plan M6: semantic IR and Dart mapping

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `typed_openapi check` builds, for each client, an immutable semantic IR — models, enums, unions, operation groups with parameters, bodies, responses and errors, already with Dart names and types — and reports naming, mapping and filter problems; the M8/M9 emitters will only print this IR.

**Architecture:** A new layer `lib/src/ir/`. IR nodes (`ir.dart`, `dart_type.dart`) refer to declarations through `DeclId` (the schema's location + a variant: the schema itself, the request model, the PATCH body model), and the names are given by one global pass at the end (`names.dart`: `DartNames`, `NameScope`). `IrBuilder` selects operations (`OperationSelector`: the config filters, `exclude`), groups them and names the methods; `DirectionIndex` collects the directions in which schemas are used; `OperationBuilder` maps parameters, bodies, responses and errors through `SchemaMapper`, which creates declarations on demand (tree-shaking) and at the end gives names with collision diagnostics. The settings are `GenerationConfig` in the client's config; the generation fields of the M4 overrides are `IrOverrides`. `SpecChecker` builds the IR after the normalizer; the hidden `ir` command prints it as JSON (`IrJson`).

**Tech Stack:** Dart `>=3.10.0 <4.0.0`, pure Dart, no new dependencies; tests on `package:test`.

**Spec:** [docs/superpowers/specs/2026-10-12-m6-ir-design.md](../specs/2026-10-12-m6-ir-design.md) — decisions 1–12. Requirements: R4, R5, R6.1–R6.4, R6.8, R7.2 ([requirements.md](../../requirements.md)); R11.4 and `errors.default_schema` — for the error type of an operation. Research: [research/README](../../research/README.md) §3.H (the lesson "a global pass over `Map<JsonPointer, String>`"), §7.5 (architecture), §7.7 (representation), [research/07](../../research/07-dart-building-blocks.md) §C. Runtime names — from [the M7 design](../specs/2026-10-12-m7-runtime-design.md) (`Patch`, `JsonValue`, `Result`, `CallOptions`, `Date`). Carried over: [roadmap](../../roadmap.md), rows "Carried over from M2/M3/M4" marked M6. Code rules — [CLAUDE.md](../../../CLAUDE.md).

## Accepted decisions

The decisions of the M6 spec are binding. These are the technical decisions that the spec leaves to the plan. The decisions about format and behaviour that the user sees were confirmed by the user after the first version of the plan (section "User decisions" at the end; numbers — the questions of the first version).

1. **Declaration identity — `DeclId` (the schema's location + `DeclVariant`: `base`, `input`, `patch`); names — in a separate pass.** Types refer to `DeclId`, and a name appears only in `SchemaMapper.declarations(scope)`. So a rename (a collision, an override `name`) does not touch the types, and an inline name `<Parent><Property>` takes the parent's already final name (`ListModel` → `ListModelTags`). This is the "global pass over `Map<JsonPointer, String>`" from research §3.H.
2. **The IR is visible to the user and to the tests through JSON.** `IrJson` writes deterministic JSON (a fixed key order, `file#pointer` for locations); the hidden command `typed_openapi ir [client...]` prints it. Why: before M8/M9 the user would otherwise not see how the generator names types and methods, and the overrides `name`/`group`/`dartType` are written for exactly these names; the tests compare structure, not lines of code. The command is hidden (`hidden: true`) and its format is unstable — it is a debugging tool, not a contract; `check` remains the only contract of the report. The alternative "a `check --dump-ir` flag" would mix the report and the dump in one stdout (and would break `--format json`).
3. **M6 codes are in the second half of the hundred of their area** (TOA x50–x99), because the first half of each hundred belongs to the normalizer rules of M3: schemas TOA250–TOA254, enum TOA350, polymorphism TOA450–TOA451, operations and naming TOA550–TOA558. The areas follow the table of research §1 (2xx schemas, 3xx enums, 4xx polymorphism, 5xx operations and naming). 6xx (media types and errors) and 7xx (output stability) have not been needed yet.
4. **Declarations are created on demand.** `SchemaMapper` creates a declaration when a selected operation first maps the schema, so tree-shaking (R4.2) is a property of the mapper, not a separate pass. A structural component schema (an array, a map, a scalar) has no declaration: each use gets its type (`Tags: {type: array, items: string}` → `List<String>`); its own type for it is `types.schemas`/`dartType`.
5. **Interpretation rules are applied in the mapper, not by editing the spec.** An `allOf` with one part, a `oneOf`/`anyOf` with one non-null branch, a `const` — the same for components and inline; a model or a reference is determined from the schema after the overrides and the M3 rules.
6. **Directions are counted before mapping** (`DirectionIndex`), because the decision to split a schema depends on all of its uses; a model used in one direction has no fields of the other (a response without `writeOnly`, a request without `readOnly`) — this is OAS semantics, not a heuristic.
7. **The PATCH body model is decided before mapping** (`DirectionIndex.separatesPatch`: the schema of a PATCH body that is also used elsewhere) and is marked while the body is mapped (`typeOf(…, patchBody: true)`); fields are computed when the model is built, so the order of operations does not change the result.
8. **Generation overrides — only the applied ones.** `IrOverrides` takes the targets that the M4 `OverrideResolver` finds on the model of the last pass (with a silent `DiagnosticBag`: the normalizer has already reported everything); entries with TOA804–TOA806 have no target and do not affect the IR (carried over from M4). A Path Item level parameter, addressed through one operation, changes the argument's name/type in all operations of the path (TOA808 already says so).
9. **The errors of an operation are computed from the IR responses** (`ErrorsIr`): `NoErrors` = `E = Never` (M7, decision 3), one schema — `SingleError`, different ones — `ErrorsByStatus`; a status without a body — `errors.default_schema`. How `ErrorsByStatus` becomes a sealed type — M9.
10. **The envelope is fixed in the IR, not in the config.** `ResponseIr.envelopeKey = 'data'` and type `T` for each successful JSON response `{data: T}`; the "generic wrapper" mode (spec, decision 8) and its config key — M9 (the user's decision, item 10); the IR for it is the same.
11. **An operation with an unbound path variable is not generated** (TOA556, error): the call could not fill in the URL. An operation written as a `$ref` (the normalizer's TOA107) is skipped silently — it has already been reported.
12. **The corpus is part of the definition of "done":** the IR is built for all 14 clients without exception; the three defects it found are fixed in task 9 with regression tests.

The IR does not know Dart syntax, but it already has Dart names and types (spec, decision 1). Types refer to declarations through `DeclId` (the schema's location + `DeclVariant`: `base`, `input` — the request model of a split schema, `patch` — the PATCH body model of a schema that is also used elsewhere), not through a name: the name is given by one global naming pass at the end (the research lesson "`Map<JsonPointer, String>`"), so a name collision or an override does not touch the types. `JsonValue` is never nullable (M7, decision 10). `FieldIr.type` implements the R6.1 matrix: tri-state — `Patch<T>?`, required — the value's type (nullable if the schema allows `null`), optional — nullable. `ClientIr` sorts declarations and groups by name, `GroupIr` — operations by name: determinism (R13.1) is built into the nodes themselves. `IrJson` — a dump for tests and for the user (see decision 2).

final class IrJson {

  const IrJson(this._fileOf);

  final String Function(Uri document) _fileOf;

  /// [ir] as indented JSON text.
  String encode(ClientIr ir) =>
      const JsonEncoder.withIndent('  ').convert(toJson(ir));

  /// [ir] as plain JSON values.
  Map<String, Object?> toJson(ClientIr ir) {
    String type(DartType t) => t.code(ir.nameOf);
    return {
      'declarations': [
        for (final d in ir.declarations) _declaration(d, type),
      ],
      'groups': [
        for (final group in ir.groups)
          {
            'name': group.name,
            'operations': [
              for (final operation in group.operations)
                _operation(operation, type),
            ],
          },
      ],
    };
  }

  String _at(SpecLocation location) =>
      '${_fileOf(location.document)}${location.pointer.value}';

  Map<String, Object?> _declaration(
    Declaration d,
    String Function(DartType) type,
  ) => {
    'name': d.name,
    'at': _at(d.location),
    if (d.deprecated) 'deprecated': true,
    ...switch (d) {
      ModelDecl() => {
        'kind': 'model',
        if (d.id.variant != .base) 'variant': d.id.variant.name,
        if (d.direction != .both) 'direction': d.direction.name,

          for (final f in d.fields)

              'json': f.jsonKey,
              'type': type(f.type),
              if (f.required) 'required': true,
              if (f.triState) 'triState': true,
              if (f.readOnly) 'readOnly': true,
              if (f.writeOnly) 'writeOnly': true,
            },
        ],
        if (d.additionalProperties case final extra?)
          'additionalProperties': type(extra),
      },
      EnumDecl() => {
        'kind': 'enum',

              'type': type(v.type),

/// Turns names from a spec into Dart identifiers (R5).
///
/// A name is split into words at characters that are not ASCII letters or
/// digits and at case changes (`petId`, `HTTPServer`, `user_dto`); words
/// keep their case except the first letter, so `UserDTO` stays `UserDTO`.
/// Nothing is shortened or added by heuristics.
final class DartNames {
  /// Creates the converter.
  const DartNames();

  static final _separators = RegExp('[^A-Za-z0-9]+');
  static final _word = RegExp(
    '[A-Z]+(?=[A-Z][a-z])|[A-Z]?[a-z]+|[A-Z]+|[0-9]+',
  );

  /// Dart reserved words: never an identifier.
  static const reservedWords = {
    'assert', 'break', 'case', 'catch', 'class', 'const', 'continue', //
    'default', 'do', 'else', 'enum', 'extends', 'false', 'final',
    'finally', 'for', 'if', 'in', 'is', 'new', 'null', 'rethrow', 'return',
    'super', 'switch', 'this', 'throw', 'true', 'try', 'var', 'void',
    'while', 'with',
    // Not reserved, but not usable inside async methods and generators.
    'await', 'yield',
  };

  /// Built-in identifiers: usable as members, not as type names.
  static const builtInIdentifiers = {
    'abstract', 'as', 'covariant', 'deferred', 'dynamic', 'export', //
    'extension', 'external', 'factory', 'Function', 'get', 'implements',
    'import', 'interface', 'late', 'library', 'mixin', 'operator', 'part',
    'required', 'set', 'static', 'typedef',
  };

  /// Type names a generated library sees without importing them: those of
  /// `dart:core`, `Uint8List` of `dart:typed_data`, and the names of
  /// `typed_openapi_runtime` that generated code uses.
  static const takenTypeNames = {
    // dart:core
    'ArgumentError', 'AssertionError', 'BigInt', 'BidirectionalIterator',
    'Comparable', 'Comparator', 'ConcurrentModificationError', 'DateTime',
    'Deprecated', 'Duration', 'Enum', 'Error', 'Exception', 'Expando',
    'Finalizer', 'FormatException', 'Function', 'Future', 'IndexError',
    'IntegerDivisionByZeroException', 'Invocation', 'Iterable', 'Iterator',
    'LateError', 'List', 'Map', 'MapEntry', 'Match', 'Never',
    'NoSuchMethodError', 'Null', 'Object', 'OutOfMemoryError', 'Pattern',
    'RangeError', 'Record', 'RegExp', 'RegExpMatch', 'Runes', 'Set', 'Sink',
    'StackOverflowError', 'StackTrace', 'StateError', 'Stopwatch', 'Stream',
    'String', 'StringBuffer', 'StringSink', 'Symbol', 'Type', 'TypeError',
    'UnimplementedError', 'UnsupportedError', 'Uri', 'WeakReference', 'bool',
    'double', 'int', 'num', 'Uint8List',
    // typed_openapi_runtime
    'CallOptions', 'Cancelled', 'CookieParameter', 'Date', 'DecodeError',
    'DioRequestSender', 'Failure', 'HeaderParameter', 'HttpError',
    'JsonDecodeException', 'JsonReader', 'JsonValue', 'OperationInfo',
    'OperationRequest', 'Patch', 'PatchNull', 'PatchValue', 'PathParameter',
    'QueryParameter', 'RawResponse', 'ResponseKind', 'Result', 'SseDecoder',
    'SseDecodeError', 'SseDisconnected', 'SseEvent', 'SseItem',
    'SseItemDecoder', 'SseMessage', 'Success', 'TransportError',
    'UndocumentedStatus',
  };

  /// Members every Dart object has, and the members generated models,
  /// enums and API classes add.
  static const objectMembers = {
    'hashCode', 'noSuchMethod', 'runtimeType', 'toString', //
  };

  /// Members a model's fields must not shadow.
  static const modelMembers = {
    ...objectMembers,
    'copyWith',
    'fromJson',
    'toJson',
  };

  /// Members an enum's values must not shadow.
  static const enumMembers = {
    ...objectMembers, 'fromJson', 'index', 'name', 'toJson', 'value', //
    'values',
  };

  /// Names of a method's arguments that generated code uses itself: the
  /// request body and the per-call options of the runtime.
  static const argumentNames = {'body', 'call'};

  /// The words of [text], in order; empty when it has no ASCII letter or
  /// digit.
  List<String> words(String text) => [
    for (final part in text.split(_separators))
      for (final match in _word.allMatches(part)) match[0]!,
  ];

  /// [text] as an UpperCamelCase type name, or null when it has no ASCII
  /// letter or digit. A name that starts with a digit gets a `$`.
  String? pascal(String text) {
    final parts = words(text);
    if (parts.isEmpty) return null;
    return _leading(parts.map(_capitalize).join());
  }

  /// [text] as a lowerCamelCase member name, or null when it has no ASCII
  /// letter or digit. A name that starts with a digit gets a `$`.
  String? camel(String text) {
    final parts = words(text);
    if (parts.isEmpty) return null;
    return _leading(
      [parts.first.toLowerCase(), ...parts.skip(1).map(_capitalize)].join(),
    );
  }

  static String _capitalize(String word) =>
      word[0].toUpperCase() + word.substring(1);

  static String _leading(String name) =>
      name.startsWith(RegExp('[0-9]')) ? '\$$name' : name;
}

/// Why [NameScope.claim] did not give the candidate itself.
enum NameChange {
  /// The candidate is a reserved word or a name Dart already has.
  reserved,

  /// Another declaration of the scope already has the candidate.
  collision,
}

/// The names of one scope (a library's types, a class's members, a
/// method's arguments), given out in the order they are claimed.
///
/// Callers claim in a deterministic order (by spec location), so the same
/// spec always gives the same names.
final class NameScope {
  /// Creates a scope where [reserved] names get [reservedSuffix].
  NameScope({required Set<String> reserved, required this.reservedSuffix})
    : _reserved = reserved;

  final Set<String> _reserved;
  final Set<String> _taken = {};

  /// What a reserved name gets appended: `Model` for types, `_` for
  /// members.
  final String reservedSuffix;

  /// Whether [name] is given out.
  bool isTaken(String name) => _taken.contains(name);

  /// Gives out [candidate], or a free name made from it: with
  /// [reservedSuffix] when it is reserved, then the first free of
  /// [alternatives], then with `2`, `3`, ... appended. Returns the name and
  /// why it differs from [candidate], if it does.
  (String, NameChange?) claim(
    String candidate, {
    List<String> alternatives = const [],
  }) {
    if (_reserved.contains(candidate)) {
      final name = _free('$candidate$reservedSuffix');
      return (name, .reserved);
    }
    if (_taken.add(candidate)) return (candidate, null);
    for (final alternative in alternatives) {
      if (!_reserved.contains(alternative) && _taken.add(alternative)) {
        return (alternative, .collision);
      }
    }
    return (_free(candidate), .collision);
  }

  String _free(String base) {
    if (_taken.add(base)) return base;
    for (var i = 2; ; i++) {
      if (_taken.add('$base$i')) return '$base$i';
    }
  }
}

A structural component schema (an array, a map, a scalar) has no declaration; one that refers to itself — TOA251 and `JsonValue`. A mix of types — TOA250, an enum with values of different types — TOA350, both → `JsonValue` with a warning. An `exclude` override of a property removes the field. /// How an inline schema's declaration is named (R5.4): after its parent
/// declaration or a fixed prefix (an operation), followed by [suffix].
final class NameHint {
  /// A name made of [prefix] and [suffix], such as `CreatePet` + `Request`.
  const NameHint(String this.prefix, this.suffix) : _parent = null;

  const NameHint._under(_Pending this._parent, this.suffix) : prefix = null;

  /// The fixed start of the name, when there is no parent declaration.
  final String? prefix;

  /// The end of the name, such as a property name in UpperCamelCase.
  final String suffix;

  final _Pending? _parent;
}

/// Maps schemas to Dart types and collects the declarations they need
/// (R6.1–R6.3, R6.8).
///
/// Declarations are created when a schema is first mapped, so only schemas
/// reachable from what is mapped are generated (R4.2). Names are given at
/// the end ([declarations]): component schemas keep their key, inline
/// schemas are named after their parent, and collisions get a suffix with a
/// diagnostic (R5.2).
final class SchemaMapper {
  /// Creates a mapper for the spec of [_context].
  SchemaMapper(this._context);

  static const _names = DartNames();
  static const _fallbackName = 'Schema';

  final IrContext _context;
  final Map<DeclId, _Pending> _pending = {};
  final Map<String, _Pending> _inlineEnums = {};
  final Set<SpecLocation> _aliases = {};

  /// The type of [schema]; an inline declaration it needs is named by
  /// [hint].
  DartType typeOf(Schema schema, NameHint hint) => _map(schema, hint);

  /// The type of the `components.schemas` entry [schema], as a `$ref` to it
  /// would have.
  DartType typeOfComponent(Schema schema) =>
      switch (_context.model.resolveSchema(schema)) {
        final SchemaObject target => _component(target),
        _ => const CoreType(.json),
      };

  /// The declarations created so far, named in [scope]: overridden names
  /// first, then component keys, then inline names, each by location.
  List<Declaration> declarations(NameScope scope) {
    final ordered = _pending.values.toList()
      ..sort((a, b) {
        final byRank = a.rank.compareTo(b.rank);
        if (byRank != 0) return byRank;
        final byDepth = a.depth.compareTo(b.depth);
        if (byDepth != 0) return byDepth;
        return a.id.compareTo(b.id);
      });
    for (final pending in ordered) {
      pending.name = _claim(scope, pending);
    }
    return [for (final pending in ordered) pending.build!(pending.name!)];
  }

  String _claim(NameScope scope, _Pending pending) {
    final overridden = pending.overrideName;
    final String? candidate;
    if (overridden != null) {
      candidate = overridden;
    } else if (pending.componentKey case final key?) {
      candidate = _names.pascal(key);
    } else {
      final parent = pending.hint!._parent?.name ?? pending.hint!.prefix!;
      candidate = '$parent${pending.hint!.suffix}';
    }
    if (candidate == null) {
      final (name, _) = scope.claim(_fallbackName);
      _context.report(
        .nameUnrepresentable,
        'Schema "${pending.componentKey}" has no ASCII letter or digit, so '
        'its type is named "$name".',
        pending.id.location,
        fix: 'Rename the schema at the source, or name its type.',
        override: _context.schemaOverride(pending.id.location, {'name': name}),
      );
      return name;
    }
    final (name, change) = scope.claim(candidate);
    if (change != null) {
      _context.report(
        change == .reserved ? .nameReserved : .nameCollision,
        change == .reserved
            ? '"$candidate" is a name Dart already has; the type is named '
                  '"$name".'
            : 'Another type is named "$candidate"; this one is named '
                  '"$name".',
        pending.id.location,
        fix: 'Name the type explicitly to keep the name stable.',
        override: _context.schemaOverride(pending.id.location, {'name': name}),
      );
    }
    return name;
  }

  DartType _map(Schema schema, NameHint hint) {
    if (schema is BooleanSchema) return const CoreType(.json);
    final object = schema as SchemaObject;
    if (object.ref != null) {
      final target = _context.model.resolveSchema(object);
      // A broken `$ref` is reported by the resolver (TOA101).
      if (target is! SchemaObject) return const CoreType(.json);
      final type = _component(target);
      return type.withNullable(type.nullable || _isNullable(object));
    }
    return _inline(object, hint);
  }

  /// The type of a schema a `$ref` points to.
  DartType _component(SchemaObject schema) {
    final custom = _customSchemaType(schema);
    if (custom != null) return custom;
    final id = DeclId(schema.location);
    final pending = _pending[id];
    if (pending != null) return NamedType(id, nullable: _isNullable(schema));
    final key = _componentKey(schema.location);
    if (_declares(schema)) {
      return _declare(
        schema,
        id,
        (p) => p
          ..componentKey = key
          ..overrideName = _context.overrides.schemaAt(schema.location)?.name,
      );
    }
    // A structural schema (array, map, scalar) has no declaration of its
    // own: each use gets its type. One that refers back to itself cannot be
    // spelled out.
    if (!_aliases.add(schema.location)) {
      _context.report(
        .recursiveAlias,
        'This schema refers to itself without an object between; the '
        'reference is generated as JsonValue.',
        schema.location,
        fix: 'Make the recursive part an object schema at the source.',
      );
      return const CoreType(.json);
    }
    try {
      return _structural(
        schema,
        NameHint(_names.pascal(key ?? '') ?? _fallbackName, ''),
      );
    } finally {
      _aliases.remove(schema.location);
    }
  }

  DartType _inline(SchemaObject schema, NameHint hint) {
    if (_declares(schema)) {
      if (_enumValues(schema) case final values?) {
        final kind = _enumKind(schema, values);
        if (kind != null) {
          final key = '${kind.name}:${values.join('\u0000')}';
          final known = _inlineEnums[key];
          if (known != null) {
            return NamedType(known.id, nullable: _isNullable(schema));
          }
        }
      }
      return _declare(schema, DeclId(schema.location), (p) => p.hint = hint);
    }
    return _structural(schema, hint);
  }

  /// Whether [schema] gets a declaration: an object with properties or an
  /// enum.
  bool _declares(SchemaObject schema) =>
      _enumValues(schema) != null || schema.properties.isNotEmpty;

  DartType _declare(
    SchemaObject schema,
    DeclId id,
    void Function(_Pending) setUp,
  ) {
    final values = _enumValues(schema);
    final kind = values == null ? null : _enumKind(schema, values);
    if (values != null && kind == null) {
      _context.report(
        .enumMixedValues,
        'The values of this enum are not all strings, all numbers or all '
        'booleans; it is generated as JsonValue.',
        schema.location,
        fix: 'Give the enum values of one JSON type at the source.',
      );
      return const CoreType(.json);
    }
    final pending = _Pending(id);
    setUp(pending);
    final parent = pending.hint?._parent;
    pending.depth = parent == null ? 0 : parent.depth + 1;
    _pending[id] = pending;
    if (values != null && kind != null) {
      _enum(schema, pending, values, kind);
    } else {
      _model(schema, pending);
    }
    return NamedType(id, nullable: _isNullable(schema));
  }

  void _model(SchemaObject schema, _Pending pending) {
    final fields = <_Field>[];
    for (final MapEntry(key: json, value: property)
        in schema.properties.entries) {
      final override = _context.overrides.propertyAt(property.location);
      if (override?.exclude ?? false) continue;
      final resolved = _resolved(property);
      final suffix = _names.pascal(json) ?? 'Field';
      final custom = override?.dartType;
      final mapped = _map(property, NameHint._under(pending, suffix));
      fields.add(
        _Field(
          json: json,
          override: override,
          location: property.location,
          valueType: custom == null ? mapped : _custom(custom, mapped),
          required: schema.required.contains(json),
          readOnly: resolved?.readOnly ?? false,
          writeOnly: resolved?.writeOnly ?? false,
          defaultValue: resolved?.defaultValue,
          description: resolved?.description,
          deprecated: resolved?.deprecated ?? false,
        ),
      );
    }
    final extra = schema.additionalProperties;
    final additional = extra == null || extra is BooleanSchema
        ? null
        : _map(extra, NameHint._under(pending, 'Value'));
    pending.build = (name) {
      final scope = NameScope(
        reserved: {...DartNames.reservedWords, ...DartNames.modelMembers},
        reservedSuffix: '_',
      );
      return ModelDecl(
        id: pending.id,
        name: name,
        description: schema.description,
        deprecated: schema.deprecated,
        additionalProperties: additional,
        fields: [
          for (final field in fields)
            FieldIr(
              name: _memberName(
                scope,
                field.json,
                field.override?.name,
                field.location,
                owner: name,
              ),
              jsonKey: field.json,
              valueType: field.valueType,
              location: field.location,
              required: field.required,
              triState: field.override?.triState ?? false,
              readOnly: field.readOnly,
              writeOnly: field.writeOnly,
              defaultValue: field.defaultValue,
              description: field.description,
              deprecated: field.deprecated,
            ),
        ],
      );
    };
  }

  /// The Dart name of the member [json] of the type [owner], from [named]
  /// (an override) or [json].
  String _memberName(
    NameScope scope,
    String json,
    String? named,
    SpecLocation location, {
    required String owner,
  }) {
    final candidate = named ?? _names.camel(json);
    if (candidate == null) {
      final (name, _) = scope.claim('field');
      _context.report(
        .nameUnrepresentable,
        'Property "$json" of $owner has no ASCII letter or digit, so its '
        'field is named "$name".',
        location,
        fix: 'Name the field explicitly.',
        override: _context.schemaOverride(location, {'name': name}),
      );
      return name;
    }
    final (name, change) = scope.claim(candidate);
    if (change != null) {
      _context.report(
        change == .reserved ? .nameReserved : .nameCollision,
        change == .reserved
            ? 'Property "$json" of $owner would be the Dart name '
                  '"$candidate"; its field is named "$name".'
            : 'Another field of $owner is named "$candidate"; the field of '
                  '"$json" is named "$name".',
        location,
        fix: 'Name the field explicitly to keep the name stable.',
        override: _context.schemaOverride(location, {'name': name}),
      );
    }
    return name;
  }

  void _enum(
    SchemaObject schema,
    _Pending pending,
    List<Object?> values,
    EnumKind kind,
  ) {
    if (pending.componentKey == null) {
      _inlineEnums['${kind.name}:${values.join('\u0000')}'] = pending;
    }
    final names = switch (schema.extensions['x-enum-varnames']) {
      final List<Object?> given
          when given.length == values.length &&
              given.every((n) => n is String) =>
        given.cast<String>(),
      _ => null,
    };
    final descriptions = switch (schema.extensions['x-enum-descriptions']) {
      final List<Object?> given when given.length == values.length => given,
      _ => null,
    };
    final exhaustive =
        _context.overrides.schemaAt(schema.location)?.exhaustive ?? true;
    pending.build = (name) {
      final scope = NameScope(
        reserved: {...DartNames.reservedWords, ...DartNames.enumMembers},
        reservedSuffix: '_',
      );
      return EnumDecl(
        id: pending.id,
        name: name,
        kind: kind,
        exhaustive: exhaustive,
        description: schema.description,
        deprecated: schema.deprecated,
        values: [
          for (final (i, value) in values.indexed)
            EnumValueIr(
              _valueName(scope, names?[i], value!, schema.location, name),
              value,
              description: switch (descriptions?[i]) {
                final String text => text,
                _ => null,
              },
            ),
        ],
      );
    };
  }

  String _valueName(
    NameScope scope,
    String? named,
    Object value,
    SpecLocation location,
    String owner,
  ) {
    final candidate =
        (named == null ? null : _names.camel(named)) ??
        switch (value) {
          final num number =>
            'value${number < 0 ? 'Minus' : ''}'
                '${'${number.abs()}'.replaceAll('.', '_')}',
          _ => _names.camel('$value'),
        };
    final (name, change) = scope.claim(candidate ?? 'value');
    if (candidate == null || change != null) {
      _context.report(
        candidate == null
            ? .nameUnrepresentable
            : change == .reserved
            ? .nameReserved
            : .nameCollision,
        'Value "$value" of enum $owner is named "$name".',
        location,
        fix: 'Name the values with x-enum-varnames at the source.',
      );
    }
    return name;
  }

  /// The non-null values of an enum (`enum`, or `const` as a one-value
  /// enum), or null when [schema] is not one.
  static List<Object?>? _enumValues(SchemaObject schema) {
    final values = [
      ...?schema.enumValues,
      if (schema.enumValues == null) ?schema.constValue?.$1,
    ];
    final nonNull = [for (final v in values) ?v];
    return nonNull.isEmpty ? null : nonNull;
  }

  static EnumKind? _enumKind(SchemaObject schema, List<Object?> values) {
    if (values.every((v) => v is String)) return .string;
    if (values.every((v) => v is bool)) return .boolean;
    if (values.every((v) => v is int)) {
      return schema.types.contains(SchemaType.number) ? .number : .integer;
    }
    if (values.every((v) => v is num)) return .number;
    return null;
  }

  /// The type of a schema without a declaration: a scalar, a list or a
  /// map.
  DartType _structural(SchemaObject schema, NameHint hint) {
    final nullable = _isNullable(schema);
    final types = [
      for (final type in schema.types)
        if (type != SchemaType.nullType) type,
    ];
    if (types.length > 1) {
      _context.report(
        .mixedTypeSchema,
        'This schema allows ${types.map((t) => t.wire).join(', ')}; it is '
        'generated as JsonValue.',
        schema.location,
        fix:
            'Give the schema one type at the source, or a Dart type with an '
            'override.',
        override: _context.schemaOverride(schema.location, {
          'dartType': {'type': 'MyType', 'import': 'package:app/my_type.dart'},
        }),
      );
      return const CoreType(.json);
    }
    final type =
        types.firstOrNull ??
        (schema.items != null
            ? SchemaType.array
            : schema.additionalProperties != null
            ? SchemaType.object
            : null);
    final DartType base = switch (type) {
      null || SchemaType.nullType => const CoreType(.json),
      .integer => const CoreType(.integer),

///
/// Operations are grouped (R5.3) and named (R5.1); their parameters,
/// bodies and responses are mapped to types, which creates the
/// declarations they reach (R4.2); then declarations and groups are named
/// in one library scope (R5.2). Problems go to the [DiagnosticBag] given to
/// the constructor; nothing is thrown for any spec.
final class IrBuilder {
  /// Creates a builder that reports to [_diagnostics].
  const IrBuilder(this._diagnostics);

  static const _names = DartNames();

  /// The `operationId` prefix the `nestjs` preset removes:
  /// `UserController_get` → `get`.

  static final _variable = RegExp(r'\{([^}]*)\}');

  /// The IR of [spec] generated as [client] says.
  ClientIr build(NormalizedSpec spec, ClientConfig client) {
    final context = IrContext(_diagnostics, spec, client);
    final mapper = SchemaMapper(context);
    final operations = OperationBuilder(context, mapper);
    final groups = <String, List<SpecOperation>>{};
    final groupSites = <String, SpecLocation>{};

        ...DartNames.builtInIdentifiers,
        ...DartNames.takenTypeNames,

      reservedSuffix: 'Model',
    );

  /// The operations of `paths`, by location, with `additionalOperations`
  /// (OpenAPI 3.2). A path item shared through `$ref` gives its operations
  /// to every path that uses it.
  static List<SpecOperation> _operations(IrContext context) {
    final result = <SpecOperation>[];
    for (final MapEntry(key: path, :value)
        in context.model.document.paths.entries) {
      final item = context.model.resolve(value);
      if (item == null) continue;
      for (final MapEntry(key: method, value: operation) in [
        ...item.operations.entries,
        ...item.additionalOperations.entries,
      ]) {
        result.add(SpecOperation(operation, method, path, item));
      }
    }
    return result..sort((a, b) {
      final byPath = a.path.compareTo(b.path);
      if (byPath != 0) return byPath;
      return a.method.compareTo(b.method);
    });
  }

  /// The group of [entry] before the class name template: an override's
  /// `group`, else by `group_by`. [reportUntagged] reports an operation
  /// without a tag.
  static String _group(
    IrContext context,
    SpecOperation entry,
    Map<String, String> tagOfGroup, {
    required bool reportUntagged,
  }) {
    final operation = entry.operation;
    final override = context.overrides.operationAt(operation.location)?.group;
    if (override != null) return _names.pascal(override) ?? override;
    final config = context.config;
    switch (config.groupBy) {
      case .single:
        return '';
      case .path:
        final segment = entry.path
            .split('/')

              orElse: () => '',

            '${config.defaultGroup}.',
            operation.location,

            override: context.overrideAt(

    }

    String group,
    SpecLocation site,
  ) {

    if (change != null) {

                  'named "$name".',

        fix: 'Change naming.group in the config, or rename the schema.',
      );
    }
    return name;
  }

  /// the words of every path segment without its variables, then, when the
  /// path has variables, `By` and the variables in path order joined by
  /// `And`: `GET /users/{userId}/posts/{postId}` gives
  /// `getUsersPostsByUserIdAndPostId`, `GET /pets/{id}` gives
  /// `getPetsById`.
  static String _pathName(String method, String path) {
    final variables = <String>[];
    final literal = path.replaceAllMapped(_variable, (match) {
      variables.add(match[1]!);
      return ' ';
    });
    if (variables.isEmpty) return '$method $literal';
    return '$method $literal By ${variables.join(' And ')}';
  }

  /// override's `name`, else `operationId` without the configured prefix,
  /// else [_pathName], in lowerCamelCase.
  static String _methodName(

    NameScope scope,
  ) {
    final operation = entry.operation;
    final override = context.overrides.operationAt(operation.location)?.name;
    final prefix =
        context.config.operationPrefix ??
        (context.client.preset == .nestjs ? nestjsPrefix : null);
    final id = operation.operationId;
    final source = id == null
        ? _pathName(entry.method, entry.path)
        : prefix == null
        ? id
        : id.replaceFirst(prefix, '');

    final (name, change) = scope.claim(candidate ?? 'operation');
    if (candidate == null || change != null) {
      context.report(
        candidate == null
            ? .nameUnrepresentable
            : change == .reserved
            ? .nameReserved
            : .nameCollision,
        candidate == null
            ? 'operationId "$id" has no ASCII letter or digit; the method is '
                  'named "$name".'
            : change == .reserved
            ? 'Method "$candidate" would be a name Dart already has; it is '
                  'named "$name".'
            : 'Another method of the group is named "$candidate"; this one '
                  'is named "$name".',
        operation.location,
        fix: 'Name the method explicitly to keep the name stable.',
        override: context.overrideAt(
          ['operations', entry.overrideKey],
          {'name': name},
        ),
      );
    }
    return name;
  }

/// An operation of the spec with its method and path.
final class SpecOperation {
  /// Creates the entry for [operation], found at [method] of [path].
  const SpecOperation(this.operation, this.method, this.path, this.item);

  /// The Operation Object.
  final Operation operation;

  /// The HTTP method as the spec writes it: lower case for the fixed
  /// fields, as written for OpenAPI 3.2 `additionalOperations`.
  final String method;

  /// The path template.
  final String path;

  /// The Path Item Object the operation is in.
  final PathItem item;

  /// The key of the operation in the overrides file: its `operationId`, or
  /// `METHOD /path`.
  String get overrideKey =>
      operation.operationId ?? '${method.toUpperCase()} $path';
}

/// Builds the IR of operations: parameters, bodies, responses and errors
/// (R10.3, R10.4, R10.6, R11.4); types come from a [SchemaMapper].
final class OperationBuilder {
  /// Creates a builder that maps types with [_mapper].
  OperationBuilder(this._context, this._mapper);

  static const _names = DartNames();
  static final _variable = RegExp(r'\{([^}]*)\}');

  final IrContext _context;
  final SchemaMapper _mapper;

  /// The IR of [entry], named [name]; null when its path template cannot
  /// be filled.
  OperationIr? build(SpecOperation entry, String name) {
    final operation = entry.operation;
    final prefix = _names.pascal(name) ?? name;
    final parameters = _parameters(entry, prefix);
    if (parameters == null) return null;
    final responses = _responses(operation, prefix);
    return OperationIr(
      location: operation.location,
      name: name,
      method: entry.method.toUpperCase(),
      path: entry.path,
      operationId: operation.operationId,
      tags: operation.tags,
      summary: operation.summary,
      description: operation.description,
      deprecated: operation.deprecated,
      parameters: parameters,
      body: _body(operation, prefix),
      responses: responses,
      errors: _errors(responses),
    );
  }

  List<ParameterIr>? _parameters(SpecOperation entry, String prefix) {
    // Operation parameters replace path item parameters with the same name
    // and location.
    final byKey = <(ParameterLocation?, String?), Parameter>{};
    for (final written in [
      ...entry.item.parameters,
      ...entry.operation.parameters,
    ]) {
      final parameter = _context.model.resolve(written);
      if (parameter == null) continue;
      byKey[(parameter.placement, parameter.name)] = parameter;
    }
    final variables = [
      for (final match in _variable.allMatches(entry.path)) match[1]!,
    ];
    var bound = true;
    for (final variable in variables) {
      if (byKey.containsKey((ParameterLocation.path, variable))) continue;
      bound = false;
      _context.report(
        .pathVariableUnbound,
        'Path variable "{$variable}" of ${entry.path} has no path parameter '
        'with this exact name, so the operation is not generated.',
        entry.operation.location,
        fix: 'Declare a path parameter named "$variable" at the source.',
      );
    }
    if (!bound) return null;
    final scope = NameScope(
      reserved: {...DartNames.reservedWords, ...DartNames.argumentNames},
      reservedSuffix: '_',
    );
    const order = [
      ParameterLocation.path,
      ParameterLocation.query,
      ParameterLocation.querystring,
      ParameterLocation.header,
      ParameterLocation.cookie,
    ];
    final sorted = byKey.values.toList()
      ..sort(
        (a, b) => order.indexOf(a.placement!) - order.indexOf(b.placement!),
      );
    return [
      for (final parameter in sorted)
        if (parameter.name case final wire?)
          _parameter(entry, parameter, wire, scope, prefix),
    ];
  }

  ParameterIr _parameter(
    SpecOperation entry,
    Parameter parameter,
    String wire,
    NameScope scope,
    String prefix,
  ) {
    final placement = parameter.placement!;
    final override = _context.overrides.parameterAt(parameter.location);
    final candidate = override?.name ?? _names.camel(wire) ?? 'param';
    final (name, change) = scope.claim(
      candidate,
      alternatives: ['$candidate${_names.pascal(placement.name)}'],
    );
    if (change != null) {
      _context.report(
        change == .reserved ? .nameReserved : .nameCollision,
        change == .reserved
            ? 'Parameter "$wire" would be the Dart name "$candidate"; the '
                  'argument is named "$name".'
            : 'Another argument of ${entry.overrideKey} is named '
                  '"$candidate"; the argument of ${placement.name} parameter '
                  '"$wire" is named "$name".',
        parameter.location,
        fix: 'Name the argument explicitly to keep the name stable.',
        override: _context.overrideAt(
          [
            'operations',
            entry.overrideKey,
            'parameters',
            '${placement.name}:$wire',
          ],
          {'name': name},
        ),
      );
    }
    final (schema, contentType) = switch (parameter.schema) {
      final schema? => (schema, null),
      null => _content(parameter.content),
    };
    final mapped = schema == null
        ? const CoreType(.json)
        : _mapper.typeOf(schema, NameHint(prefix, _names.pascal(wire) ?? ''));
    final custom = override?.dartType;
    final type = custom == null
        ? mapped
        : CustomType(
            type: custom.type,
            import: custom.import,
            converter: custom.converter,
            json: mapped.withNullable(false),
          );
    final required = placement == .path || parameter.required;
    return ParameterIr(
      name: name,
      wireName: wire,
      placement: placement,
      type: required ? type : type.withNullable(true),
      location: parameter.location,
      required: required,
      style: parameter.style,
      explode: parameter.explode,
      allowReserved: parameter.allowReserved,
      contentType: contentType,
      description: parameter.description,
      deprecated: parameter.deprecated,
    );
  }

  RequestBodyIr? _body(Operation operation, String prefix) {
    final written = operation.requestBody;
    if (written == null) return null;
    final body = _context.model.resolve(written);
    if (body == null) return null;
    final (contentType, media) = _pick(body.content);
    final kind = contentType == null ? BodyKind.none : _kind(contentType);
    final schema = media?.schema;
    return RequestBodyIr(
      kind: kind,
      location: body.location,
      contentType: contentType,
      type: schema == null
          ? null
          : _mapper.typeOf(schema, NameHint(prefix, 'Request')),
      required: body.required,
      description: body.description,
    );
  }

  List<ResponseIr> _responses(Operation operation, String prefix) {
    final responses = [
      for (final MapEntry(key: status, value: written)
          in operation.responses.entries)
        if (_context.model.resolve(written) case final response?)
          (status, response, _pick(response.content)),
    ];
    // Inline names carry the status only when several responses of the
    // same kind (success or error) have a body.
    final withBody = <String, int>{};
    for (final (status, _, (_, media)) in responses) {
      if (media?.schema == null && media?.itemSchema == null) continue;
      final base = _nameBase(status);
      withBody[base] = (withBody[base] ?? 0) + 1;
    }
    final result = <ResponseIr>[];
    for (final (status, response, (contentType, media)) in responses) {
      final kind = contentType == null ? BodyKind.none : _kind(contentType);
      final success = status.startsWith('2');
      final base = _nameBase(status);
      final suffix = (withBody[base] ?? 0) > 1
          ? '$base${status == 'default' ? 'Default' : status.toUpperCase()}'
          : base;
      final schema = kind == .eventStream
          ? media?.itemSchema ?? media?.schema
          : media?.schema;
      final envelope = success && kind == .json && schema != null
          ? _envelope(schema)
          : null;
      final DartType? type = switch ((schema, kind)) {
        (_, .text) => const CoreType(.string),
        (_, .bytes) => const CoreType(.binary),
        (final schema?, _) => _mapper.typeOf(
          envelope ?? schema,
          NameHint(prefix, suffix),
        ),
        _ => null,
      };
      result.add(
        ResponseIr(
          status: status,
          kind: kind,
          location: response.location,
          contentType: contentType,
          type: type,
          envelopeKey: envelope == null ? null : 'data',
          description: response.description,
        ),
      );
    }
    return result;
  }

  /// How inline types of a response with [status] are named: `Response`
  /// for 2xx, `Error` for 4xx, 5xx and `default`, `Response` with the status
  /// for the rest.
  static String _nameBase(String status) {
    if (status.startsWith('2')) return 'Response';
    if (status.startsWith('4') || status.startsWith('5')) return 'Error';
    if (status == 'default') return 'Error';
    return 'Response${status.toUpperCase()}';
  }

  /// The schema of `data` when [schema] is an envelope `{data: T}`: an
  /// object whose only property is the required `data` (R6.4).
  Schema? _envelope(Schema schema) {
    final resolved = _context.model.resolveSchema(schema);
    if (resolved is! SchemaObject) return null;
    final data = resolved.properties['data'];
    if (data == null ||
        resolved.properties.length != 1 ||
        !resolved.required.contains('data') ||
        resolved.allOf.isNotEmpty ||
        resolved.additionalProperties is SchemaObject) {
      return null;
    }
    return data;
  }

  /// The documented errors (R11.4): `Never` without any, the one body
  /// type when all errors share it, else the body type of each status. A
  /// status without a body uses `errors.default_schema` when it is set.
  ErrorsIr _errors(List<ResponseIr> responses) {
    final fallback = _defaultErrorType();
    final cases = [
      for (final response in responses)
        if (response.isError) (response.status, response.type ?? fallback),
    ];
    if (cases.isEmpty) {
      return fallback == null
          ? const NoErrors()
          : SingleError(fallback, const []);
    }
    final types = {for (final (_, type) in cases) type};
    if (types.length == 1 && types.single != null) {
      return SingleError(types.single!, [for (final (s, _) in cases) s]);
    }
    return ErrorsByStatus(cases);
  }

  DartType? _defaultErrorType() {
    final key = _context.config.defaultErrorSchema;
    if (key == null) return null;
    final schema = _context.model.document.components?.schemas[key];
    if (schema == null) return null;
    return _mapper.typeOfComponent(schema);
  }

  /// The media type the client uses: JSON first, then forms, text, event
  /// streams and anything else, each in document order.
  (String?, MediaType?) _pick(Map<String, RefOr<MediaType>> content) {
    if (content.isEmpty) return (null, null);
    const preference = [
      BodyKind.json,
      BodyKind.multipart,
      BodyKind.form,
      BodyKind.text,
      BodyKind.eventStream,
      BodyKind.bytes,
    ];
    for (final kind in preference) {
      for (final MapEntry(key: type, value: written) in content.entries) {
        if (_kind(type) != kind) continue;
        return (type, _context.model.resolve(written));
      }
    }
    return (null, null);
  }

  (Schema?, String?) _content(Map<String, RefOr<MediaType>> content) {
    final (type, media) = _pick(content);
    return (media?.schema, type);
  }

  static BodyKind _kind(String contentType) {
    final type = contentType.split(';').first.trim().toLowerCase();
    if (type == 'application/json' || type.endsWith('+json')) return .json;
    if (type == 'multipart/form-data') return .multipart;
    if (type == 'application/x-www-form-urlencoded') return .form;
    if (type == 'text/event-stream') return .eventStream;
    if (type.startsWith('text/')) return .text;
    return .bytes;
  }
}

/// Where each schema is used, requests or responses, to split models by
/// direction (spec decision 4).
///
/// A schema is split into a response model and a request model when it, or
/// a schema inside it, has a `readOnly` or `writeOnly` property and it is
/// used in both directions. The request body of a PATCH operation is not a
/// use of its schema here: it is recorded apart, and a PATCH body schema
/// that is used anywhere else gets a PATCH model of its own.
final class DirectionIndex {
  /// Creates an index of [_model] with no uses.
  DirectionIndex(this._model);

  final SpecModel _model;
  final Map<SpecLocation, Set<ModelDirection>> _uses = {};
  final Set<(SpecLocation, ModelDirection)> _seen = {};
  final Map<SpecLocation, bool> _directional = {};
  final Set<SpecLocation> _patchBodies = {};

  /// Records the schemas of [operation]'s parameters and request body as
  /// used in requests and those of its responses as used in responses; the
  /// body of a [method] `patch` is a PATCH body.
  void addOperation(Operation operation, PathItem item, String method) {
    for (final written in [...item.parameters, ...operation.parameters]) {
      final parameter = _model.resolve(written);
      if (parameter == null) continue;
      add(parameter.schema, .request);
      _content(parameter.content, .request);
    }
    if (operation.requestBody case final written?) {
      final content = _model.resolve(written)?.content ?? const {};
      if (method.toLowerCase() == 'patch') {
        for (final media in content.values) {
          _patchBody(_model.resolve(media)?.schema);
        }
      } else {
        _content(content, .request);
      }
    }
    for (final written in operation.responses.values) {
      _content(_model.resolve(written)?.content ?? const {}, .response);
    }
  }

  void _content(
    Map<String, RefOr<MediaType>> content,
    ModelDirection direction,
  ) {
    for (final written in content.values) {
      final media = _model.resolve(written);
      add(media?.schema, direction);
      add(media?.itemSchema, direction);
    }
  }

  /// Records [schema] as a PATCH body; the schemas inside it are used in
  /// requests.
  void _patchBody(Schema? schema) {
    if (schema == null) return;
    final resolved = _model.resolveSchema(schema);
    if (resolved is! SchemaObject) return;
    _patchBodies.add(resolved.location);
    for (final child in _children(resolved)) {
      add(child, .request);
    }
  }

  /// Records [schema] and every schema inside it as used in [direction].
  void add(Schema? schema, ModelDirection direction) {
    if (schema is! SchemaObject) return;
    if (schema.ref != null) {
      add(_model.resolveSchema(schema), direction);
      return;
    }
    if (!_seen.add((schema.location, direction))) return;
    (_uses[schema.location] ??= {}).add(direction);
    for (final child in _children(schema)) {
      add(child, direction);
    }
  }

  /// Whether [schema] is a PATCH body that is also used elsewhere, so the
  /// PATCH body gets a model of its own.
  bool separatesPatch(SchemaObject schema) =>
      _patchBodies.contains(schema.location) &&
      _uses.containsKey(schema.location);

  /// Whether [schema] gets a response model and a request model.
  bool splits(SchemaObject schema) =>
      (_uses[schema.location]?.length ?? 0) > 1 && _isDirectional(schema);

  /// The one direction [schema] is used in, if it is used in one only.
  ModelDirection? onlyDirection(SchemaObject schema) =>
      switch (_uses[schema.location]) {
        final uses? when uses.length == 1 => uses.single,
        _ => null,
      };

  /// Whether [schema] or a schema inside it has a `readOnly` or `writeOnly`
  /// property.
  bool _isDirectional(SchemaObject schema) {
    final known = _directional[schema.location];
    if (known != null) return known;
    // A cycle is not directional by itself.
    _directional[schema.location] = false;
    var result = false;
    for (final property in schema.properties.values) {
      final resolved = _model.resolveSchema(property);
      if (resolved is SchemaObject &&
          (resolved.readOnly || resolved.writeOnly)) {
        result = true;
      }
      if (property is SchemaObject &&
          (property.readOnly || property.writeOnly)) {
        result = true;
      }
    }
    if (!result) {
      for (final child in _children(schema)) {
        final resolved = _model.resolveSchema(child);
        if (resolved is SchemaObject && _isDirectional(resolved)) {
          result = true;
          break;
        }
      }
    }
    return _directional[schema.location] = result;
  }

  static List<Schema> _children(SchemaObject schema) => [
    ...schema.properties.values,
    ?schema.items,
    ...schema.prefixItems,
    ?schema.additionalProperties,
    ...schema.allOf,
    ...schema.oneOf,
    ...schema.anyOf,
  ];
}

/// `include` and `exclude` filters and the overrides' `exclude`.
///
/// With `include`, only operations that match one of its patterns are
/// kept; `exclude` then removes the operations it matches, so it refines

/// A pattern that matches no operation of the spec is reported, and so is a
/// pattern both filters list: the config contradicts itself there.
final class OperationSelector {
  /// Creates a selector for the client of [_context].
  const OperationSelector(this._context);

  final IrContext _context;

  /// The operations of [all] to generate, in the same order.
  List<SpecOperation> select(List<SpecOperation> all) {
    final config = _context.config;
    final include = _Matcher(config.include);
    final exclude = _Matcher(config.exclude);
    final selected = <SpecOperation>[];

      if (!included || excluded || (override?.exclude ?? false)) continue;

import 'dart:convert';

import 'package:args/command_runner.dart';
import 'package:io/io.dart' show ExitCode;

import '../check/spec_checker.dart';
import '../config/config_loader.dart';
import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/display_paths.dart';
import '../diagnostics/reporters.dart';

/// `typed_openapi ir`: prints the semantic IR of clients as JSON, to see
/// the names and types the generator will emit and to write overrides
/// before code generation exists.
///
/// The command is hidden: its output is for inspection and may change in
/// any release.
final class IrCommand extends Command<int> {
  /// Creates the command; the IR is written to [_out] and files are named
  /// as [_paths] does.
  IrCommand(this._out, [this._paths = const DisplayPaths()]) {
    argParser.addOption(
      'config',
      abbr: 'c',
      defaultsTo: 'typed_openapi.yaml',
      help: 'Path to the config file.',
    );
  }

  final StringSink _out;
  final DisplayPaths _paths;

  @override
  String get name => 'ir';

  @override
  bool get hidden => true;

  @override
  String get description =>
      'Print the semantic IR of clients as JSON (for debugging).';

  @override
  String get invocation => '${runner!.executableName} ir [options] [client...]';

  @override
  Future<int> run() async {
    final results = argResults!;
    final diagnostics = DiagnosticBag();
    final config = ConfigLoader(
      diagnostics,
      _paths,
    ).load(results.option('config')!);
    if (config == null) {
      _out.writeln(const TextReporter().format(diagnostics));
      return ExitCode.config.code;
    }
    final only = results.rest.toSet();
    final unknown = only.difference(config.declaredClients);
    if (unknown.isNotEmpty) {
      usageException(
        'Unknown client: ${(unknown.toList()..sort()).join(', ')}.',
      );
    }
    final checks = SpecChecker(
      diagnostics,
      _paths,
    ).checkClients(config, only: only);
    final json = {
      for (final ClientCheck(:client, :ir, :irJson) in checks)
        client.name: ir == null || irJson == null ? null : irJson.toJson(ir),
    };
    _out.writeln(const JsonEncoder.withIndent('  ').convert(json));
    return json.values.contains(null) ? 1 : ExitCode.success.code;
  }
}

## User decisions

Answers to the open questions of the first version of the plan (binding):

1. **Config keys** — as in the section "New config keys", plus `naming.patch_suffix` (item 6); the R5.1 transformations — only a regex prefix; `default_group` — a ready class name.
2. **Inline names of bodies and responses:** the request body — `<Method>Request`; one success response with a body — `<Method>Response`, one error with a body — `<Method>Error`; the status (`CreatePetResponse201`, `CreatePetError404`) — only when there are several responses of this kind with a body (task 6). `default` gives `Default`; a range — as written (`4XX`).
3. **Invalid identifiers** — as agreed: a `$` prefix for a first digit, fallback names `Schema`, `field`, `value`, `operation`, `param`, enum values `value1`, `valueMinus1`, `value0_5`, `true_`/`false_`.
4. **Collision suffixes** — as agreed: `2`, `3`…; arguments — first `<name><In>`; `Model` / `_` for reserved names; schema names take priority over group names.
5. **Method name without `operationId`:** a path parameter becomes `By<Param>`, several — joined by `And` in path order: `GET /pets/{id}` → `getPetsById`, `GET /users/{userId}/posts/{postId}` → `getUsersPostsByUserIdAndPostId`. The exact rule — in task 6 (`IrBuilder._pathName`).
6. **PATCH body:** a schema used only as a PATCH body — one model with `Patch<T>?`; used elsewhere too — a separate model `<Name>Patch` (`naming.patch_suffix`; the override `name` works). The interaction with `PetInput` — in task 7.
7. **The `group` override** goes through the template (`group: Pets` → `PetsApi`).
8. **TOA554:** a spec without any tag — one info for the whole spec; otherwise — one per operation without a tag (task 6).
9. **Inline enums** are deduplicated only among inline ones (deduplication with a component would be a guess); the address of an override for the name of an inline type — M8 (see "Deferred").
10. **The "generic wrapper" envelope** — M9.
11. **`type: object` without properties** — `Map<String, JsonValue>`.
12. **A model used in one direction** has no fields of the other.
13. **The `ir` command** — hidden; it is not shown in `--help`.

## Open questions

1. **"Used elsewhere" for a PATCH body** counts any other use of the schema, including as a property of another schema or inside itself (recursion): `Node` with `children: [Node]` in a PATCH body always gets `NodePatch`, and `children` leads to `Node`/`NodeInput`. Accepted this way as the most literal reading of decision 6.
2. **A variant for the status in the name** — a response with a body schema (`text/plain` with a schema also counts, although its type is `String` and it gives no inline declaration); responses `1xx`/`3xx` with a body always have the status in the name (`<Method>Response3XX`).
