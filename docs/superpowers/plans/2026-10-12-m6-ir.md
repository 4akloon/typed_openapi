# План M6: семантична IR і Dart-мапінг

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `typed_openapi check` будує для кожного клієнта незмінну семантичну IR — моделі, enum, union-и, групи операцій з параметрами, тілами, відповідями й помилками, уже з Dart-іменами й типами — і звітує проблеми іменування, мапінгу та фільтрів; емітери M8/M9 лише друкуватимуть цю IR.

**Architecture:** Новий шар `lib/src/ir/`. Вузли IR (`ir.dart`, `dart_type.dart`) посилаються на декларації через `DeclId` (розташування схеми + варіант: сама схема, модель запиту, модель тіла PATCH), а імена дає один глобальний прохід наприкінці (`names.dart`: `DartNames`, `NameScope`). `IrBuilder` вибирає операції (`OperationSelector`: фільтри конфігу, `exclude`), групує й іменує методи, `DirectionIndex` збирає напрямки використання схем, `OperationBuilder` мапить параметри, тіла, відповіді й помилки через `SchemaMapper`, який створює декларації на вимогу (tree-shaking) і наприкінці дає імена з діагностиками колізій. Налаштування — `GenerationConfig` у конфігу клієнта; поля генерації override-ів M4 — `IrOverrides`. `SpecChecker` будує IR після нормалізатора; прихована команда `ir` друкує її як JSON (`IrJson`).

**Tech Stack:** Dart `>=3.10.0 <4.0.0`, чистий Dart, без нових залежностей; тести на `package:test`.

**Spec:** [docs/superpowers/specs/2026-10-12-m6-ir-design.md](../specs/2026-10-12-m6-ir-design.md) — рішення 1–12. Вимоги: R4, R5, R6.1–R6.4, R6.8, R7.2 ([requirements.md](../../requirements.md)); R11.4 і `errors.default_schema` — для типу помилок операції. Дослідження: [research/README](../../research/README.md) §3.H (урок «глобальний прохід `Map<JsonPointer, String>`»), §7.5 (архітектура), §7.7 (представлення), [research/07](../../research/07-dart-building-blocks.md) §C. Runtime-імена — з [дизайну M7](../specs/2026-10-12-m7-runtime-design.md) (`Patch`, `JsonValue`, `Result`, `CallOptions`, `Date`). Перенесене: [roadmap](../../roadmap.md), рядки «Перенесено з M2/M3/M4» з позначкою M6. Правила коду — [CLAUDE.md](../../../CLAUDE.md).

## Global Constraints

- SDK `>=3.10.0 <4.0.0`; обидва пакети — чистий Dart. Primary constructors (Dart 3.13) не використовуються.
- Dart 3.10 активно: dot shorthands скрізь, де відомий тип контексту (`.nameCollision`, `direction: .request`, `case .tag:`), null-aware елементи колекцій (`'discriminator': ?d.discriminator`, `?schema.items`), switch-вирази і patterns, records, `final`/`sealed` класи. У тестах аргументи `expect(...)` — повні імена (`DiagnosticCode.nameCollision`, `ModelDirection.request`).
- ООП: жодних функцій верхнього рівня, крім `main` у `bin/` і тестах (у тестах — і локальні допоміжні функції верхнього рівня, як у наявних тестах). Компоненти, що звітують, отримують `DiagnosticBag` через конструктор (`IrBuilder(bag)`) або через `IrContext`.
- Помилки вхідних даних (специфікація, конфіг, override-и) не кидаються: вони йдуть у `DiagnosticBag`, решта будується. Жодна специфікація корпусу не дає винятку.
- Нічого не вгадується мовчки (R2.5): кожне перейменування, запасне ім'я, пропущена конструкція чи `JsonValue` замість типу — діагностика зі стабільним кодом і pointer-ом, а де ціль адресовна — з готовим override-ом (`OverrideSnippet`).
- Error — лише для справжніх помилок (операцію неможливо згенерувати: TOA556); інформаційні рішення генератора (суфікс, перша група) — info; втрата типу — warning.
- Детермінізм (R13.1): операції — за шляхом і методом, декларації в одному просторі імен — override-и, потім ключі компонентів, потім inline за глибиною, кожна група — за розташуванням; `ClientIr`/`GroupIr` сортують за іменем; жодного обходу хеш-мап у порядку вставки, крім мап специфікації в порядку документа.
- Кожен новий код — у `DiagnosticCode` з doc-коментарем, slug у kebab-case, рівень за замовчуванням.
- Негативні тести на валідних специфікаціях: валідна специфікація, валідні `allOf`, union, конфіг без нових ключів — жодної діагностики.
- Фікстури — вигадані й маленькі. Приватна специфікація компанії не використовується ні як фікстура, ні як джерело фікстур. Публічний корпус — лише для прогону `check`.
- Лінти з кореневого `analysis_options.yaml`; `dart analyze packages` з кореня — `No issues found!`; `dart format lib test bin` (з `packages/typed_openapi`) — другий запуск змінює 0 файлів.
- Тести не ходять у мережу; тимчасові файли — лише через `test/helpers/temp_dir.dart`.
- Команди `dart test`, `dart format` — з `packages/typed_openapi`; `dart pub get`, `dart analyze packages`, `git apply` і `git` — з кореня репозиторію. Diff-и в плані застосовуються `git apply` (з кореня), нові файли створюються з блоків цілком.

## Ухвалені рішення

Рішення специфікації M6 — обов'язкові. Тут — технічні рішення, які специфікація лишає планові. Рішення про формат і поведінку, які бачить користувач, підтвердив користувач після першої версії плану (розділ «Рішення користувача» наприкінці; номери — питання першої версії).

1. **Ідентичність декларації — `DeclId` (розташування схеми + `DeclVariant`: `base`, `input`, `patch`), імена — окремим проходом.** Типи посилаються на `DeclId`, ім'я з'являється лише в `SchemaMapper.declarations(scope)`. Так перейменування (колізія, override `name`) не чіпає типів, а inline-ім'я `<Parent><Property>` бере вже остаточне ім'я батька (`ListModel` → `ListModelTags`). Це «глобальний прохід `Map<JsonPointer, String>`» з research §3.H.
2. **IR видно користувачу і тестам через JSON.** `IrJson` пише детермінований JSON (фіксований порядок ключів, `файл#pointer` для місць), прихована команда `typed_openapi ir [client...]` друкує його. Чому: до M8/M9 користувач інакше не побачить, як генератор назве типи і методи, а override-и `name`/`group`/`dartType` пишуться саме під ці імена; тести порівнюють структуру, а не рядки коду. Команда прихована (`hidden: true`) і формат нестабільний — це інструмент налагодження, а не контракт; `check` лишається єдиним контрактом звіту. Альтернатива «прапорець `check --dump-ir`» змішала б звіт і дамп в одному stdout (і зламала б `--format json`).
3. **Коди M6 — у другій половині сотні своєї області** (TOA x50–x99), бо перша половина кожної сотні — правила нормалізатора M3: схеми TOA250–TOA254, enum TOA350, поліморфізм TOA450–TOA451, операції й іменування TOA550–TOA558. Області — за таблицею research §1 (2xx схеми, 3xx enum, 4xx поліморфізм, 5xx операції та іменування). 6xx (media types і помилки) і 7xx (стабільність виходу) поки не знадобились.
4. **Декларації створюються на вимогу.** `SchemaMapper` створює декларацію, коли схему вперше мапить вибрана операція, тож tree-shaking (R4.2) — властивість мапера, а не окремий прохід. Структурна компонент-схема (масив, мапа, скаляр) декларації не має: кожне використання отримує її тип (`Tags: {type: array, items: string}` → `List<String>`); власний тип для неї — `types.schemas`/`dartType`.
5. **Інтерпретаційні правила застосовуються в мапері, а не правкою специфікації.** `allOf` з однією частиною, `oneOf`/`anyOf` з однією не-null гілкою, `const` — так само для компонентів і inline; модель/посилання визначаються за схемою після override-ів і правил M3.
6. **Напрямки рахуються до мапінгу** (`DirectionIndex`), бо рішення «ділити схему» залежить від усіх її використань; модель, вжита в одному напрямку, не має полів іншого (відповідь без `writeOnly`, запит без `readOnly`) — це семантика OAS, а не евристика.
7. **Модель тіла PATCH вирішується до мапінгу** (`DirectionIndex.separatesPatch`: схема тіла PATCH, вжита ще деінде) і позначається під час мапінгу тіла (`typeOf(…, patchBody: true)`); поля обчислюються, коли модель будується, тож порядок операцій не впливає на результат.
8. **Override-и генерації — лише застосовані.** `IrOverrides` бере цілі, які `OverrideResolver` M4 знаходить на моделі останнього проходу (з тихим `DiagnosticBag`: усе вже звітував нормалізатор); записи з TOA804–TOA806 не мають цілі й на IR не впливають (перенесене з M4). Параметр рівня Path Item, адресований через одну операцію, змінює ім'я/тип аргументу в усіх операціях шляху (TOA808 про це вже каже).
9. **Помилки операції обчислюються з відповідей IR** (`ErrorsIr`): `NoErrors` = `E = Never` (M7, рішення 3), одна схема — `SingleError`, різні — `ErrorsByStatus`; статус без тіла — `errors.default_schema`. Як `ErrorsByStatus` стає sealed-типом — M9.
10. **Конверт фіксується в IR, а не в конфігу.** `ResponseIr.envelopeKey = 'data'` і тип `T` для кожної успішної JSON-відповіді `{data: T}`; режим «дженерик-обгортка» (spec, рішення 8) і його ключ конфігу — M9 (рішення користувача, п. 10), IR для нього та сама.
11. **Операція з незв'язаною змінною шляху не генерується** (TOA556, error): виклик не міг би заповнити URL. Операція, записана як `$ref` (TOA107 нормалізатора), пропускається мовчки — її вже звітовано.
12. **Корпус — частина визначення «готово»:** IR будується для всіх 14 клієнтів без винятків; три знайдені ним дефекти виправлено в задачі 9 з регресійними тестами.

## Нові ключі конфігу

У `defaults` і в клієнті; клієнт перекриває `defaults` (`naming`, `types`, `errors` — поключно, `types.formats`/`types.schemas` — поелементно):

```yaml
naming:
  group: '{Tag}Api'              # шаблон класу групи; {Tag} — ім'я групи в PascalCase
  default_group: DefaultApi      # клас операцій без групи
  input_suffix: Input            # модель запиту схеми, поділеної за напрямком
  patch_suffix: Patch            # модель тіла PATCH схеми, вжитої ще деінде
  operation_prefix: '^v1_'       # regex, зрізається з operationId (nestjs: ^[A-Za-z0-9]*Controller_)
group_by: tag                    # tag | path | single
include: {tags: [pets], operations: [getPet], paths: ['/store/**']}
exclude: {tags: [], operations: [], paths: []}
types:
  number: num                    # num | double | int — number без формату
  formats: {decimal: {type: Decimal, import: 'package:decimal/decimal.dart'}}
  schemas: {Money: {type: Money, import: 'package:app/money.dart', converter: MoneyConverter}}
tri_state: patch                 # patch | optional | extension (x-typed-tri-state: true)
errors:
  default_schema: ErrorDto       # ключ components.schemas
```

### Task 1: Вузли IR, Dart-типи і JSON-дамп

import '../model/spec_node.dart';

/// Which of the declarations of one schema an id names.
enum DeclVariant {
  /// The declaration of the schema; the response model of a split schema.
  base,

  /// The request model of a schema split by direction (`PetInput`).
  input,

  /// The PATCH body model of a schema also used elsewhere (`PetPatch`).
  patch,
}

/// The identity of a generated declaration: the location of the schema it
/// comes from and its [variant].
///
/// Types refer to declarations by id, so a declaration can be renamed
/// (collisions, overrides) without touching the types that use it.
final class DeclId implements Comparable<DeclId> {
  /// Creates the id of the declaration of the schema at [location].
  const DeclId(this.location, {this.variant = .base});

  /// Where the schema is.
  final SpecLocation location;

  /// Which declaration of the schema this is.
  final DeclVariant variant;

  @override
  bool operator ==(Object other) =>
      other is DeclId && other.location == location && other.variant == variant;

  @override
  int get hashCode => Object.hash(location, variant);

  @override
  int compareTo(DeclId other) {
    final byLocation = location.compareTo(other.location);
    if (byLocation != 0) return byLocation;
    return variant.index - other.variant.index;
  }

  @override
  String toString() =>
      variant == .base ? '$location' : '$location (${variant.name})';
}

/// A Dart type of a field, a parameter or a body.
sealed class DartType {
  /// Creates a type.
  const DartType({this.nullable = false});

  /// Whether the type is followed by `?`.
  final bool nullable;

  /// This type with [nullable] set to [value].
  DartType withNullable(bool value);

  /// The type as Dart code; [nameOf] gives the name of a declaration.
  String code(String Function(DeclId id) nameOf) =>
      nullable ? '${_code(nameOf)}?' : _code(nameOf);

  String _code(String Function(DeclId id) nameOf);
}

  @override
  bool operator ==(Object other) =>
      other is CoreType && other.kind == kind && other.nullable == nullable;

  @override

}

    required this.type,
    required this.import,
    required this.json,
    this.converter,
    super.nullable = false,
  });

  /// The Dart type, such as `Money`.
  final String type;

  /// The library that declares [type].
  final String import;

  /// A class with `fromJson` and `toJson` that converts [type], if any.
  final String? converter;

  /// The type of the value in JSON, from the schema: `S` of `fromJson(S)`.
  final DartType json;

  CustomType withNullable(bool value) => CustomType(
    type: type,
    import: import,
    json: json,
    converter: converter,
    nullable: value,

  String _code(String Function(DeclId id) nameOf) => type;

      other.type == type &&
      other.import == import &&
      other.converter == converter &&
      other.json == json &&
      other.nullable == nullable;

  @override
  int get hashCode =>
      Object.hash(CustomType, type, import, converter, json, nullable);
}

import '../model/operation.dart';
import '../model/spec_node.dart';
import 'dart_type.dart';

/// The semantic IR of one client: what the emitters print, with Dart names
/// and types already chosen.
///
/// Every list is sorted, so the same spec and config give the same IR.
final class ClientIr {
  /// Creates the IR; [declarations] and [groups] are sorted by name.
  ClientIr({
    required List<Declaration> declarations,
    required List<GroupIr> groups,
  }) : declarations = List.unmodifiable(
         declarations.toList()..sort((a, b) => a.name.compareTo(b.name)),
       ),
       groups = List.unmodifiable(
         groups.toList()..sort((a, b) => a.name.compareTo(b.name)),
       );

  /// The models, enums and unions, by name.
  final List<Declaration> declarations;

  /// The API classes, by name.
  final List<GroupIr> groups;

  late final Map<DeclId, Declaration> _byId = {
    for (final declaration in declarations) declaration.id: declaration,
  };

  /// The declaration [id] names, if it is generated.
  Declaration? operator [](DeclId id) => _byId[id];

  /// The Dart name of the declaration [id]; `?` when it is not generated.
  String nameOf(DeclId id) => _byId[id]?.name ?? '?';
}

/// A generated model, enum or union.
sealed class Declaration {
  /// Creates a declaration.
  const Declaration({
    required this.id,
    required this.name,
    this.description,
    this.deprecated = false,
  });

  /// The identity of the declaration.
  final DeclId id;

  /// The Dart name of the type.
  final String name;

  /// `description` of the schema.
  final String? description;

  /// `deprecated` of the schema.
  final bool deprecated;

  /// Where the schema is.
  SpecLocation get location => id.location;
}

/// Where a model is used.
enum ModelDirection {
  /// In requests and responses.
  both,

  /// In responses only: `writeOnly` properties are left out.
  response,

  /// In requests only: `readOnly` properties are left out.
  request,
}

/// A class with fields: an object schema, or the flat merge of an `allOf`.
final class ModelDecl extends Declaration {
  /// Creates a model.
  const ModelDecl({
    required super.id,
    required super.name,
    required this.fields,
    this.direction = .both,
    this.additionalProperties,
    super.description,
    super.deprecated,
  });

  /// The fields, in the order of the schema's properties.
  final List<FieldIr> fields;

  /// Where the model is used.
  final ModelDirection direction;

  /// The type of the values of `additionalProperties`, when the schema
  /// allows other keys with a schema.
  final DartType? additionalProperties;
}

/// A field of a model.
final class FieldIr {
  /// Creates a field.
  const FieldIr({
    required this.name,
    required this.jsonKey,
    required this.valueType,
    required this.location,
    this.required = false,
    this.triState = false,
    this.readOnly = false,
    this.writeOnly = false,
    this.defaultValue,
    this.description,
    this.deprecated = false,
  });

  /// The Dart name.
  final String name;

  /// The property name in JSON, as in the spec.
  final String jsonKey;

  /// The type of a value; nullable when the schema allows `null`.
  final DartType valueType;

  /// Where the property schema is.
  final SpecLocation location;

  /// Whether the property is in the schema's `required`.
  final bool required;

  /// Whether the field tells "absent" from `null` (R7).
  final bool triState;

  /// `readOnly`.
  final bool readOnly;

  /// `writeOnly`.
  final bool writeOnly;

  /// `default`, as a one-element record.
  final (Object?,)? defaultValue;

  /// `description`.
  final String? description;

  /// `deprecated`.
  final bool deprecated;

  /// The type of the field (R6.1): `Patch<T>?` for a tri-state field, the
  /// value type for a required one, and a nullable value type otherwise.
  DartType get type {
    if (triState) {
      return PatchType(valueType.withNullable(false), nullable: true);
    }
    return required ? valueType : valueType.withNullable(true);
  }
}

/// Turns names from a spec into Dart identifiers (R5).
///
/// A name is split into words at characters that are not ASCII letters or
/// digits and at case changes (`petId`, `HTTPServer`, `user_dto`); words
/// keep their case except the first letter, so `UserDTO` stays `UserDTO`.
/// Nothing is shortened or added by heuristics.
final class DartNames {
  /// Creates the converter.
  const DartNames();

  static final _separators = RegExp('[^A-Za-z0-9]+');
  static final _word = RegExp(
    '[A-Z]+(?=[A-Z][a-z])|[A-Z]?[a-z]+|[A-Z]+|[0-9]+',
  );

  /// Dart reserved words: never an identifier.
  static const reservedWords = {
    'assert', 'break', 'case', 'catch', 'class', 'const', 'continue', //
    'default', 'do', 'else', 'enum', 'extends', 'false', 'final',
    'finally', 'for', 'if', 'in', 'is', 'new', 'null', 'rethrow', 'return',
    'super', 'switch', 'this', 'throw', 'true', 'try', 'var', 'void',
    'while', 'with',
    // Not reserved, but not usable inside async methods and generators.
    'await', 'yield',
  };

  /// Built-in identifiers: usable as members, not as type names.
  static const builtInIdentifiers = {
    'abstract', 'as', 'covariant', 'deferred', 'dynamic', 'export', //
    'extension', 'external', 'factory', 'Function', 'get', 'implements',
    'import', 'interface', 'late', 'library', 'mixin', 'operator', 'part',

  static const takenTypeNames = {

    'String', 'StringBuffer', 'StringSink', 'Symbol', 'Type', 'TypeError',
    'UnimplementedError', 'UnsupportedError', 'Uri', 'WeakReference', 'bool',
    'double', 'int', 'num', 'Uint8List',

    'SseItemDecoder', 'SseMessage', 'Success', 'TransportError',

  /// enums and API classes add.
  static const objectMembers = {
    'hashCode', 'noSuchMethod', 'runtimeType', 'toString', //

  /// Members a model's fields must not shadow.

  /// request body and the per-call options of the runtime.

  /// digit.

    for (final part in text.split(_separators))
      for (final match in _word.allMatches(part)) match[0]!,

  /// letter or digit. A name that starts with a digit gets a `$`.
  String? pascal(String text) {
    final parts = words(text);
    if (parts.isEmpty) return null;
    return _leading(parts.map(_capitalize).join());
  }

  /// [text] as a lowerCamelCase member name, or null when it has no ASCII
  /// letter or digit. A name that starts with a digit gets a `$`.
  String? camel(String text) {
    final parts = words(text);
    if (parts.isEmpty) return null;
    return _leading(
      [parts.first.toLowerCase(), ...parts.skip(1).map(_capitalize)].join(),

/// Why [NameScope.claim] did not give the candidate itself.
enum NameChange {
  /// The candidate is a reserved word or a name Dart already has.
  reserved,

  /// Another declaration of the scope already has the candidate.
  collision,
}

/// The names of one scope (a library's types, a class's members, a
/// method's arguments), given out in the order they are claimed.
///
/// Callers claim in a deterministic order (by spec location), so the same
/// spec always gives the same names.
final class NameScope {
  /// Creates a scope where [reserved] names get [reservedSuffix].
  NameScope({required Set<String> reserved, required this.reservedSuffix})
    : _reserved = reserved;

  final Set<String> _reserved;
  final Set<String> _taken = {};

  /// What a reserved name gets appended: `Model` for types, `_` for
  /// members.
  final String reservedSuffix;

  /// Whether [name] is given out.
  bool isTaken(String name) => _taken.contains(name);

  /// Gives out [candidate], or a free name made from it: with
  /// [reservedSuffix] when it is reserved, then the first free of
  /// [alternatives], then with `2`, `3`, ... appended. Returns the name and
  /// why it differs from [candidate], if it does.
  (String, NameChange?) claim(
    String candidate, {
    List<String> alternatives = const [],
  }) {
    if (_reserved.contains(candidate)) {
      final name = _free('$candidate$reservedSuffix');
      return (name, .reserved);
    }
    if (_taken.add(candidate)) return (candidate, null);
    for (final alternative in alternatives) {
      if (!_reserved.contains(alternative) && _taken.add(alternative)) {
        return (alternative, .collision);
      }
    }
    return (_free(candidate), .collision);
  }

  String _free(String base) {
    if (_taken.add(base)) return base;
    for (var i = 2; ; i++) {
      if (_taken.add('$base$i')) return '$base$i';
    }
  }
}

/// The generation fields of a client's overrides (M4), by the location of
/// the node each entry names.
///
/// Only entries the normalizer could apply are here: an entry whose target
/// is missing, ambiguous or in conflict (TOA804–TOA806) changes nothing.
final class IrOverrides {
  /// Indexes the overrides of [spec] that name a node of its model.
  factory IrOverrides(NormalizedSpec spec) {
    final overrides = spec.overrides;
    if (overrides == null || overrides.isEmpty) return IrOverrides.none();
    // The normalizer has reported what cannot be resolved already.
    final targets = OverrideResolver(
      DiagnosticBag(),
      overrides,
    ).resolve(spec.model, spec.documents);
    return IrOverrides._({
      for (final target in targets) target.node.location: target.entry,
    });
  }

  /// No overrides.
  IrOverrides.none() : this._(const {});

  IrOverrides._(this._entries);

  final Map<SpecLocation, OverrideEntry> _entries;

  /// The override of the schema at the end of a `components.schemas`
  /// key's `$ref` chain.
  SchemaOverride? schemaAt(SpecLocation location) =>
      switch (_entries[location]) {
        final SchemaOverride entry => entry,
        _ => null,
      };

  /// The override of the property schema written at [location].
  PropertyOverride? propertyAt(SpecLocation location) =>
      switch (_entries[location]) {
        final PropertyOverride entry => entry,
        _ => null,
      };

  /// The override of the Operation Object at [location].
  OperationOverride? operationAt(SpecLocation location) =>
      switch (_entries[location]) {
        final OperationOverride entry => entry,
        _ => null,
      };

  /// The override of the Parameter Object at [location].
  ParameterOverride? parameterAt(SpecLocation location) =>
      switch (_entries[location]) {
        final ParameterOverride entry => entry,
        _ => null,
      };
}

/// What every step of building the IR of a client reads, and where it
/// reports.
final class IrContext {
  /// Creates a context for [spec] generated as [client] says.
  IrContext(this.diagnostics, this.spec, this.client)
    : overrides = IrOverrides(spec);

  /// Where problems go.
  final DiagnosticBag diagnostics;

  /// The normalized spec.
  final NormalizedSpec spec;

  /// The client.
  final ClientConfig client;

  /// The generation fields of the client's overrides.
  final IrOverrides overrides;

  late final OverrideSnippet _snippets = OverrideSnippet(model);

  /// The spec model.
  SpecModel get model => spec.model;

  /// The spec files.
  SpecDocuments get documents => spec.documents;

  /// The generation settings.
  GenerationConfig get config => client.generation;

  /// Reports [code] at [at]; [override] is an override to copy into the
  /// overrides file, added to [fix].
  void report(
    DiagnosticCode code,
    String message,
    SpecLocation at, {
    String? fix,
    String? override,
  }) {
    final text = switch ((fix, override)) {
      (final fix?, final snippet?) => '$fix Override:\n$snippet',
      (null, final snippet?) => 'Override:\n$snippet',
      (final fix, null) => fix,
    };
    diagnostics.report(
      code,
      message,
      file: documents.displayPath(at.document),
      pointer: at.pointer,
      span: documents[at.document]?.spanOf(at.pointer),
      fix: text,
    );
  }

  /// The override of the schema at [location] that sets [fields], if the
  /// schema can be addressed.
  String? schemaOverride(SpecLocation location, Map<String, Object?> fields) =>
      _snippets.forSchema(location, fields);

  /// The override at [address] that sets [fields].
  String? overrideAt(List<String> address, Map<String, Object?> fields) =>
      _snippets.write(address, fields);
}

/// How an inline schema's declaration is named (R5.4): after its parent
/// declaration or a fixed prefix (an operation), followed by [suffix].
final class NameHint {
  /// A name made of [prefix] and [suffix], such as `CreatePet` + `Request`.
  const NameHint(String this.prefix, this.suffix) : _parent = null;

  const NameHint._under(_Pending this._parent, this.suffix) : prefix = null;

  /// The fixed start of the name, when there is no parent declaration.
  final String? prefix;

  /// The end of the name, such as a property name in UpperCamelCase.
  final String suffix;

  final _Pending? _parent;
}

/// Maps schemas to Dart types and collects the declarations they need
/// (R6.1–R6.3, R6.8).
///
/// Declarations are created when a schema is first mapped, so only schemas
/// reachable from what is mapped are generated (R4.2). Names are given at
/// the end ([declarations]): component schemas keep their key, inline
/// schemas are named after their parent, and collisions get a suffix with a
/// diagnostic (R5.2).
final class SchemaMapper {
  /// Creates a mapper for the spec of [_context].
  SchemaMapper(this._context);

  static const _names = DartNames();
  static const _fallbackName = 'Schema';

  final IrContext _context;
  final Map<DeclId, _Pending> _pending = {};
  final Map<String, _Pending> _inlineEnums = {};
  final Set<SpecLocation> _aliases = {};

  /// The type of [schema]; an inline declaration it needs is named by
  /// [hint].
  DartType typeOf(Schema schema, NameHint hint) => _map(schema, hint);

  /// The type of the `components.schemas` entry [schema], as a `$ref` to it
  /// would have.
  DartType typeOfComponent(Schema schema) =>
      switch (_context.model.resolveSchema(schema)) {
        final SchemaObject target => _component(target),
        _ => const CoreType(.json),
      };

  /// The declarations created so far, named in [scope]: overridden names
  /// first, then component keys, then inline names, each by location.
  List<Declaration> declarations(NameScope scope) {
    final ordered = _pending.values.toList()
      ..sort((a, b) {
        final byRank = a.rank.compareTo(b.rank);
        if (byRank != 0) return byRank;
        final byDepth = a.depth.compareTo(b.depth);
        if (byDepth != 0) return byDepth;
        return a.id.compareTo(b.id);
      });
    for (final pending in ordered) {
      pending.name = _claim(scope, pending);
    }
    return [for (final pending in ordered) pending.build!(pending.name!)];
  }

  String _claim(NameScope scope, _Pending pending) {
    final overridden = pending.overrideName;
    final String? candidate;
    if (overridden != null) {
      candidate = overridden;
    } else if (pending.componentKey case final key?) {
      candidate = _names.pascal(key);
    } else {
      final parent = pending.hint!._parent?.name ?? pending.hint!.prefix!;
      candidate = '$parent${pending.hint!.suffix}';
    }
    if (candidate == null) {
      final (name, _) = scope.claim(_fallbackName);
      _context.report(
        .nameUnrepresentable,
        'Schema "${pending.componentKey}" has no ASCII letter or digit, so '
        'its type is named "$name".',
        pending.id.location,
        fix: 'Rename the schema at the source, or name its type.',
        override: _context.schemaOverride(pending.id.location, {'name': name}),
      );
      return name;
    }
    final (name, change) = scope.claim(candidate);
    if (change != null) {
      _context.report(
        change == .reserved ? .nameReserved : .nameCollision,
        change == .reserved
            ? '"$candidate" is a name Dart already has; the type is named '
                  '"$name".'
            : 'Another type is named "$candidate"; this one is named '
                  '"$name".',
        pending.id.location,
        fix: 'Name the type explicitly to keep the name stable.',
        override: _context.schemaOverride(pending.id.location, {'name': name}),
      );
    }
    return name;
  }

  DartType _map(Schema schema, NameHint hint) {
    if (schema is BooleanSchema) return const CoreType(.json);
    final object = schema as SchemaObject;
    if (object.ref != null) {
      final target = _context.model.resolveSchema(object);
      // A broken `$ref` is reported by the resolver (TOA101).
      if (target is! SchemaObject) return const CoreType(.json);
      final type = _component(target);
      return type.withNullable(type.nullable || _isNullable(object));
    }
    return _inline(object, hint);
  }

  /// The type of a schema a `$ref` points to.
  DartType _component(SchemaObject schema) {
    final custom = _customSchemaType(schema);
    if (custom != null) return custom;
    final id = DeclId(schema.location);
    final pending = _pending[id];
    if (pending != null) return NamedType(id, nullable: _isNullable(schema));
    final key = _componentKey(schema.location);
    if (_declares(schema)) {
      return _declare(
        schema,
        id,
        (p) => p
          ..componentKey = key
          ..overrideName = _context.overrides.schemaAt(schema.location)?.name,
      );
    }
    // A structural schema (array, map, scalar) has no declaration of its
    // own: each use gets its type. One that refers back to itself cannot be
    // spelled out.
    if (!_aliases.add(schema.location)) {
      _context.report(
        .recursiveAlias,
        'This schema refers to itself without an object between; the '
        'reference is generated as JsonValue.',
        schema.location,
        fix: 'Make the recursive part an object schema at the source.',
      );
      return const CoreType(.json);
    }
    try {
      return _structural(
        schema,
        NameHint(_names.pascal(key ?? '') ?? _fallbackName, ''),
      );
    } finally {
      _aliases.remove(schema.location);
    }
  }

  DartType _inline(SchemaObject schema, NameHint hint) {
    if (_declares(schema)) {
      if (_enumValues(schema) case final values?) {
        final kind = _enumKind(schema, values);
        if (kind != null) {
          final key = '${kind.name}:${values.join('\u0000')}';
          final known = _inlineEnums[key];
          if (known != null) {
            return NamedType(known.id, nullable: _isNullable(schema));
          }
        }
      }
      return _declare(schema, DeclId(schema.location), (p) => p.hint = hint);
    }
    return _structural(schema, hint);
  }

  /// Whether [schema] gets a declaration: an object with properties or an
  /// enum.
  bool _declares(SchemaObject schema) =>
      _enumValues(schema) != null || schema.properties.isNotEmpty;

  DartType _declare(
    SchemaObject schema,
    DeclId id,
    void Function(_Pending) setUp,
  ) {
    final values = _enumValues(schema);
    final kind = values == null ? null : _enumKind(schema, values);
    if (values != null && kind == null) {
      _context.report(
        .enumMixedValues,
        'The values of this enum are not all strings, all numbers or all '
        'booleans; it is generated as JsonValue.',
        schema.location,
        fix: 'Give the enum values of one JSON type at the source.',
      );
      return const CoreType(.json);
    }
    final pending = _Pending(id);
    setUp(pending);
    final parent = pending.hint?._parent;
    pending.depth = parent == null ? 0 : parent.depth + 1;
    _pending[id] = pending;
    if (values != null && kind != null) {
      _enum(schema, pending, values, kind);
    } else {
      _model(schema, pending);
    }
    return NamedType(id, nullable: _isNullable(schema));
  }

  void _model(SchemaObject schema, _Pending pending) {
    final fields = <_Field>[];
    for (final MapEntry(key: json, value: property)
        in schema.properties.entries) {
      final override = _context.overrides.propertyAt(property.location);
      if (override?.exclude ?? false) continue;

      final suffix = _names.pascal(json) ?? 'Field';

          json: json,
          override: override,
          location: property.location,
          valueType: custom == null ? mapped : _custom(custom, mapped),

          writeOnly: resolved?.writeOnly ?? false,
          defaultValue: resolved?.defaultValue,
          description: resolved?.description,
          deprecated: resolved?.deprecated ?? false,
        ),
      );

    final additional = extra == null || extra is BooleanSchema
        ? null
        : _map(extra, NameHint._under(pending, 'Value'));

        reserved: {...DartNames.reservedWords, ...DartNames.modelMembers},
        reservedSuffix: '_',

        id: pending.id,

  /// The Dart name of the member [json] of the type [owner], from [named]
  /// (an override) or [json].
  String _memberName(
    NameScope scope,
    String json,
    String? named,
    SpecLocation location, {
    required String owner,

    _Pending pending,

  String _valueName(
    NameScope scope,
    String? named,
    Object value,
    SpecLocation location,

  static EnumKind? _enumKind(SchemaObject schema, List<Object?> values) {
    if (values.every((v) => v is String)) return .string;
    if (values.every((v) => v is bool)) return .boolean;
    if (values.every((v) => v is int)) {

  /// The type of a schema without a declaration: a scalar, a list or a
  /// map.
  DartType _structural(SchemaObject schema, NameHint hint) {
    final nullable = _isNullable(schema);
    final types = [
      for (final type in schema.types)
        if (type != SchemaType.nullType) type,
    ];
    if (types.length > 1) {
      _context.report(
        .mixedTypeSchema,

        'generated as JsonValue.',
        schema.location,

            'Give the schema one type at the source, or a Dart type with an '

          'dartType': {'type': 'MyType', 'import': 'package:app/my_type.dart'},
        }),

      return const CoreType(.json);
    }
    final type =
        types.firstOrNull ??
        (schema.items != null
            ? SchemaType.array
            : schema.additionalProperties != null
            ? SchemaType.object
            : null);
    final DartType base = switch (type) {
      null || SchemaType.nullType => const CoreType(.json),
      .integer => const CoreType(.integer),
      .number => switch (schema.format) {
        'float' || 'double' => const CoreType(.float),
        _ => switch (_context.config.numberType) {
          'double' => const CoreType(.float),
          'int' => const CoreType(.integer),
          _ => const CoreType(.number),

      },
      .boolean => const CoreType(.boolean),
      .string => switch (schema.format) {
        'date-time' => const CoreType(.dateTime),
        'date' => const CoreType(.date),
        'byte' => const CoreType(.bytes),
        'binary' => const CoreType(.binary),
        _ => const CoreType(.string),

          null => const CoreType(.json),

          final BooleanSchema _ || null => const CoreType(.json),
          final values => _map(values, _suffixed(hint, 'Value')),
        },
      ),
    };

    final custom = format == null ? null : _context.config.formats[format];
    final mapped = custom == null ? base : _custom(custom, base);
    return mapped.withNullable(nullable);

import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/json_pointer.dart';
import '../model/spec_node.dart';
import '../normalize/normalizer.dart';
import 'ir.dart';
import 'ir_context.dart';
import 'names.dart';
import 'operation_builder.dart';
import 'schema_mapper.dart';

/// Builds the semantic IR of a client from its normalized spec (M6).
///
/// Operations are grouped (R5.3) and named (R5.1); their parameters,
/// bodies and responses are mapped to types, which creates the
/// declarations they reach (R4.2); then declarations and groups are named
/// in one library scope (R5.2). Problems go to the [DiagnosticBag] given to
/// the constructor; nothing is thrown for any spec.
final class IrBuilder {
  /// Creates a builder that reports to [_diagnostics].
  const IrBuilder(this._diagnostics);

  static const _names = DartNames();

  /// The `operationId` prefix the `nestjs` preset removes:
  /// `UserController_get` → `get`.
  static final nestjsPrefix = RegExp('^[A-Za-z0-9]*Controller_');

  static final _variable = RegExp(r'\{([^}]*)\}');

  final DiagnosticBag _diagnostics;

  /// The IR of [spec] generated as [client] says.
  ClientIr build(NormalizedSpec spec, ClientConfig client) {
    final context = IrContext(_diagnostics, spec, client);
    final mapper = SchemaMapper(context);
    final operations = OperationBuilder(context, mapper);
    final groups = <String, List<SpecOperation>>{};
    final groupSites = <String, SpecLocation>{};
    final tagOfGroup = <String, String>{};
    final all = _operations(context);
    // A spec without any tag gets one TOA554, not one per operation.
    final untagged =
        client.generation.groupBy == .tag &&
        all.every((e) => e.operation.tags.isEmpty);
    if (untagged && all.isNotEmpty) {
      context.report(
        .operationUntagged,
        'No operation of the spec has a tag, so all operations are in '
        '${client.generation.defaultGroup}.',
        SpecLocation(
          spec.model.document.location.document,
          JsonPointer.root.child('paths'),
        ),
        fix:
            'Tag the operations at the source, or set group_by to path or '
            'single in the config.',
      );
    }
    for (final entry in all) {
      final group = _group(
        context,
        entry,
        tagOfGroup,
        reportUntagged: !untagged,
      );
      (groups[group] ??= []).add(entry);
      final site = groupSites[group];
      if (site == null || entry.operation.location.compareTo(site) < 0) {
        groupSites[group] = entry.operation.location;
      }
    }
    final built = <String, List<OperationIr>>{};
    for (final group in groups.keys.toList()..sort()) {
      final scope = NameScope(
        reserved: {...DartNames.reservedWords, ...DartNames.objectMembers},
        reservedSuffix: '_',
      );
      for (final entry in groups[group]!) {
        final name = _methodName(context, entry, scope);
        final operation = operations.build(entry, name);
        if (operation != null) (built[group] ??= []).add(operation);
      }
    }
    final types = NameScope(
      reserved: {
        ...DartNames.reservedWords,
        ...DartNames.builtInIdentifiers,
        ...DartNames.takenTypeNames,
      },
      reservedSuffix: 'Model',
    );
    final declarations = mapper.declarations(types);
    return ClientIr(
      declarations: declarations,
      groups: [
        for (final group in built.keys.toList()..sort())
          GroupIr(
            _groupName(context, types, group, groupSites[group]!),
            built[group]!,
          ),
      ],
    );
  }

  /// The operations of `paths`, by location, with `additionalOperations`
  /// (OpenAPI 3.2). A path item shared through `$ref` gives its operations
  /// to every path that uses it.
  static List<SpecOperation> _operations(IrContext context) {
    final result = <SpecOperation>[];
    for (final MapEntry(key: path, :value)
        in context.model.document.paths.entries) {
      final item = context.model.resolve(value);
      if (item == null) continue;
      for (final MapEntry(key: method, value: operation) in [
        ...item.operations.entries,
        ...item.additionalOperations.entries,
      ]) {
        result.add(SpecOperation(operation, method, path, item));
      }
    }
    return result..sort((a, b) {
      final byPath = a.path.compareTo(b.path);
      if (byPath != 0) return byPath;
      return a.method.compareTo(b.method);
    });
  }

  /// The group of [entry] before the class name template: an override's
  /// `group`, else by `group_by`. [reportUntagged] reports an operation
  /// without a tag.
  static String _group(
    IrContext context,
    SpecOperation entry,
    Map<String, String> tagOfGroup, {
    required bool reportUntagged,
  }) {
    final operation = entry.operation;
    final override = context.overrides.operationAt(operation.location)?.group;
    if (override != null) return _names.pascal(override) ?? override;
    final config = context.config;
    switch (config.groupBy) {
      case .single:
        return '';
      case .path:
        final segment = entry.path
            .split('/')
            .firstWhere(
              (s) => s.isNotEmpty && !s.startsWith('{'),
              orElse: () => '',
            );
        return _names.pascal(segment) ?? '';
      case .tag:
        if (operation.tags.isEmpty) {
          if (!reportUntagged) return '';
          context.report(
            .operationUntagged,
            'This operation has no tag, so it is in '
            '${config.defaultGroup}.',
            operation.location,
            fix: 'Tag the operation at the source, or name its group.',
            override: context.overrideAt(
              ['operations', entry.overrideKey],
              {'group': 'Default'},
            ),
          );
          return '';
        }
        final tag = operation.tags.first;
        if (operation.tags.length > 1) {
          context.report(
            .operationMultipleTags,

            'generated once, in the group of "$tag".',

            fix: 'Keep one tag at the source, or name the group.',
            override: context.overrideAt(

            ),
          );
        }
        final group = _names.pascal(tag);
        if (group == null) {
          context.report(

            '${config.defaultGroup}.',
            operation.location.child('tags').child(0),
            fix: 'Name the group of the operation.',
            override: context.overrideAt(
              ['operations', entry.overrideKey],
              {'group': 'MyGroup'},
            ),
          );
          return '';

          tagOfGroup[group] = tag;
        } else if (earlier != tag) {
          context.report(
            .tagsMerged,
            'Tags "$earlier" and "$tag" give the same group name, so their '
            'operations are in one class.',
            operation.location.child('tags').child(0),
            fix: 'Write the tag the same way everywhere at the source.',
          );
        }
        return group;
    }
  }

  /// The class name of [group] in the library scope [types].
  static String _groupName(
    IrContext context,
    NameScope types,
    String group,
    SpecLocation site,
  ) {
    final config = context.config;
    final candidate = group.isEmpty
        ? config.defaultGroup
        : config.groupTemplate.replaceAll('{Tag}', group);
    final (name, change) = types.claim(candidate);
    if (change != null) {
      context.report(
        change == .reserved ? .nameReserved : .nameCollision,
        change == .reserved
            ? 'Group class "$candidate" would be a name Dart already has; it '
                  'is named "$name".'
            : 'A type is named "$candidate" already; the group class is '
                  'named "$name".',
        site,
        fix: 'Change naming.group in the config, or rename the schema.',
      );
    }
    return name;
  }

  /// The words of a method name made from [method] and [path]: the method,
  /// the words of every path segment without its variables, then, when the
  /// path has variables, `By` and the variables in path order joined by
  /// `And`: `GET /users/{userId}/posts/{postId}` gives
  /// `getUsersPostsByUserIdAndPostId`, `GET /pets/{id}` gives
  /// `getPetsById`.
  static String _pathName(String method, String path) {
    final variables = <String>[];
    final literal = path.replaceAllMapped(_variable, (match) {
      variables.add(match[1]!);
      return ' ';
    });
    if (variables.isEmpty) return '$method $literal';
    return '$method $literal By ${variables.join(' And ')}';
  }

  /// The method name of [entry] in its group's [scope] (R5.1): an
  /// override's `name`, else `operationId` without the configured prefix,
  /// else [_pathName], in lowerCamelCase.
  static String _methodName(
    IrContext context,
    SpecOperation entry,
    NameScope scope,
  ) {
    final operation = entry.operation;
    final override = context.overrides.operationAt(operation.location)?.name;
    final prefix =
        context.config.operationPrefix ??
        (context.client.preset == .nestjs ? nestjsPrefix : null);
    final id = operation.operationId;
    final source = id == null
        ? _pathName(entry.method, entry.path)
        : prefix == null
        ? id
        : id.replaceFirst(prefix, '');
    final candidate = override ?? _names.camel(source);
    final (name, change) = scope.claim(candidate ?? 'operation');
    if (candidate == null || change != null) {
      context.report(
        candidate == null
            ? .nameUnrepresentable
            : change == .reserved
            ? .nameReserved
            : .nameCollision,
        candidate == null
            ? 'operationId "$id" has no ASCII letter or digit; the method is '
                  'named "$name".'
            : change == .reserved
            ? 'Method "$candidate" would be a name Dart already has; it is '
                  'named "$name".'
            : 'Another method of the group is named "$candidate"; this one '
                  'is named "$name".',
        operation.location,
        fix: 'Name the method explicitly to keep the name stable.',
        override: context.overrideAt(
          ['operations', entry.overrideKey],
          {'name': name},
        ),
      );
    }
    return name;
  }
}

/// Builds the IR of operations: parameters, bodies, responses and errors
/// (R10.3, R10.4, R10.6, R11.4); types come from a [SchemaMapper].
final class OperationBuilder {
  /// Creates a builder that maps types with [_mapper].
  OperationBuilder(this._context, this._mapper);

  static const _names = DartNames();
  static final _variable = RegExp(r'\{([^}]*)\}');

  final IrContext _context;
  final SchemaMapper _mapper;

  /// The IR of [entry], named [name]; null when its path template cannot
  /// be filled.
  OperationIr? build(SpecOperation entry, String name) {
    final operation = entry.operation;
    final prefix = _names.pascal(name) ?? name;
    final parameters = _parameters(entry, prefix);
    if (parameters == null) return null;
    final responses = _responses(operation, prefix);
    return OperationIr(
      location: operation.location,
      name: name,
      method: entry.method.toUpperCase(),
      path: entry.path,
      operationId: operation.operationId,
      tags: operation.tags,
      summary: operation.summary,
      description: operation.description,
      deprecated: operation.deprecated,
      parameters: parameters,
      body: _body(operation, prefix),
      responses: responses,
      errors: _errors(responses),
    );
  }

  List<ParameterIr>? _parameters(SpecOperation entry, String prefix) {
    // Operation parameters replace path item parameters with the same name
    // and location.
    final byKey = <(ParameterLocation?, String?), Parameter>{};
    for (final written in [
      ...entry.item.parameters,
      ...entry.operation.parameters,
    ]) {
      final parameter = _context.model.resolve(written);
      if (parameter == null) continue;
      byKey[(parameter.placement, parameter.name)] = parameter;
    }
    final variables = [
      for (final match in _variable.allMatches(entry.path)) match[1]!,
    ];
    var bound = true;
    for (final variable in variables) {
      if (byKey.containsKey((ParameterLocation.path, variable))) continue;
      bound = false;
      _context.report(
        .pathVariableUnbound,
        'Path variable "{$variable}" of ${entry.path} has no path parameter '
        'with this exact name, so the operation is not generated.',
        entry.operation.location,
        fix: 'Declare a path parameter named "$variable" at the source.',
      );
    }
    if (!bound) return null;
    final scope = NameScope(
      reserved: {...DartNames.reservedWords, ...DartNames.argumentNames},
      reservedSuffix: '_',
    );
    const order = [
      ParameterLocation.path,
      ParameterLocation.query,
      ParameterLocation.querystring,
      ParameterLocation.header,
      ParameterLocation.cookie,
    ];
    final sorted = byKey.values.toList()
      ..sort(
        (a, b) => order.indexOf(a.placement!) - order.indexOf(b.placement!),
      );
    return [
      for (final parameter in sorted)
        if (parameter.name case final wire?)

      null => _content(parameter.content),

  RequestBodyIr? _body(Operation operation, String prefix) {
    final written = operation.requestBody;
    if (written == null) return null;
    final body = _context.model.resolve(written);
    if (body == null) return null;

    final kind = contentType == null ? BodyKind.none : _kind(contentType);
    final schema = media?.schema;

      description: body.description,

  List<ResponseIr> _responses(Operation operation, String prefix) {
    final responses = [
      for (final MapEntry(key: status, value: written)
          in operation.responses.entries)
        if (_context.model.resolve(written) case final response?)
          (status, response, _pick(response.content)),
    ];
    // Inline names carry the status only when several responses of the
    // same kind (success or error) have a body.
    final withBody = <String, int>{};
    for (final (status, _, (_, media)) in responses) {
      if (media?.schema == null && media?.itemSchema == null) continue;
      final base = _nameBase(status);
      withBody[base] = (withBody[base] ?? 0) + 1;
    }
    final result = <ResponseIr>[];
    for (final (status, response, (contentType, media)) in responses) {
      final kind = contentType == null ? BodyKind.none : _kind(contentType);
      final success = status.startsWith('2');
      final base = _nameBase(status);
      final suffix = (withBody[base] ?? 0) > 1
          ? '$base${status == 'default' ? 'Default' : status.toUpperCase()}'
          : base;
      final schema = kind == .eventStream
          ? media?.itemSchema ?? media?.schema
          : media?.schema;
      final envelope = success && kind == .json && schema != null
          ? _envelope(schema)
          : null;
      final DartType? type = switch ((schema, kind)) {
        (_, .text) => const CoreType(.string),
        (_, .bytes) => const CoreType(.binary),
        (final schema?, _) => _mapper.typeOf(
          envelope ?? schema,
          NameHint(prefix, suffix),
        ),
        _ => null,
      };
      result.add(
        ResponseIr(
          status: status,
          kind: kind,
          location: response.location,
          contentType: contentType,
          type: type,
          envelopeKey: envelope == null ? null : 'data',
          description: response.description,
        ),
      );
    }
    return result;
  }

  /// How inline types of a response with [status] are named: `Response`
  /// for 2xx, `Error` for 4xx, 5xx and `default`, `Response` with the status
  /// for the rest.
  static String _nameBase(String status) {
    if (status.startsWith('2')) return 'Response';
    if (status.startsWith('4') || status.startsWith('5')) return 'Error';
    if (status == 'default') return 'Error';
    return 'Response${status.toUpperCase()}';
  }

  /// The schema of `data` when [schema] is an envelope `{data: T}`: an
  /// object whose only property is the required `data` (R6.4).
  Schema? _envelope(Schema schema) {
    final resolved = _context.model.resolveSchema(schema);
    if (resolved is! SchemaObject) return null;
    final data = resolved.properties['data'];
    if (data == null ||
        resolved.properties.length != 1 ||
        !resolved.required.contains('data') ||
        resolved.allOf.isNotEmpty ||
        resolved.additionalProperties is SchemaObject) {
      return null;
    }
    return data;
  }

  /// The documented errors (R11.4): `Never` without any, the one body
  /// type when all errors share it, else the body type of each status. A
  /// status without a body uses `errors.default_schema` when it is set.
  ErrorsIr _errors(List<ResponseIr> responses) {
    final fallback = _defaultErrorType();
    final cases = [
      for (final response in responses)
        if (response.isError) (response.status, response.type ?? fallback),
    ];
    if (cases.isEmpty) {
      return fallback == null
          ? const NoErrors()
          : SingleError(fallback, const []);
    }
    final types = {for (final (_, type) in cases) type};
    if (types.length == 1 && types.single != null) {
      return SingleError(types.single!, [for (final (s, _) in cases) s]);
    }
    return ErrorsByStatus(cases);
  }

  DartType? _defaultErrorType() {
    final key = _context.config.defaultErrorSchema;
    if (key == null) return null;
    final schema = _context.model.document.components?.schemas[key];
    if (schema == null) return null;
    return _mapper.typeOfComponent(schema);
  }

  /// The media type the client uses: JSON first, then forms, text, event
  /// streams and anything else, each in document order.
  (String?, MediaType?) _pick(Map<String, RefOr<MediaType>> content) {
    if (content.isEmpty) return (null, null);
    const preference = [
      BodyKind.json,
      BodyKind.multipart,
      BodyKind.form,
      BodyKind.text,
      BodyKind.eventStream,
      BodyKind.bytes,
    ];
    for (final kind in preference) {
      for (final MapEntry(key: type, value: written) in content.entries) {
        if (_kind(type) != kind) continue;
        return (type, _context.model.resolve(written));
      }
    }
    return (null, null);
  }

  (Schema?, String?) _content(Map<String, RefOr<MediaType>> content) {
    final (type, media) = _pick(content);
    return (media?.schema, type);
  }

  static BodyKind _kind(String contentType) {
    final type = contentType.split(';').first.trim().toLowerCase();
    if (type == 'application/json' || type.endsWith('+json')) return .json;
    if (type == 'multipart/form-data') return .multipart;
    if (type == 'application/x-www-form-urlencoded') return .form;
    if (type == 'text/event-stream') return .eventStream;
    if (type.startsWith('text/')) return .text;
    return .bytes;
  }

/// Where each schema is used, requests or responses, to split models by
/// direction (spec decision 4).
///
/// A schema is split into a response model and a request model when it, or
/// a schema inside it, has a `readOnly` or `writeOnly` property and it is
/// used in both directions. The request body of a PATCH operation is not a
/// use of its schema here: it is recorded apart, and a PATCH body schema
/// that is used anywhere else gets a PATCH model of its own.
final class DirectionIndex {
  /// Creates an index of [_model] with no uses.
  DirectionIndex(this._model);

  final SpecModel _model;
  final Map<SpecLocation, Set<ModelDirection>> _uses = {};
  final Set<(SpecLocation, ModelDirection)> _seen = {};
  final Map<SpecLocation, bool> _directional = {};
  final Set<SpecLocation> _patchBodies = {};

  /// Records the schemas of [operation]'s parameters and request body as
  /// used in requests and those of its responses as used in responses; the
  /// body of a [method] `patch` is a PATCH body.
  void addOperation(Operation operation, PathItem item, String method) {
    for (final written in [...item.parameters, ...operation.parameters]) {
      final parameter = _model.resolve(written);
      if (parameter == null) continue;
      add(parameter.schema, .request);
      _content(parameter.content, .request);
    }
    if (operation.requestBody case final written?) {
      final content = _model.resolve(written)?.content ?? const {};
      if (method.toLowerCase() == 'patch') {
        for (final media in content.values) {
          _patchBody(_model.resolve(media)?.schema);
        }
      } else {
        _content(content, .request);
      }
    }
    for (final written in operation.responses.values) {
      _content(_model.resolve(written)?.content ?? const {}, .response);
    }
  }

  void _content(
    Map<String, RefOr<MediaType>> content,
    ModelDirection direction,
  ) {
    for (final written in content.values) {
      final media = _model.resolve(written);
      add(media?.schema, direction);
      add(media?.itemSchema, direction);
    }
  }

  /// Records [schema] as a PATCH body; the schemas inside it are used in
  /// requests.
  void _patchBody(Schema? schema) {
    if (schema == null) return;
    final resolved = _model.resolveSchema(schema);
    if (resolved is! SchemaObject) return;
    _patchBodies.add(resolved.location);
    for (final child in _children(resolved)) {
      add(child, .request);
    }
  }

  /// Records [schema] and every schema inside it as used in [direction].
  void add(Schema? schema, ModelDirection direction) {
    if (schema is! SchemaObject) return;
    if (schema.ref != null) {
      add(_model.resolveSchema(schema), direction);
      return;
    }
    if (!_seen.add((schema.location, direction))) return;
    (_uses[schema.location] ??= {}).add(direction);
    for (final child in _children(schema)) {
      add(child, direction);
    }
  }

  /// Whether [schema] is a PATCH body that is also used elsewhere, so the
  /// PATCH body gets a model of its own.
  bool separatesPatch(SchemaObject schema) =>
      _patchBodies.contains(schema.location) &&
      _uses.containsKey(schema.location);

  /// Whether [schema] gets a response model and a request model.
  bool splits(SchemaObject schema) =>
      (_uses[schema.location]?.length ?? 0) > 1 && _isDirectional(schema);

  /// The one direction [schema] is used in, if it is used in one only.
  ModelDirection? onlyDirection(SchemaObject schema) =>
      switch (_uses[schema.location]) {
        final uses? when uses.length == 1 => uses.single,
        _ => null,
      };

  /// Whether [schema] or a schema inside it has a `readOnly` or `writeOnly`
  /// property.
  bool _isDirectional(SchemaObject schema) {
    final known = _directional[schema.location];
    if (known != null) return known;
    // A cycle is not directional by itself.
    _directional[schema.location] = false;
    var result = false;
    for (final property in schema.properties.values) {
      final resolved = _model.resolveSchema(property);
      if (resolved is SchemaObject &&
          (resolved.readOnly || resolved.writeOnly)) {
        result = true;
      }
      if (property is SchemaObject &&
          (property.readOnly || property.writeOnly)) {
        result = true;
      }
    }
    if (!result) {
      for (final child in _children(schema)) {
        final resolved = _model.resolveSchema(child);
        if (resolved is SchemaObject && _isDirectional(resolved)) {
          result = true;
          break;
        }
      }
    }
    return _directional[schema.location] = result;
  }

  static List<Schema> _children(SchemaObject schema) => [
    ...schema.properties.values,
    ?schema.items,
    ...schema.prefixItems,
    ?schema.additionalProperties,
    ...schema.allOf,
    ...schema.oneOf,
    ...schema.anyOf,
  ];
}

import '../config/generation_config.dart';
import 'ir_context.dart';
import 'operation_builder.dart';

/// Chooses the operations a client generates (R4.1): the config's
/// `include` and `exclude` filters and the overrides' `exclude`.
///
/// With `include`, only operations that match one of its patterns are
/// kept; `exclude` then removes the operations it matches, so it refines
/// `include` (`include: {tags: [pets]}`, `exclude: {paths: [/pets/admin/**]}`).
/// A pattern that matches no operation of the spec is reported, and so is a
/// pattern both filters list: the config contradicts itself there.
final class OperationSelector {
  /// Creates a selector for the client of [_context].
  const OperationSelector(this._context);

  final IrContext _context;

  /// The operations of [all] to generate, in the same order.
  List<SpecOperation> select(List<SpecOperation> all) {
    final config = _context.config;
    final include = _Matcher(config.include);
    final exclude = _Matcher(config.exclude);
    final selected = <SpecOperation>[];
    for (final entry in all) {
      final included = config.include.isEmpty || include.matches(entry);
      final excluded = exclude.matches(entry);
      final override = _context.overrides.operationAt(entry.operation.location);
      if (!included || excluded || (override?.exclude ?? false)) continue;
      selected.add(entry);
    }
    for (final (included, excluded) in [
      (config.include.tags, config.exclude.tags),
      (config.include.operations, config.exclude.operations),
      (config.include.paths, config.exclude.paths),
    ]) {
      final values = {for (final p in included) p.value};
      for (final pattern in excluded) {
        if (!values.contains(pattern.value)) continue;
        _context.diagnostics.report(
          .filterConflict,
          '"${pattern.value}" is in both include and exclude; exclude wins.',
          file: config.file,
          pointer: pattern.pointer,
          span: pattern.span,
          fix: 'Remove it from one of the filters.',
        );
      }
    }
    for (final pattern in [...include.unused, ...exclude.unused]) {
      _context.diagnostics.report(
        .filterMatchesNothing,
        'Filter "${pattern.value}" matches no operation of the spec.',
        file: config.file,
        pointer: pattern.pointer,
        span: pattern.span,
        fix: 'Fix the pattern, or remove it from the config.',
      );
    }
    return selected;
  }
}

/// The patterns of one filter, and which of them matched.
final class _Matcher {
  _Matcher(this._filter)
    : _paths = [for (final p in _filter.paths) (p, _glob(p.value))];

  final OperationFilter _filter;
  final List<(FilterPattern, RegExp)> _paths;
  final Set<FilterPattern> _used = {};

  /// The patterns that matched no operation so far, in config order.
  List<FilterPattern> get unused => [
    for (final p in [..._filter.tags, ..._filter.operations, ..._filter.paths])
      if (!_used.contains(p)) p,
  ];

  /// Whether a pattern matches [entry]; every matching pattern counts as
  /// used.
  bool matches(SpecOperation entry) {
    final operation = entry.operation;
    final matched = [
      for (final pattern in _filter.tags)
        if (operation.tags.contains(pattern.value)) pattern,
      for (final pattern in _filter.operations)
        if (operation.operationId == pattern.value) pattern,
      for (final (pattern, glob) in _paths)
        if (glob.hasMatch(entry.path)) pattern,
    ];
    _used.addAll(matched);
    return matched.isNotEmpty;
  }

  /// A path glob as a regular expression: `**` matches any characters,
  /// `*` any characters but `/`, `?` one character but `/`.
  static RegExp _glob(String pattern) {
    final buffer = StringBuffer('^');
    for (var i = 0; i < pattern.length; i++) {
      final char = pattern[i];
      if (char == '*' && i + 1 < pattern.length && pattern[i + 1] == '*') {
        buffer.write('.*');
        i++;
      } else if (char == '*') {
        buffer.write('[^/]*');
      } else if (char == '?') {
        buffer.write('[^/]');
      } else {
        buffer.write(RegExp.escape(char));
      }
    }
    buffer.write(r'$');
    return RegExp(buffer.toString());
  }
}

/// `typed_openapi ir`: prints the semantic IR of clients as JSON, to see
/// the names and types the generator will emit and to write overrides
/// before code generation exists.
///
/// The command is hidden: its output is for inspection and may change in
/// any release.
final class IrCommand extends Command<int> {
  /// Creates the command; the IR is written to [_out] and files are named
  /// as [_paths] does.
  IrCommand(this._out, [this._paths = const DisplayPaths()]) {
    argParser.addOption(
      'config',
      abbr: 'c',
      defaultsTo: 'typed_openapi.yaml',
      help: 'Path to the config file.',
    );
  }

  final StringSink _out;
  final DisplayPaths _paths;

  @override
  String get name => 'ir';

  @override
  bool get hidden => true;

  @override
  String get description =>
      'Print the semantic IR of clients as JSON (for debugging).';

  @override
  String get invocation => '${runner!.executableName} ir [options] [client...]';

  @override
  Future<int> run() async {
    final results = argResults!;
    final diagnostics = DiagnosticBag();
    final config = ConfigLoader(
      diagnostics,
      _paths,
    ).load(results.option('config')!);
    if (config == null) {
      _out.writeln(const TextReporter().format(diagnostics));
      return ExitCode.config.code;
    }
    final only = results.rest.toSet();
    final unknown = only.difference(config.declaredClients);
    if (unknown.isNotEmpty) {
      usageException(
        'Unknown client: ${(unknown.toList()..sort()).join(', ')}.',
      );
    }
    final checks = SpecChecker(
      diagnostics,
      _paths,
    ).checkClients(config, only: only);
    final json = {
      for (final ClientCheck(:client, :ir, :irJson) in checks)
        client.name: ir == null || irJson == null ? null : irJson.toJson(ir),
    };
    _out.writeln(const JsonEncoder.withIndent('  ').convert(json));
    return json.values.contains(null) ? 1 : ExitCode.success.code;
  }
}
