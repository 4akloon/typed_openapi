# План M1: каркас, діагностика, завантаження специфікації, `check`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Робочий `typed_openapi check`: читає `typed_openapi.yaml` з кількома клієнтами, завантажує кожну специфікацію (JSON або YAML) з позиціями, визначає версію OpenAPI і друкує діагностики зі стабільними кодами, JSON-pointer і позиціями у форматі text або json. Генерації коду в цьому етапі ще немає.

**Architecture:** Три шари в `packages/typed_openapi/lib/src/`: `diagnostics/` (модель діагностики і репортери), `load/` (файл → `SpecDocument` з деревом і spans; детекція версії), `config/` (`typed_openapi.yaml` → `ProjectConfig`). JSON і YAML читаються одним парсером `package:yaml`, тому позиції є для обох форматів.

**Tech Stack:** Dart `>=3.8.0 <4.0.0`, чистий Dart без Flutter; пакети `yaml`, `source_span`, `args`, `io`, `path`; тести на `package:test`.

```dart
/// An RFC 6901 JSON Pointer in URI-fragment form, such as
/// `#/paths/~1users/get`.
///
/// Tokens are escaped (`~` → `~0`, `/` → `~1`) but not percent-encoded, so
/// pointers stay readable in diagnostics.
extension type const JsonPointer._(String value) {
  /// Parses a pointer in `#` or `#/...` form.
  ///
  /// Throws a [FormatException] for any other input.
  factory JsonPointer.parse(String value) {
    if (value != '#' && !value.startsWith('#/')) {
      throw FormatException('A JSON pointer must start with "#/".', value);
    }
    return JsonPointer._(value);
  }

  /// The pointer to the document root.
  static const JsonPointer root = JsonPointer._('#');

  /// The pointer to [token] (a property name or a list index) under this one.
  JsonPointer child(Object token) =>
      JsonPointer._('$value/${_escape(token.toString())}');

  /// The unescaped reference tokens, outermost first.
  List<String> get tokens => value == '#'
      ? const []
      : [for (final token in value.substring(2).split('/')) _unescape(token)];
}

String _escape(String token) =>
    token.replaceAll('~', '~0').replaceAll('/', '~1');

String _unescape(String token) =>
    token.replaceAll('~1', '/').replaceAll('~0', '~');
```

```dart
///
/// An [id] is stable: once released it never changes meaning.

  parseError('TOA001', 'parse-error', Severity.error),

  /// A mapping repeats a key.
  duplicateKey('TOA002', 'duplicate-key', Severity.warning),

  /// The document root is not an object.
  rootNotObject('TOA003', 'root-not-object', Severity.error),

  /// The input file does not exist.
  inputNotFound('TOA004', 'input-not-found', Severity.error),

  /// Source positions could not be recorded for a document.
  positionsUnavailable('TOA005', 'positions-unavailable', Severity.info),

  /// The document has no `openapi` field.
  missingOpenApiVersion('TOA010', 'missing-openapi-version', Severity.error),

  /// The document declares a version this tool does not read.
  unsupportedOpenApiVersion(
    'TOA011',
    'unsupported-openapi-version',
    Severity.error,
  ),

  /// The document declares a 3.x minor version newer than 3.2.
  unknownOpenApiMinorVersion(
    'TOA012',
    'unknown-openapi-minor-version',
    Severity.warning,
  ),

  /// The configuration file does not exist.
  configNotFound('TOA901', 'config-not-found', Severity.error),

  /// The configuration file is malformed or has an invalid value.
  configInvalid('TOA902', 'config-invalid', Severity.error),

  configUnknownKey('TOA903', 'config-unknown-key', Severity.warning),

  /// Two clients write to the same or nested output directories.
  outputOverlap('TOA904', 'output-overlap', Severity.error);
```

```dart
import 'package:source_span/source_span.dart';

import 'diagnostic.dart';
import 'diagnostic_code.dart';
import 'json_pointer.dart';
import 'severity.dart';

/// Collects diagnostics while input is processed.
///
/// Processing code reports problems here instead of throwing, so a single
/// run shows every problem it can find.
class DiagnosticBag {
  final List<Diagnostic> _items = [];

  /// All diagnostics in the order they were reported.
  List<Diagnostic> get all => List.unmodifiable(_items);

  /// Whether any diagnostic has [Severity.error].
  bool get hasErrors => _items.any((d) => d.severity == Severity.error);

  /// Adds an already built [diagnostic].
  void add(Diagnostic diagnostic) => _items.add(diagnostic);

  /// Reports [code] with [message].
  ///
  /// [severity] defaults to the code's [DiagnosticCode.defaultSeverity].
  void report(
    DiagnosticCode code,
    String message, {
    Severity? severity,
    String? file,
    JsonPointer? pointer,
    SourceSpan? span,
    String? fix,
  }) {
    _items.add(
      Diagnostic(
        code: code,
        severity: severity ?? code.defaultSeverity,
        message: message,
        file: file,
        pointer: pointer,
        span: span,
        fix: fix,
      ),
    );
  }
}
```

```dart
import 'dart:convert';

import 'diagnostic.dart';
import 'severity.dart';

/// Orders [diagnostics] by file, position, pointer, code and message, so
/// the same input always prints the same report.
List<Diagnostic> sortDiagnostics(Iterable<Diagnostic> diagnostics) {
  return diagnostics.toList()..sort(_compare);
}

int _compare(Diagnostic a, Diagnostic b) {
  final byFile = (a.file ?? '').compareTo(b.file ?? '');
  if (byFile != 0) return byFile;
  final byOffset = (a.span?.start.offset ?? -1).compareTo(
    b.span?.start.offset ?? -1,
  );
  if (byOffset != 0) return byOffset;
  final byPointer = (a.pointer?.value ?? '').compareTo(b.pointer?.value ?? '');
  if (byPointer != 0) return byPointer;
  final byCode = a.code.id.compareTo(b.code.id);
  if (byCode != 0) return byCode;
  return a.message.compareTo(b.message);
}

/// Formats [diagnostics] for a terminal, ending with a summary line.
String formatText(Iterable<Diagnostic> diagnostics) {
  final sorted = sortDiagnostics(diagnostics);
  final out = StringBuffer();
  for (final d in sorted) {
    out.writeln('${d.severity.name} ${d.code.id} ${d.code.slug}: ${d.message}');
    final location = _location(d);
    if (location != null) out.writeln('  --> $location');
    final pointer = d.pointer;
    if (pointer != null) out.writeln('  at ${pointer.value}');
    final fix = d.fix;
    if (fix != null) out.writeln('  fix: $fix');
  }
  final counts = _counts(sorted);
  out.write(
    'errors: ${counts[Severity.error]}, '
    'warnings: ${counts[Severity.warning]}, '
    'infos: ${counts[Severity.info]}',
  );
  return out.toString();
}

/// Formats [diagnostics] as JSON for CI and other tools.
///
/// Lines and columns are 1-based; they are null when positions are unknown.
String formatJson(Iterable<Diagnostic> diagnostics) {
  final sorted = sortDiagnostics(diagnostics);
  final counts = _counts(sorted);
  return const JsonEncoder.withIndent('  ').convert({
    'diagnostics': [
      for (final d in sorted)
        {
          'code': d.code.id,
          'name': d.code.slug,
          'severity': d.severity.name,
          'message': d.message,
          'file': d.file,
          'pointer': d.pointer?.value,
          'line': _line(d),
          'column': _column(d),
          'fix': d.fix,
        },
    ],
    'summary': {for (final s in Severity.values) s.name: counts[s]},
  });
}

String? _location(Diagnostic d) {
  final file = d.file;
  if (file == null) return null;
  final line = _line(d);
  return line == null ? file : '$file:$line:${_column(d)}';
}

int? _line(Diagnostic d) {
  final start = d.span?.start;
  return start == null ? null : start.line + 1;
}

int? _column(Diagnostic d) {
  final start = d.span?.start;
  return start == null ? null : start.column + 1;
}

Map<Severity, int> _counts(List<Diagnostic> diagnostics) => {
  for (final s in Severity.values)
    s: diagnostics.where((d) => d.severity == s).length,
};
```

```dart
/// A loaded spec: a plain JSON-like tree plus the source position of every
/// node, looked up by JSON pointer.
///
/// [root] contains only `Map<String, Object?>`, `List<Object?>`, `String`,
/// `num`, `bool` and `null`; keys are always strings.
final class SpecDocument {
  /// Creates a document; [spans] maps pointer values to source ranges.
  const SpecDocument({
    required this.file,
    required this.root,
    required Map<String, SourceSpan> spans,
  }) : _spans = spans;

  /// The file path as shown to the user.
  final String file;

  /// The document contents.
  final Map<String, Object?> root;

  final Map<String, SourceSpan> _spans;

  /// Whether source positions were recorded.
  bool get hasPositions => _spans.isNotEmpty;

  /// The source range of the node at [pointer], if known.
  SourceSpan? spanOf(JsonPointer pointer) => _spans[pointer.value];
}
```

```dart
import 'dart:convert';
import 'dart:io';

import 'package:path/path.dart' as p;
import 'package:source_span/source_span.dart';
import 'package:yaml/yaml.dart';

import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/diagnostic_code.dart';
import '../diagnostics/json_pointer.dart';
import '../diagnostics/severity.dart';
import 'spec_document.dart';

/// Reads the spec file at [path] (JSON or YAML).
///
/// [displayPath] is used in diagnostics instead of [path]. Problems go to
/// [diagnostics]; returns null when the file cannot be used at all.
SpecDocument? loadSpec(
  String path,
  DiagnosticBag diagnostics, {
  String? displayPath,
}) {
  final file = displayPath ?? path;
  final source = File(path);
  if (!source.existsSync()) {
    diagnostics.report(
      DiagnosticCode.inputNotFound,
      'Spec file $file does not exist.',
      file: file,
      fix: 'Check "input" in the config, or download a fresh snapshot.',
    );
    return null;
  }
  return parseSpec(source.readAsStringSync(), file, diagnostics);
}

/// Parses spec [text]; [file] names it in diagnostics.
///
/// JSON and YAML go through the same YAML parser, so both get positions.
/// A JSON file the YAML parser rejects (for example, because of a duplicate
/// key) is read again with `jsonDecode`, without positions.
SpecDocument? parseSpec(String text, String file, DiagnosticBag diagnostics) {
  final YamlNode node;
  try {
    node = loadYamlNode(text, sourceUrl: Uri.file(file));
  } on YamlException catch (e) {
    return _parseJsonFallback(text, file, e, diagnostics);
  }
  if (node is! YamlMap) {
    diagnostics.report(
      DiagnosticCode.rootNotObject,
      'The document root must be an object.',
      file: file,
      pointer: JsonPointer.root,
      span: node.span,
    );
    return null;
  }
  final spans = <String, SourceSpan>{};
  final root = _toPlain(node, JsonPointer.root, spans)! as Map<String, Object?>;
  return SpecDocument(file: file, root: root, spans: spans);
}

SpecDocument? _parseJsonFallback(
  String text,
  String file,
  YamlException error,
  DiagnosticBag diagnostics,
) {
  final duplicate = error.message.startsWith('Duplicate mapping key');
  final decoded = p.extension(file).toLowerCase() == '.json'
      ? _tryDecodeJson(text)
      : null;
  if (decoded == null) {
    diagnostics.report(
      duplicate ? DiagnosticCode.duplicateKey : DiagnosticCode.parseError,
      error.message,
      severity: Severity.error,
      file: file,
      span: error.span,
    );
    return null;
  }
  if (duplicate) {
    diagnostics.report(
      DiagnosticCode.duplicateKey,
      '${error.message} The last value is used.',
      file: file,
      span: error.span,
      fix: 'Remove the duplicate key from the spec.',
    );
  }
  diagnostics.report(
    DiagnosticCode.positionsUnavailable,
    'Read $file without source positions; '
    'diagnostics for it show JSON pointers only.',
    file: file,
  );
  final (root,) = decoded;
  if (root is! Map<String, Object?>) {
    diagnostics.report(
      DiagnosticCode.rootNotObject,
      'The document root must be an object.',
      file: file,
      pointer: JsonPointer.root,
    );
    return null;
  }
  return SpecDocument(file: file, root: root, spans: const {});
}

(Object?,)? _tryDecodeJson(String text) {
  try {
    return (jsonDecode(text),);
  } on FormatException {
    return null;
  }
}

Object? _toPlain(
  YamlNode node,
  JsonPointer pointer,
  Map<String, SourceSpan> spans,
) {
  spans[pointer.value] = node.span;
  return switch (node) {
    YamlMap() => <String, Object?>{
      for (final MapEntry(:key, :value) in node.nodes.entries)
        '${(key as YamlNode).value}': _toPlain(
          value,
          pointer.child('${key.value}'),
          spans,
        ),
    },
    YamlList() => <Object?>[
      for (var i = 0; i < node.nodes.length; i++)
        _toPlain(node.nodes[i], pointer.child(i), spans),
    ],
    _ => node.value,
  };
}
```

```dart
import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/diagnostic_code.dart';
import '../diagnostics/json_pointer.dart';
import 'spec_document.dart';

/// The OpenAPI line a document declares in its `openapi` field.
enum OpenApiVersion {
  /// OpenAPI 3.0.x.
  v30,

  /// OpenAPI 3.1.x.
  v31,

  /// OpenAPI 3.2.x.
  v32,
}

final _version = RegExp(r'^3\.(\d+)(?:\.\d+)?$');

/// Reads the `openapi` field of [document].
///
/// Reports a diagnostic and returns null when the field is missing or the
/// document is not OpenAPI 3. A minor version above 3.2 is read as 3.2,
/// with a warning.
OpenApiVersion? detectOpenApiVersion(
  SpecDocument document,
  DiagnosticBag diagnostics,
) {
  final root = document.root;
  final declared = root['openapi'];
  if (declared == null) {
    final swagger = root['swagger'];
    final pointer = JsonPointer.root.child('swagger');
    if (swagger != null) {
      diagnostics.report(
        DiagnosticCode.unsupportedOpenApiVersion,
        'Swagger $swagger is not supported; only OpenAPI 3.0, 3.1 and 3.2 are.',
        file: document.file,
        pointer: pointer,
        span: document.spanOf(pointer),
        fix: 'Have the backend emit OpenAPI 3, or convert the document.',
      );
    } else {
      diagnostics.report(
        DiagnosticCode.missingOpenApiVersion,
        'The document has no "openapi" field.',
        file: document.file,
        pointer: JsonPointer.root,
        fix: 'Add the version the backend emits, for example "openapi: 3.0.3".',
      );
    }
    return null;
  }
  final pointer = JsonPointer.root.child('openapi');
  final match = _version.firstMatch('$declared');
  if (match == null) {
    diagnostics.report(
      DiagnosticCode.unsupportedOpenApiVersion,
      'OpenAPI "$declared" is not supported; only 3.0, 3.1 and 3.2 are.',
      file: document.file,
      pointer: pointer,
      span: document.spanOf(pointer),
    );
    return null;
  }
  switch (int.parse(match.group(1)!)) {
    case 0:
      return OpenApiVersion.v30;
    case 1:
      return OpenApiVersion.v31;
    case 2:
      return OpenApiVersion.v32;
    case final minor:
      diagnostics.report(
        DiagnosticCode.unknownOpenApiMinorVersion,
        'OpenAPI 3.$minor is newer than this tool knows; reading it as 3.2.',
        file: document.file,
        pointer: pointer,
        span: document.spanOf(pointer),
      );
      return OpenApiVersion.v32;
  }
}
```

```dart
/// Normalizer presets a client may name in the config.
const knownPresets = {'generic', 'nestjs', 'fastapi', 'springdoc', 'aspnet'};

/// Line width of generated code when the config does not set one.
const defaultLineWidth = 80;

/// Generation settings for one client from `typed_openapi.yaml`.
final class ClientConfig {
  /// Creates a client configuration.
  const ClientConfig({
    required this.name,
    required this.input,
    required this.output,
    required this.lineWidth,
    this.preset,
    this.overrides,
    this.baseline,
  });

  /// The key under `clients`, such as `core_api`.
  final String name;

  /// Absolute path of the spec file.
  final String input;

  /// Absolute path of the output directory.
  final String output;

  /// Line width of generated code.
  final int lineWidth;

  /// Normalizer preset, one of [knownPresets].
  final String? preset;

  /// Absolute path of the overrides file.
  final String? overrides;

  /// Absolute path of the baseline file.
  final String? baseline;
}

/// The parsed `typed_openapi.yaml`.
final class ProjectConfig {
  /// Creates a project configuration.
  const ProjectConfig({required this.file, required this.clients});

  /// Path of the config file as given by the user.
  final String file;

  /// Clients sorted by name.
  final List<ClientConfig> clients;
}
```

```dart
import 'dart:io';

import 'package:path/path.dart' as p;
import 'package:source_span/source_span.dart';
import 'package:yaml/yaml.dart';

import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/diagnostic_code.dart';
import '../diagnostics/json_pointer.dart';
import 'project_config.dart';

const _topLevelKeys = {'defaults', 'clients'};
const _defaultsKeys = {'preset', 'line_width'};
const _clientKeys = {
  'input',
  'output',
  'preset',
  'overrides',
  'baseline',
  'line_width',
};

/// Reads the config file at [path].
///
/// Relative paths inside it are resolved against its directory. Problems go
/// to [diagnostics]. Returns null when the file is missing or unusable;
/// otherwise returns every client that is valid.
ProjectConfig? loadConfig(String path, DiagnosticBag diagnostics) {
  final source = File(path);
  if (!source.existsSync()) {
    diagnostics.report(
      DiagnosticCode.configNotFound,
      'Config file $path does not exist.',
      file: path,
      fix: 'Create typed_openapi.yaml, or pass its path with --config.',
    );
    return null;
  }
  final YamlNode root;
  try {
    root = loadYamlNode(source.readAsStringSync(), sourceUrl: Uri.file(path));
  } on YamlException catch (e) {
    diagnostics.report(
      DiagnosticCode.configInvalid,
      e.message,
      file: path,
      span: e.span,
    );
    return null;
  }
  final reader = _ConfigReader(path, diagnostics);
  if (root is! YamlMap) {
    reader.invalid('The config must be a mapping.', root, JsonPointer.root);
    return null;
  }
  reader.checkKeys(root, _topLevelKeys, JsonPointer.root);

  final defaultsPointer = JsonPointer.root.child('defaults');
  final defaults = reader.mapAt(root, 'defaults', JsonPointer.root);
  String? defaultPreset;
  int? defaultWidth;
  if (defaults != null) {
    reader.checkKeys(defaults, _defaultsKeys, defaultsPointer);
    defaultPreset = reader.presetAt(defaults, defaultsPointer);
    defaultWidth = reader.intAt(defaults, 'line_width', defaultsPointer);
  }

  final clientsPointer = JsonPointer.root.child('clients');
  final clientNodes = reader.mapAt(
    root,
    'clients',
    JsonPointer.root,
    required: true,
  );
  if (clientNodes == null) return null;
  if (clientNodes.isEmpty) {
    reader.invalid('"clients" is empty.', clientNodes, clientsPointer);
    return null;
  }

  final baseDir = p.dirname(p.absolute(path));
  String resolve(String value) => p.normalize(p.join(baseDir, value));

  final clients = <ClientConfig>[];
  final outputSpans = <String, SourceSpan>{};
  for (final MapEntry(:key, :value) in clientNodes.nodes.entries) {
    final name = '${(key as YamlNode).value}';
    final pointer = clientsPointer.child(name);
    if (value is! YamlMap) {
      reader.invalid('Client "$name" must be a mapping.', value, pointer);
      continue;
    }
    reader.checkKeys(value, _clientKeys, pointer);
    final input = reader.stringAt(value, 'input', pointer, required: true);
    final output = reader.stringAt(value, 'output', pointer, required: true);
    final preset = reader.presetAt(value, pointer) ?? defaultPreset;
    final lineWidth =
        reader.intAt(value, 'line_width', pointer) ??
        defaultWidth ??
        defaultLineWidth;
    final overrides = reader.stringAt(value, 'overrides', pointer);
    final baseline = reader.stringAt(value, 'baseline', pointer);
    if (input == null || output == null) continue;
    outputSpans[name] = value.nodes['output']!.span;
    clients.add(
      ClientConfig(
        name: name,
        input: resolve(input),
        output: resolve(output),
        lineWidth: lineWidth,
        preset: preset,
        overrides: overrides == null ? null : resolve(overrides),
        baseline: baseline == null ? null : resolve(baseline),
      ),
    );
  }
  clients.sort((a, b) => a.name.compareTo(b.name));
  _checkOutputOverlap(clients, outputSpans, path, diagnostics);
  return ProjectConfig(file: path, clients: clients);
}

void _checkOutputOverlap(
  List<ClientConfig> clients,
  Map<String, SourceSpan> outputSpans,
  String file,
  DiagnosticBag diagnostics,
) {
  for (var i = 0; i < clients.length; i++) {
    for (var j = i + 1; j < clients.length; j++) {
      final a = clients[i];
      final b = clients[j];
      final overlap =
          p.equals(a.output, b.output) ||
          p.isWithin(a.output, b.output) ||
          p.isWithin(b.output, a.output);
      if (!overlap) continue;
      diagnostics.report(
        DiagnosticCode.outputOverlap,
        'Clients "${a.name}" and "${b.name}" write to overlapping '
        'directories.',
        file: file,
        pointer: JsonPointer.root
            .child('clients')
            .child(b.name)
            .child('output'),
        span: outputSpans[b.name],
        fix: 'Give each client its own output directory.',
      );
    }
  }
}

class _ConfigReader {
  _ConfigReader(this.file, this.diagnostics);

  final String file;
  final DiagnosticBag diagnostics;

  void checkKeys(YamlMap map, Set<String> allowed, JsonPointer at) {
    for (final key in map.nodes.keys.cast<YamlNode>()) {
      final name = '${key.value}';
      if (allowed.contains(name)) continue;
      diagnostics.report(
        DiagnosticCode.configUnknownKey,
        'Unknown key "$name".',
        file: file,
        pointer: at.child(name),
        span: key.span,
        fix: 'Allowed keys here: ${(allowed.toList()..sort()).join(', ')}.',
      );
    }
  }

  YamlMap? mapAt(
    YamlMap parent,
    String key,
    JsonPointer at, {
    bool required = false,
  }) {
    final node = parent.nodes[key];
    if (node == null) {
      if (required) invalid('Missing required key "$key".', parent, at);
      return null;
    }
    if (node is YamlMap) return node;
    invalid('"$key" must be a mapping.', node, at.child(key));
    return null;
  }

  String? stringAt(
    YamlMap parent,
    String key,
    JsonPointer at, {
    bool required = false,
  }) {
    final node = parent.nodes[key];
    if (node == null) {
      if (required) invalid('Missing required key "$key".', parent, at);
      return null;
    }
    final value = node.value;
    if (value is String && value.isNotEmpty) return value;
    invalid('"$key" must be a non-empty string.', node, at.child(key));
    return null;
  }

  int? intAt(YamlMap parent, String key, JsonPointer at) {
    final node = parent.nodes[key];
    if (node == null) return null;
    final value = node.value;
    if (value is int && value > 0) return value;
    invalid('"$key" must be a positive integer.', node, at.child(key));
    return null;
  }

  String? presetAt(YamlMap parent, JsonPointer at) {
    final preset = stringAt(parent, 'preset', at);
    if (preset == null || knownPresets.contains(preset)) return preset;
    invalid(
      'Unknown preset "$preset". '
      'Known presets: ${(knownPresets.toList()..sort()).join(', ')}.',
      parent.nodes['preset']!,
      at.child('preset'),
    );
    return null;
  }

  void invalid(String message, YamlNode node, JsonPointer at) {
    diagnostics.report(
      DiagnosticCode.configInvalid,
      message,
      file: file,
      pointer: at,
      span: node.span,
    );
  }
}
```

```dart
import 'package:path/path.dart' as p;

import 'config/project_config.dart';
import 'diagnostics/diagnostic.dart';
import 'diagnostics/diagnostic_bag.dart';
import 'load/openapi_version.dart';
import 'load/spec_loader.dart';

/// Loads every client's spec in [config] and reports what is wrong with it.
/// Nothing is generated.
///
/// [only] limits the run to clients with these names; empty means all.
/// Spec paths in diagnostics are relative to the config file's directory.
List<Diagnostic> runCheck(
  ProjectConfig config, {
  Set<String> only = const {},
}) {
  final diagnostics = DiagnosticBag();
  final configDir = p.dirname(p.absolute(config.file));
  for (final client in config.clients) {
    if (only.isNotEmpty && !only.contains(client.name)) continue;
    final document = loadSpec(
      client.input,
      diagnostics,
      displayPath: p.relative(client.input, from: configDir),
    );
    if (document == null) continue;
    detectOpenApiVersion(document, diagnostics);
  }
  return diagnostics.all;
}
```

```dart
import 'package:args/command_runner.dart';
import 'package:io/io.dart' show ExitCode;

import '../check.dart';
import '../config/config_loader.dart';
import '../diagnostics/diagnostic_bag.dart';
import '../diagnostics/reporters.dart';

/// Exit code when the check found at least one error.
const exitHasErrors = 1;

/// `typed_openapi check`: analyzes specs without generating code.
class CheckCommand extends Command<int> {
  /// Creates the command; reports are written to [out].
  CheckCommand(this._out) {
    argParser
      ..addOption(
        'config',
        abbr: 'c',
        defaultsTo: 'typed_openapi.yaml',
        help: 'Path to the config file.',
      )
      ..addOption(
        'format',
        allowed: ['text', 'json'],
        defaultsTo: 'text',
        help: 'Report format.',
      );
  }

  final StringSink _out;

  @override
  String get name => 'check';

  @override
  String get description =>
      'Check specs and report diagnostics without generating code.';

  @override
  String get invocation =>
      '${runner!.executableName} check [options] [client...]';

  @override
  Future<int> run() async {
    final results = argResults!;
    final diagnostics = DiagnosticBag();
    final config = loadConfig(results.option('config')!, diagnostics);
    if (config != null) {
      final only = results.rest.toSet();
      final unknown = only.difference({
        for (final client in config.clients) client.name,
      });
      if (unknown.isNotEmpty) {
        usageException(
          'Unknown client: ${(unknown.toList()..sort()).join(', ')}.',
        );
      }
      runCheck(config, only: only).forEach(diagnostics.add);
    }
    final all = diagnostics.all;
    _out.writeln(
      results.option('format') == 'json' ? formatJson(all) : formatText(all),
    );
    if (config == null) return ExitCode.config.code;
    return diagnostics.hasErrors ? exitHasErrors : ExitCode.success.code;
  }
}
```

```dart
import 'dart:io';

import 'package:args/command_runner.dart';
import 'package:io/io.dart' show ExitCode;

import 'check_command.dart';

/// Runs the `typed_openapi` command line with [args]; returns the exit code.
///
/// Reports go to [out] and usage errors to [err]; both default to the
/// process streams.
Future<int> runCli(
  List<String> args, {
  StringSink? out,
  StringSink? err,
}) async {
  final runner = CommandRunner<int>(
    'typed_openapi',
    'OpenAPI 3.x to Dart client generator.',
  )..addCommand(CheckCommand(out ?? stdout));
  try {
    return await runner.run(args) ?? ExitCode.success.code;
  } on UsageException catch (e) {
    (err ?? stderr)
      ..writeln(e.message)
      ..writeln()
      ..writeln(e.usage);
    return ExitCode.usage.code;
  }
}
```

## Поправка від 2026-10-11 (після Task 5): ООП і Dart 3.10

Рішення автора проєкту, ухвалені під час виконання плану. **Поправка має пріоритет над кодом у Tasks 1–9 вище.** Код задач 6–9 переноситься з плану з перетворенням за таблицею нижче; логіка, повідомлення діагностик, коди, тест-кейси і їхні очікувані значення не змінюються.

### Правила

1. **Мінімальний SDK — Dart 3.10** (`sdk: ">=3.10.0 <4.0.0"`) для кореневого `pubspec.yaml`, обох пакетів і, відповідно, для згенерованого коду. Primary constructors (Dart 3.13) не використовуємо.
2. **Активно використовуємо можливості мови ≥3.10:**
   - dot shorthands скрізь, де відомий тип контексту: `.error`, `.parseError`, `.v30`, `return .v32;`, `severity: .error`, `d.severity == .error`, `case .v30`;
   - null-aware елементи колекцій (`'k': ?v`), switch-вирази і patterns, records, модифікатори класів (`final`, `sealed`, `interface`), extension types для обгорток без накладних витрат.
   - У тестах аргументи `expect(...)` не мають типу контексту, тому там лишаються повні імена (`DiagnosticCode.parseError`).
3. **ООП, жодних функцій верхнього рівня.** Єдиний виняток — `main` у `bin/` і в тестах. Приватні хелпери стають приватними методами (статичними, якщо не потребують стану). Константи живуть у класах, до яких належать. Компоненти, що звітують про проблеми, отримують `DiagnosticBag` через конструктор.
4. У корені репозиторію є `CLAUDE.md` з цими правилами, командами і архітектурою.
